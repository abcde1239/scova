# Agent 与模型配置

在「账号 → Agent 配置」（`/account/agent`）配置研究用的模型和搜索。页面分为三块：「解析」「任务执行」「搜索与正文提取」。

- **解析**：生成任务草稿。
- **任务执行**：真实研究和报告问答。
- **搜索与正文提取**：搜索地址、密钥和正文策略，独立保存。

每个账号可以保存多个模型供应商，解析与任务执行分别选择，也可以共用同一个。

## 配置模型

页面上方选择解析和任务执行用的配置，下方「模型供应商管理」用来添加、编辑和删除模型连接。

1. 在「供应商管理」点「添加供应商」，选择预设或自定义配置。预设会填好地址与协议。
2. 填写配置名称、API 根地址和 API Key，点「获取模型列表」，按名称或 ID 搜索并选择模型，然后保存。根地址包含版本路径，例如 `https://api.example.com/v1`，不需要再加具体请求接口。
3. 在上方分别选择「解析使用的配置」与「任务执行使用的配置」，选择后立即保存。

切换一种用途不会改动另一种用途或搜索配置。保存和切换都不会调用收费模型，也不会自动尝试其他供应商。

### 什么时候生效

- 使用账号默认配置的后续调用，以及新开始或中断后恢复的研究，会读取最新选择。
- 正在运行的执行会话保持启动时的配置。

### 接口协议

| 接口协议                  | 使用场景                                               |
| ------------------------- | ------------------------------------------------------ |
| OpenAI 兼容 · JSON Schema | 支持 Chat Completions 严格结构化输出的模型或兼容服务   |
| OpenAI 兼容 · JSON 模式   | 支持 `json_object` 的兼容服务，DeepSeek 预设使用此模式 |
| Anthropic Messages        | 通过工具调用返回结构化结果                             |
| Gemini generateContent    | 通过 JSON Schema 返回结构化结果                        |

兼容服务需要支持所选协议。所有模式都会校验返回数据、完成状态和用量，不合格的结果不会进入报告。保存成功只代表配置已保存，不代表远程模型已通过验证。

### 编辑与删除

- **密钥**：编辑时留空保留原值，填写新密钥则替换。密钥不会回显。
- **切换预设**：会清空未保存的模型 ID 和密钥。
- **多窗口冲突**：编辑、切换和删除遇到冲突时，重新读取后再操作。
- **保存结果不明**：先关闭编辑并重新读取列表，避免重复创建。
- **删除配置**：正在使用它的用途会恢复默认选择。
- **没有个人供应商时**：该用途使用部署的 `MODEL_API_KEY`、`MODEL_NAME`、`MODEL_BASE_URL`。部署也没有默认模型时，真实研究不可用，草稿和问答按缺模型流程处理。

### 为任务指定配置

创建或编辑任务时，可在「时间与输出 → 执行 Agent 配置」选择已保存的个人配置，用于该任务的手动和计划执行。留为「账号默认配置」则沿用账号的任务执行选择。

- **本次执行**：立即执行和重试区域可以单独指定本次配置，或显式选择账号默认，不修改任务和账号的默认选择。
- **重发**：发送后本次选择即固定，重发同一命令保持一致。
- **配置不可用**：指定的配置被删除或无法读取时会明确失败，需要重新选择。

## 获取模型列表

「获取模型列表」只访问供应商的模型目录，不生成内容，不保存配置，也不切换用途。页面会显示读取中、成功数量、空列表或失败状态，可以刷新和重试。

- **编辑已有配置**：自动用本人已存密钥读取。更改地址或协议后需要重新填写密钥，防止把原密钥发给新的目的地。
- **读取范围**：OpenAI 兼容与 Anthropic 读取根地址下的 `/models`，Gemini 读取支持 `generateContent` 的模型。分页或数量达到上限时会提示只显示部分结果。
- **目录里没有想要的模型**：服务不提供目录、私有模型未列出或列表为空时，展开「手动输入模型 ID」。
- **刷新后**：不会自动替换已选模型；旧配置在目录里没有返回时会保留并标注。
- **注意**：目录里能看到模型，不保证它支持所选的结构化输出协议。

### 读取失败时

页面会区分供应商拒绝鉴权、不提供目录、网络连接、超时、响应格式、大小限制和限流等原因。需要排查时，可提供失败请求 Response 中的 `code`、`message` 和 `requestId`，不必发送请求体、Cookie 或 API Key。

| 错误码                           | 建议                                  |
| -------------------------------- | ------------------------------------- |
| `MODEL_CATALOG_NETWORK`          | 检查代理、DNS 与 TLS                  |
| `MODEL_CATALOG_INVALID_RESPONSE` | 检查根地址和协议                      |
| `MODEL_CATALOG_TOO_LARGE`        | 先用手动输入模型 ID，大小限制仍然保留 |

## 研究搜索方式

在独立的「搜索与正文提取」区域保存账号默认方式。

- **Search API**：支持 DeepSeek Search / Fetch 和 Tavily Search / Extract。单独填写地址和密钥，由 API 同时完成搜索和网页读取。
- **SearXNG**：选择后会保留已填的 API 配置，供指定任务使用。
- **密钥**：不回显。地址与协议没变时留空保留；更改后必须重新填写。

任务可以保存自己的搜索方式，并在立即执行时临时覆盖：

- **沿用账号搜索配置**：读取搜索区域的默认方式；账号未设置时使用内置 SearXNG。
- **Search API**：只使用账号搜索密钥，不随所选模型变化。缺少配置时会提示去设置或改用内置搜索。
- **内置 SearXNG＋网页读取工具**：使用内置搜索和网页读取工具。

部署不提供默认的搜索凭据，也不会用模型密钥代替搜索密钥。详见[搜索服务配置](search.md)。

### 从旧配置迁入

如果搜索 API 原来保存在某个模型配置里，在搜索区域点「迁入」，会把它复制并重新加密为独立的搜索配置。迁入后，删除原模型不会影响搜索配置。未迁入的旧搜索数据不再用于任务执行。

## 余额与额度查询

在供应商卡片选择「额度查询方式」，点「查询额度」手动读取。页面显示单位和查询时间；刷新失败时保留上次成功的结果并标明时间。

进入页面不会自动查询，查询也不调用生成接口或切换模型。

| 查询方式           | 支持范围                                               | 结果含义                                 |
| ------------------ | ------------------------------------------------------ | ---------------------------------------- |
| 自动识别官方余额   | DeepSeek、OpenRouter、SiliconFlow（中国/国际）官方地址 | 账号余额，按返回币种分别显示             |
| New API · Key 额度 | 支持 `/api/usage/token/` 的中转站                      | Key 剩余额度、已用量；允许时另列账号额度 |
| Sub2API · 额度查询 | 支持 `/v1/usage` 的中转站                              | 供应商返回的余额或额度及单位             |

- **Key 限额不是账号余额**：同一账号的多个配置可能查到同一份余额，不能相加。
- **New API**：使用原始额度点，各站点的换算规则可能不同。「Key 未设限额」仍受账号余额约束。
- **结果是当时的快照**：Scova 的任务 Token 预算是独立的执行限制。
- **不支持的情况**：其他供应商或兼容站点不一定提供额度接口。无接口、权限不足或返回格式不支持时会明确提示，不会把缺失值当作零。
- **使用的凭据**：只用该配置已保存的密钥和同源固定接口，不读取本机其他应用的订阅登录凭据。

## 执行预算

任务配置里可以调整预算；已保存的任务保留原预算，修改并保存后只影响新版本和之后的执行，已有报告不会被改写。

| 项目           | 新任务默认 | 部署上限  |
| -------------- | ---------- | --------- |
| 执行时长       | 10 分钟    | 30 分钟   |
| 累计输入 token | 1,000,000  | 2,000,000 |
| 累计输出 token | 128,000    | 512,000   |

- **共享预算**：规划、比较、综合和重试共享累计预算。
- **单次综合**：新执行的综合单次输入最多 128,000 token，首次输出最多 16,000，修复最多 24,000。按成功回执的实际用量和剩余批次分配；旧检查点保留原配额。
- **等待上限**：模型调用最多等待 120 秒。
- **供应商限制**：供应商和所选模型可能有更低的上下文或输出限制。
- **简报**：优先归纳核心发现，原句保留为引用。无法完成综合时会明确显示未完成归纳，不会把正文摘录当作总结。

## 常见问题

### DeepSeek 官方 API 为什么要关闭思考？

DeepSeek 官方 API 的 `deepseek-flash`、`deepseek-v4-pro` 默认启用思考，可能在输出 JSON 前耗尽单次预算。因此 Scova 对这两种模型的 JSON 模式请求显式发送 `thinking.type=disabled`，让输出额度用于结构化回答。累计预算、引用和覆盖校验不变。

该参数只发送到 `https://api.deepseek.com` 的标准根地址，不会推断兼容代理或其他模型是否支持。参见 [DeepSeek 思考模式](https://api-docs.deepseek.com/guides/thinking_mode)。

### 模型列表或网页读取连不上，DNS 怎么设置？

模型列表和实际生成共用同一套解析策略。默认 `MODEL_DNS_RESOLVER=auto` 使用系统 DNS；系统全部返回代理 Fake-IP（`198.18.0.0/15`）时，会通过固定公网 IP 连接 AliDNS 的 HTTPS 服务重新解析，再校验并固定真实公网 IP。

- **安全**：不会直接放行 Fake-IP、内网或混合解析；DNS 查询不携带 API Key。
- **可选值**：设为 `system` 禁用回退，或显式选择 `alidns`、`cloudflare`、`google`。修改后重启 Server 和 Worker。
- **网页读取**：使用独立的 `READER_DNS_RESOLVER`，默认 `auto`，可选值相同。系统全部返回 Fake-IP 时，默认改经 Cloudflare 官方公网引导的 HTTPS DNS 回退，并保留原域名的 TLS 校验；它不继承模型通道的配置。
- **SearXNG**：固定的服务地址继续使用独立的内部连接策略。

### 提示词用什么语言？

研究提示以英文为主，报告正文要求中文，原文引文保留原语言。规划、综合、证据评估和四种交付形式各有目标，详见[研究提示词](../reference/research-prompts.md)。

## 管理员设置

- **加密主密钥**：Server 持有 `AGENT_CREDENTIAL_KEY`（64 位十六进制、256 bit 随机密钥），用来加密账号 API Key，并在 Worker 持有有效 Run 租约时提供本次执行所需的供应商凭据。
- **生成密钥**：本机运行 `vp run local:init`，把缺失的主密钥写入根 `.env.local`。Compose 部署从 `.env` 传给 Server。
- **备份**：单独保管并备份主密钥，升级时保持不变。只有数据库备份而没有原主密钥，无法恢复已保存的账号 API Key。
- **未配置主密钥时**：可以查看和删除配置，但不能新增、编辑或切换。
- **网络限制**：接口只允许公开 HTTPS 地址，保留 DNS、公网地址与重定向约束。
- **升级**：先备份并停止应用，再执行增量迁移。本机用 `vp run db:migrate`，Compose 见[部署指南](deployment.md)。迁移只新增供应商、独立用途和搜索配置表，不重置现有数据；已有的模型用途选择保持不变。
