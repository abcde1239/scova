# 工作流

在「工作流」页面用画布把整理、研究、生成文档等步骤串成固定流程。

## 功能概览

- 创建自定义画布，或从模板库选择模板。
- 拖动、连线、分组、撤销重做，也可在步骤列表中编辑。
- 保存草稿后试跑，确认无误再发布并正式运行。
- 上传 CSV 或 JSON 作为输入，下载 CSV、JSON 或 Markdown 成果。
- 导出草稿 JSON，用该文件创建副本。

## 使用预设模板

预设模板有「库存预警清单」和「项目周报」。以库存预警为例：

1. 打开「工作流」，在模板库选择「库存预警清单」，点「使用模板」。
2. 点「使用示例数据」填入两行 CSV 和库存阈值，也可上传自己的文件。
3. 点「运行模板」。
4. 在运行详情查看预警表并下载成果；勾选「发送站内通知」后，也可从通知进入成果。

## 编辑画布

- 支持拖动、连线、分组、撤销重做，也可在步骤列表中编辑。
- **并行组**：可能同时运行的研究节点需要绑定不同任务，或改为串行连接。并行组中的研究全部成功后，工作流才会进入下一阶段。
- **旧版工作流**：已有的串并行工作流可预览升级为画布，历史发布版本继续按原图运行。

## 试跑与发布

1. 保存草稿后可「试跑」。试跑时通知显示为预览，研究节点会跳过。
2. 发布前先保存修改，并处理画布提示的问题。
3. 发布后的正式运行使用已发布版本。

## 文件输入

| 项目       | 说明                                            |
| ---------- | ----------------------------------------------- |
| 格式       | UTF-8 CSV 或 JSON，适用于含表格整理节点的工作流 |
| 大小       | 单文件最多 256 KiB                              |
| JSON       | 用于筛选时须为对象数组                          |
| 自定义模板 | 也可公开 JSON 文件输入                          |

## 运行结果与下载

- 运行详情显示节点状态、输出和可下载的 CSV、JSON 或 Markdown。
- 表格交付为 JSON 时，单元格按文本导出；开始节点的 JSON 原文可直接交付为 `.json`。
- 站内通知可打开对应的运行或交付文件。

## 导出与导入

- 在详情页导出已保存的草稿 JSON。
- 在工作流列表用该文件创建副本。
- 研究节点引用账号下的任务，跨账号导入后需重新绑定任务才能发布。

## 常见问题

**无法发布？** 先保存修改，并处理画布提示的问题，例如并行的研究节点绑定了同一任务。

**试跑为什么没有研究结果？** 试跑会跳过研究节点，通知也只显示为预览。

**导入后不能发布？** 跨账号导入后，研究节点需重新绑定当前账号下的任务。
