# 报告

报告是研究任务的成果，带引用、可核对来源，还能继续提问、补充研究和导出。

## 功能概览

- **核对来源**：每条结论都能展开保存的原文片段和采集信息。
- **选择输出形式**：同一次研究可以生成简报、主题清单、对比表和研究报告。
- **查看变化**：定期追踪后，与上次比较新增和变化的内容。
- **对报告提问**：只依据这份报告已保存的资料连续追问，不联网。
- **补充研究**：据此补查新资料，或用已有资料改写成新版报告。
- **导出与打印**：导出 Markdown、JSON，或另存为 PDF。

## 打开报告

登录后打开报告页，查看当前账号可访问的报告。页首显示配置版本、服务模式和交付时间。

1. 宽屏：左侧是“对话与后续研究”，右侧是成果预览，预览在自己的区域内滚动。
2. 窄屏：先显示对话。点“成果”进入全屏阅读，用“返回对话”或 Esc 返回。
3. 点预览右上角“关闭成果预览”（×）关闭，再点对话里的成果卡重新打开。在输入框和下拉框中按 Esc 不会关闭预览。
4. 点“完整阅读”展开报告并隐藏对话，再点“返回研究对话”恢复。

切换视图不会丢失问题、笔记草稿、已展开的引用和当前成果选择，也不会发起研究。

成果预览按顺序展示：

1. **变化**：与上次比较的结果。
2. **成果正文**：标题、概述、结论。
3. **查阅范围**：已执行的查询、限制、覆盖缺口和耗尽的预算。“完整覆盖”只指本次计划范围，不表示查遍了互联网。
4. **来源与保存引用**：集中放在末尾。

演示报告会标明演示来源。反馈、笔记和收藏默认折叠；“执行详情”进入本报告所属的运行与日志，见[任务](./tasks.md)。

### 来源与引用怎么核对

- **点击引用**：正文里的引用会展开来源并定位到对应片段。
- **来源分组**：按网页和快照版本分组，同一网页只显示一次标题。网页按规范化地址归并，忽略片段和常见跟踪参数。
- **看原文**：展开来源查看保存的逐字片段，再展开“采集与定位信息”看原文位置、查阅时间和快照信息。
- **外链**：来源链接在新窗口打开，仅支持不带凭据的 HTTP/HTTPS 地址。
- **不重新抓取**：页面不会重新抓取网页。完整正文过期后，保存的引用仍可解释历史结论，但来源网页本身可能已变化。
- **日期**：发布时间和更新时间分别显示，保留各自精度；旧报告缺少时不猜测。
- **校验失败**：引用校验失败时，整份报告隐藏并提供重新读取入口，不展示部分结果。
- **边界**：章节结构和引用校验不等于独立事实核查。

### “部分完成”和“部分内容待补充”

“部分完成”表示这次执行没有走完整个计划，例如预算耗尽或部分来源没读到。报告页相应显示：

- 页首显示已整理的问题材料数，提示“部分内容待补充”，摘要和回答仍排在最前。
- 摘要后最多列出三条具体的未答项或分歧。
- 完整的待补充清单、查询和来源覆盖说明在末尾默认折叠的“查阅与核验详情”里。
- 待核实材料单独折叠并标注数量，不当作确定结论。

部分完成的报告不能证明资料没有变化，也不会显示“无重要变化”。

## 选择输出形式

一次研究可以同时生成多种形式，每种有自己的采集目标和写法。

1. 打开任务配置页，在输出形式里多选，至少选一种：简报、主题清单、对比表、研究报告。
2. 保存任务配置。
3. 立即执行沿用已保存的形式，执行区域不再临时选择；重试沿用原执行的设置。要增加形式，先修改并保存任务配置，再新建执行。

| 形式     | 适合               | 包含什么                                                                                   |
| -------- | ------------------ | ------------------------------------------------------------------------------------------ |
| 简报     | 快速拿到答案       | 核心答复和少量关键发现，证据充分时通常 3–5 点。必要条件紧邻发现，不凑数、不强加建议。      |
| 主题清单 | 知道“有哪些”       | 具名对象卡片，列出字段值、依据和缺口；未知字段明确标出。保留日期、条件和来源，不虚构条目。 |
| 对比表   | 在几个对象间做取舍 | 对象为列、共同维度为行，统一单位、时段和计费口径。缺失值不等于零或劣势，不无依据评选胜者。 |
| 研究报告 | 需要完整论证和背景 | 概述、必要背景、主题分析、结论与限制，用连贯段落，不虚构实验、样本或研究方法。             |

### 切换与阅读

- **已生成成果**：多份成果用该按钮切换，单份成果不显示选择器。切换只是阅读，不修改任务配置、不改变比较基线，也不启动研究。
- **记住选择**：在同一个页面内切换视图或阅读其他部分时保留选择，刷新页面后恢复默认。
- **页内导航**：“正文”“变化”“来源”与成果选择分开，点击后焦点移到对应标题。
- **目录**：研究报告有大纲时，目录链接章节和问题覆盖；点目录会展开所在折叠区并滚动到标题。

### 各形式的细节

- **简报与研究报告**：新报告可带章节大纲。条件和缺口留在对应段落旁，问题覆盖可展开查看。
- **主题清单**：字段一致、不超过六个且值简短时，宽屏用表格、窄屏用卡片，其余用卡片。表格单元格只放简短值，额外条件和缺口放在表下编号注释。
- **对比表**：只读，不会重新比较事实。表太宽时只在表内横向滚动，聚焦后可用左右方向键，Tab 进入引用。点击单元格引用可定位原文，表后可展开完整的问题依据与结论。没有历史变化，不代表对象之间没有差别。
- **资料采集清单**：显示“已采集条目”表，含值、发布或更新日期、日期来源和直接原文引用。日期筛选另列窗口、收录页数、日期未知页数和窗口外页数；选择剔除未知日期时不展示该来源列表。零条目时提示没有满足日期和出处要求的条目。

### 模型自答与统计

- **分析研究**：稳定知识可由模型直接回答，答案和表格单元格显示“模型自回答”。实时信息、精确数据、指定出处和真实冲突仍需要证据。
- **资料采集**：不使用模型自答。
- **统计**：报告页和执行页分别显示“回答完成”“外部证据支持”“仍未解决”。模型自答计入回答完成，不计入外部支持。切换成果时按该成果的必要字段重算。

旧报告没有对象结构时，会说明这一点并保留原问答，更早的报告按“来源事实 / Agent 推断 / 冲突证据 / 证据不足”分组。切换成果不能增加没生成过的形式。

## 查看变化与基线

给任务设定定期执行后（见[任务](./tasks.md)），每份成果正文前的“变化”区会说明本次与上次相比有什么不同。

- **比较状态**：最先显示。
- **新增、实质变化、待核验**：直接展开。
- **其他 N 项**：重复、疑似转载和非实质变化折叠在这里。
- **首次执行**：满足条件时显示“已设为比较起点”，不重复列出基线事实。
- **未达条件**：显示“未设为比较起点”和具体原因，例如字段只有模型回答、外部证据不足或日期未确认。

每一项怎么读：

- **旧值 → 新值**：旧值为空时只显示本次值。
- **引用分侧**：新旧两侧各自链接到自己的原文，不借用另一侧的证据。
- **待核验**：旧值存在但没有旧引用时显示待核验。
- **空值不等于删除**：没有值不表示被删除、撤回或没有变化。

基线规则：

- 只有全部必答字段都有外部支持，并通过完整性与比较检查，基线才会推进。模型自答不算外部支持。
- 只有查阅完整、没有待核验项且服务端判定“无重要变化”时，才显示“无重要变化”。部分完成或本次没看到某页，都不能证明资料没变。
- 有上次报告时，可点击链接跳转过去。

## 对报告提问

在报告页可以接着报告连续提问。回答只依据这份报告已保存的资料，不会联网。

1. 在输入框写下问题，问题最多 2000 个字符，保留原始空格和换行，纯空白不能提交。
2. 输入为空时，可点输入框上方的三条建议填入，再编辑。建议只来自报告已保存的内容，点选不会调用模型。
3. 提交后回答带当前报告的引用。成功后输入框清空，可直接追问。
4. 历史按轮显示问题、回答、引用和关联执行。选中一轮可看用量和后续操作。

收起对话时，草稿和未确认的请求会保留。问题内容不写入链接，未发送的草稿只留在当前页面。

### 限制

- **上下文**：最近最多 12 个完整问答，更早最多 16 轮的摘要，另有有限的报告内容和最多 24 条保存证据。输入有长度预算，不保证记住全部细节；久远或含糊的指代请写明具体内容。
- **历史回答**：只是讨论背景，不会成为新的事实证据。
- **引用**：事实摘录要求逐字匹配保存的原文，解释和归纳用自然语言并明确标识。逐字引用通过不代表已核查事实真伪。校验失败时不显示回答。
- **回答不足**：分为证据不足、未配置可用模型、模型失败、输出未通过核验、已中止。“需要更多资料”不表示已同意后续研究。
- **用量**：本次问答的模型调用和 token 单独记录，不计入原运行的预算。含估算或未知调用的预留会标注，不表示精确费用。

### 结果未确认时

- 网络错误、处理中或限流，不代表问题没有保存。点“读取本次结果”恢复，沿用同一个问题，不会自动重发。读取到的可能是已保存的“不足”结果，并不表示再次调用了模型。
- 服务给出等待时间时，界面会显示再次读取的时间。
- 放弃未知请求前，先复制需要保留的问题。再次独立提问可能另计用量。
- 切换报告、换账号或离开页面会中止请求，但不能撤销已经执行的模型调用。离开未提交或未知请求前会有确认。

### 刷新与历史

- 刷新后恢复最近 100 轮，点“查看更早的对话”继续向前翻。
- 链接可直接定位到某条回答，不会再次提问。
- 每份报告同时只处理一轮。另一个标签页已新增轮次时，先读取最新历史再提交。
- 报告暂时不可读时，本地问题和未确认请求保留供复制，回答和读写暂停。换账号或换报告会清除旧的编辑内容。

## 补充研究

需要新资料或换一种组织方式时，在已保存的回答下操作。两者都需要单独确认，普通提问、刷新、打开或取消确认都不会创建执行。

| 操作           | 数据来源                       | 联网 | 结果                                                 |
| -------------- | ------------------------------ | ---- | ---------------------------------------------------- |
| 用已有资料改写 | 原报告已保存的证据和对话上下文 | 否   | 在原有证据内重新组织。缺少所选形式所需材料时会说明。 |
| 据此补查新资料 | 联网搜索并读取新来源           | 是   | 补充新资料后生成新成果。                             |

输入区的“补查新资料”会把未提交的问题直接作为新研究目标。

1. 点“据此补查新资料”或“用已有资料改写”。
2. 在确认卡里核对原报告的任务、配置版本和模式，以及预算。补查沿用原执行预算，搜索和模型调用按实际用量计入。
3. 选择本次成果形式，不选则沿用原配置。
4. 确认（补查为“开始补查”）。

只有真实报告能新建执行，演示报告仅供讨论。

### 执行规则

- 研究目标改为问题原文，计划改为手动，沿用原版本、模式、预算和其他限制。
- 确认时会固定报告、历史问答和本轮问题，重试沿用这份快照。
- 原报告、原任务和周期计划都不变，后续比较和日常监控的基线不受影响。原证据的覆盖限制继续保留。

### 完成之后

- 对话历史里出现新成果入口，新版报告提供“返回原报告对话”，回到对应问题。原报告内容保持不变。
- 已有关联执行时会提供入口，可能指向进行中或已结束的运行。不会再创建第二个执行，也不会自动跳转抢占当前页面。

### 结果未知时

- 写入期间会阻止重复确认。
- 超时或网络错误时，页面保留冻结的问题、版本、模式和预算，不自动重试。
- 点“读取已保存关联”。有关联时到运行详情核对；没有关联也不能证明未创建，原请求会继续保留。
- 也可以用同一请求重发，不会生成重复执行。
- 报告暂时读不出来时，写入被禁用，未知请求保留。离开页面、换问题或刷新会丢失这份恢复记录，离开前会提示。
- 换账号或换报告会隔离迟到的响应。取消请求不保证服务端已回滚。

## 导出与打印

- **导出**：报告页提供“导出 Markdown”和“导出 JSON”。两种格式都包含摘要、覆盖缺口、结论、变化及引用片段；JSON 是带版本号的结构化文档。导出使用已交付的报告，无需重新运行研究。
- **导出文件限制**：暂存限制在当前账号内，有效期 24 小时，单份上限 256 KiB，账号总计最多 32 份。同一报告和格式在有效期内可复用。
- **打印**：成果面板的“打印 / 另存为 PDF”会打开浏览器打印，内容包含当前成果、变化和来源。

更多工作台操作见[工作台](./web-workbench.md)。

## 常见问题

**“完整覆盖”是查遍了互联网吗？** 不是，只指本次计划范围内的查询已执行完。

**没有“变化”内容，是不是资料没变？** 不一定。部分完成、有待核验项或本次没看到某页时，不会显示“无重要变化”。

**提问会联网吗？** 不会，只依据这份报告保存的资料。要联网请用“据此补查新资料”，并另行确认。

**提问的费用算在哪里？** 单独记录，不计入原运行预算。补查沿用原执行预算。

**点了提问或补查没有反应？** 先点“读取本次结果”或“读取已保存关联”，不要重复提交。

**缺少某种输出形式？** 先在任务配置里加上并保存，再新建执行。切换成果不会生成新形式。

**没有配置搜索或模型？** 见[Agent 配置](./agent-configuration.md)和[搜索配置](./search.md)；项目与对话见[项目](./projects.md)，工作流见[工作流](./workflows.md)，上传文件见[资料库](./library.md)。
