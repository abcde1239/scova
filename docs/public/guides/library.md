# 资料库、附件与通知

管理已保存的资料：搜索、收藏来源、写笔记、查看来源快照，并通过收件箱和站内通知跟进结果。

## 功能概览

- 搜索当前账号已保存的资料。搜索资料库不会联网研究。
- 收藏来源，写纯文本笔记。
- 查看已保存的来源快照及其历史。
- 在结果收件箱和站内通知里跟进新结果，已读状态独立管理。
- 对结果提交反馈，可撤销，已交付的效果会保留。
- 为报告上传、下载和删除附件。

## 搜索与整理资料

- **资料搜索**：只在当前账号已保存的资料中查找，不会联网研究。
- **来源收藏与笔记**：收藏来源，并为其写纯文本笔记。
- **来源快照与历史**：查看已保存的来源快照及其历史。

## 收件箱与通知

- 结果收件箱与站内通知的已读状态相互独立。
- 工作流勾选「发送站内通知」后，可从通知打开对应的运行或交付文件，见[工作流](./workflows.md)。
- 对结果提交的反馈可以撤销；已经交付的效果会保留。

## 报告附件

支持上传、下载和删除以下格式：CSV、TXT、Markdown、JSON、TSV、PDF、PNG、JPEG 和 WebP。

| 项目     | 说明                                        |
| -------- | ------------------------------------------- |
| 文本预览 | 256 KiB 以内的 UTF-8 文本可按原文行预览     |
| 原件下载 | 图片、PDF 和超过 256 KiB 的附件提供原件下载 |
| 大小上限 | 配置私有 R2/S3 存储后，单文件上限为 10 MiB  |

报告本身的阅读与导出见[报告](./reports.md)。

## 常见问题

**搜索资料库会联网吗？** 不会，只搜索当前账号已保存的资料。

**大文件无法预览？** 超过 256 KiB 的附件只提供原件下载。

**附件超过 256 KiB 还能上传吗？** 部署配置私有 R2/S3 存储后，单文件最多 10 MiB。
