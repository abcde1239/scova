# Web 工作台

在浏览器里创建研究任务、查看进度、阅读报告，并管理资料库和通知。登录使用同源 Cookie 会话。

当前支持浏览器访问；桌面客户端和完整的移动端适配暂未提供。

## 账号与界面

- **账号**：支持注册、登录、会话恢复和退出。账号偏好包括四色主题、浅色/深色/跟随系统，以及本地阅读设置。
- **模型配置**：每个账号独立保存多个模型供应商，可随时切换，见 [Agent 配置](agent-configuration.md)。
- **界面语言**：在登录页或工作台顶部切换「简体中文」或「English」，默认简体中文，选择只保存在当前浏览器。目前覆盖导航、页面标题、登录注册和连接状态，任务、报告等业务页面尚未完全翻译。切换语言不会修改账号或任务时区，不影响搜索语言，也不翻译报告和原文引文。

## 项目与会话

用项目把相关任务和对话放在一起。

- **从首页开始**：输入研究需求，选择已有项目、新建项目，或让工作台按项目名归类。匹配有歧义时会保留输入，请你选择。
- **管理会话**：在项目侧栏新建、改名和归档会话。
- **右侧面板**：可查看概览、成果、任务和设定。报告支持侧读和段落引用。
- **调整布局**：桌面端可拖动栏宽，也可用方向键调整；窄屏可打开抽屉。
- **独立任务**：不必归入项目，仍可直接创建并运行。要通过对话继续研究，请先选择项目。
- **起草研究**：空项目没有可查询的报告时，会话可能提供「起草研究」，用你的原消息准备计划，由你检查后决定是否启动。

### 自主度与自动启动

默认自主度保存在项目设定里，也可以在单轮输入中临时修改。

- **自动启动条件**：需要同时满足明确的启动意图、成功生成的草案，以及部署配置的账号额度。
- **未配置额度时**：部署没有设置 `PROJECT_AGENT_AUTO_RUNS_PER_DAY`，会话会先请你批准研究。
- **暂停或调整周期任务**：请在输入里引用目标任务。
- **撤销**：已应用的可逆动作提供撤销；任务之后被编辑过的，需要重新核对。

### 会话附件

支持上传 UTF-8 的 CSV、TXT、Markdown（`.md`、`.markdown`）、JSON、TSV，以及 PDF、PNG、JPEG（`.jpg`、`.jpeg`）和 WebP。单份最多 256 KiB，部署需配置私有对象存储。

- **文本附件**：会话先提供每份开头最多 1,200 字符。需要后续内容或精确行号时，助手可在本轮引用的附件里搜索关键词，或从指定行读取。
- **读取上限**：每轮最多请求三个片段，每个片段最多六行。回答引用片段时会显示文件名和行号。
- **PDF 和图片**：提供原件下载。

## 任务与执行

### 创建任务

有三种方式：

1. **自然语言草稿**：描述需求后点「生成任务草稿」，由需求整理 Agent 澄清并生成草稿。
2. **手动创建**：点「跳过 AI，手动创建」直接进入表单。
3. **编辑已有任务**：修改配置后保存，新版本只影响后续执行。

「确认保存任务」只创建任务；「保存并立即运行」还会排队执行一次。缺少可用模型时可以先保存，再按提示前往 Agent 配置。

### 用自然语言生成草稿

- **澄清问题**：根据原文和已有回答，动态确认搜索内容、来源、时间与交付形式。最多三轮，每轮最多三个问题；需求明确时可直接进入范围核对。
- **范围核对**：确认核心问题与排除内容、查阅时间与来源、研究方式和输出形式后，生成最终草稿。模型不能扩大你已确认的范围。
- **应用草稿**：草稿需要应用到表单并保存才会创建任务。
- **切换到手动**：会停止在途解析，保留原文和已有配置，并聚焦任务标题。
- **失败处理**：失败时保留当前输入，可重试或手动继续。模型不可用时会明确提示手动填写，不提供伪装成 AI 的固定问题。
- **额度**：问答和草稿生成使用独立的解析限流与 Token 预算，不计入研究预算。

### 填写任务表单

- **快速保存**：填完基础信息后，点「跳到保存」，按需要选择只保存或立即启动。
- **日期与时间**：固定日期用日历选择，执行当地时间用时分选择器，也可键盘输入。
- **预算**：点「查看预算说明」查看分配表和详细解释；预算输入和校验错误直接显示在表单里。
- **多项输入**：关注点、排除条件、优先来源网址和排除来源网址逐项填写，可独立添加、修改和删除。Enter 新增一项，文本项用 Shift+Enter 换行；逗号和项内换行不会自动拆项。每个链接单独校验。
- **输出形式预览**：在「输出形式」旁点击 ⓘ，可预览简报、主题清单、对比和研究报告的交付样例。样例是明确标注的虚构内容，预览不会修改表单，也不会创建任务。
- **执行 Agent 与搜索方式**：见 [Agent 配置](agent-configuration.md) 和[搜索服务配置](search.md)。

### 研究方式与输出形式

创建或编辑时选择「资料采集」或「分析研究」：

| 方式     | 适合                               | 时间窗口                                                            | 模型补答                         |
| -------- | ---------------------------------- | ------------------------------------------------------------------- | -------------------------------- |
| 资料采集 | 收录日期在窗口内、有原文出处的条目 | 默认近 7 天；日期未确认的来源默认单列且不计入结果，也可选择直接剔除 | 不使用模型补答                   |
| 分析研究 | 综合证据和推论                     | 可选择不限日期                                                      | 允许稳定知识以【模型自回答】交付 |

- **来源日期**：以来源发布时间为准；仅当它未知时才使用独立解析的更新时间。网页采集时间不能替代来源日期。
- **缺失与冲突**：两种方式都保留真实缺失项和来源冲突。
- **修改输出形式**：在任务配置编辑页修改并保存。立即执行沿用任务配置，重试保留原执行的形式。

### 搜索方式

任务配置可保存「搜索方式」：

- **Search API（搜索与网页读取）**：使用账号独立保存的 API 完成搜索和正文读取。
- **内置 SearXNG＋网页读取工具**：使用系统搜索服务并读取来源网页。
- **沿用账号搜索配置**：读取账号搜索区域的默认方式，不随执行模型变化。

立即执行默认沿用任务的搜索方式，也可只为本次执行覆盖。重试时若未覆盖，沿用原执行的搜索方式。缺少指定服务的配置会明确失败，不会自动切换。支持的来源格式见[搜索服务配置](search.md)。

### 执行与进度

- **启动与查看**：点击启动真实研究后，可查看执行历史、实时进度、覆盖缺口和预算，并随时取消或重试。关闭页面不会取消服务端的执行。
- **进度来源**：进度来自实际执行事件，停止、重试和详情都对应真实执行。
- **配置错误**：执行详情遇到模型或搜索配置错误时，会提供配置入口和重试入口。
- **自动进入报告**：正在查看的执行完成并取得报告后，自动进入报告工作区。失败、取消或尚未找到报告时，保留执行页。历史执行详情有独立入口，报告结果排在执行信息之前。

### 任务状态

- **已启用**：表示允许后续计划，不代表当前正在执行。
- **单次执行状态**：排队、运行、恢复、取消中，以及已完成、有结果、失败、已取消。
- **暂停**：只停止未来计划。
- **归档**：阻止新执行，并请求取消在途执行。

### 清除任务

任务详情的「任务管理 → 清除任务」会在弹窗确认后永久删除任务配置、执行历史、报告，以及关联的通知、报告笔记和问答。共享来源、网页快照和来源收藏会保留。

- **有活动执行**：须先取消并等待结束。归档的任务也可以清除。
- **只想停止计划**：用暂停或归档，历史会保留。

### 批量清除

在任务列表点「批量管理」多选并清除。

- **范围**：每批最多 50 个，仅限当前筛选下已加载的任务。加载更多不会自动选中，切换筛选会清空选择。
- **确认**：弹窗列出任务名称、数量和影响，需要输入「清除 N 个任务」。
- **保留的任务**：有活动执行或修订已变化的任务会保留。结果逐项展示，可能只完成部分清除。
- **网络结果不明**：会停止后续请求且不自动重发。点「刷新任务列表」核对后重新选择。

### 执行日志与错误

- **警告与错误**：单页拒绝访问、失效、限流、无法提取正文等可跳过的问题显示为警告；配置、安全校验、模型余额和最终执行失败显示为错误。
- **网页读取重试**：SearXNG 本地 Reader 对临时网络和网页服务端故障最多重试一次，共用原时间和累计读取预算；登录限制、验证码、404 和 429 不重试。Search API 远程读取默认单次调用，失败不切换到本地 Reader。
- **没有可交付内容**：执行失败。资料采集若只有已认证的日期筛选说明，仍可部分交付「0 收录」，这不表示互联网上没有相关资料。
- **模型错误**：分别显示 JSON 无效、报告结构不符、响应状态异常和拒绝生成。结构错误会在原修复次数和预算内重新生成。
- **部分交付**：两次综合均失败但已有可验证正文时，保留为「已保存来源资料」，各所选形式会明确显示不足，不计为完成研究。
- **用量计量**：失败响应有可信用量时按实际值计量；超时或无法确认用量时保留预算预留，日志标记「保守估算」，不表示供应商已确认扣费。
- **重试后的旧故障**：同一工具操作重试成功后，已恢复的旧故障只留说明，累计用量照常保留。

## 报告

### 阅读报告

- **四种形式**：同一份报告可有简报、主题清单、对比表和研究报告。工作台只展示实际保存的成果形式，切换阅读不会启动研究，也不会补生成其他形式。
- **切换形式**：保留外围笔记和问答上下文，刷新后以报告保存的形式打开。
- **证据与变化**：可查看证据引用、变化和报告历史。
- **图片**：目前来源图片没有媒体字段，缺图时保持纯文字。
- **界面布局**：宽屏左侧是连续对话，右侧是成果浮窗；窄屏先显示对话，点「成果」进入全屏阅读，用「返回对话」或 Escape 返回，草稿和滚动位置会保留。桌面浮窗点 × 关闭，「完整阅读」展开同一面板。

### 来源与引用

- **来源标签**：报告正文和结构化字段用小字号标签显示站点名，`+N` 表示还关联 N 个不同网页。打开标签可查看已保存的引用摘录、访问原网页或跳到文末原文定位，不会重新读取网页。
- **来源与保存引用**：文末保留完整的版本与引用。
- **发布与更新时间**：分别展示来源声明的发布时间和更新时间，可识别页面元信息、关联本文的结构化数据，以及明确标记的正文时间。只有日期或没有时区时保留原精度，不补造午夜 UTC；时间窗口边界无法确定时保留待确认。更新时间、网页采集时间和搜索摘要不替代发布时间。

### 回答完成与证据支持

报告和已结束的执行分别展示回答完成、外部证据支持和未解决项。

- **模型自回答**：分析研究允许稳定知识以【模型自回答】交付，不带引用，也不计入外部支持；资料采集不使用模型补答。
- **比较起点**：回答完成不代表已满足比较条件。新执行只有必答字段全部获得外部支持，并通过完整性与比较检查，才能推进比较起点。具体规则见[研究循环](../reference/agent-research-loop.md)。

### 报告内问答与补查

- **提问**：Enter 发送，Shift+Enter 换行。内容建议会填入草稿。
- **补查新资料**：对正式报告，从输入区选择「补查新资料」，核对问题、搜索方式、预算和成果形式后启动研究。可选内置搜索或已配置的账号 Search API。取消确认会保留草稿。
- **逐轮操作**：每轮回答下方可选「据此补查新资料」或「用已有资料改写」，在原位计划中选择成果形式、核对费用和预算后开始。搜索方式沿用原执行配置。
- **引用**：同一网页的引用集中在每轮回答末尾，可展开逐字引文和保存的定位。
- **结果不明时**：保留原请求标识，通过恢复入口确认，避免重复建立执行。
- **缺少远程模型**：报告问答会明确提示不足，不会自动改用演示数据。

### 续作与合并

- **独立成果**：补查和改写产出的都是独立报告，成果选择器会注明来源轮次。切换阅读成果时，讨论仍以原报告为上下文。
- **合并到原报告**：最多可选择 8 份同一对话的续作，用已保存证据生成新的合并报告。不联网，计入模型额度，原报告和续作都保留。
- **修改定期研究**：初次任务的配置、周期、时区和预算仍在任务页管理，报告页的「修改定期研究设置」直接进入原编辑页。

### 导出与打印

- **导出**：报告页提供「导出 Markdown」和「导出 JSON」。两种格式都包含摘要、覆盖缺口、结论、变化及引用片段；JSON 是带版本号的结构化文档。导出使用已交付的报告，无需重新运行研究。
- **导出文件限制**：暂存限制在当前账号内，有效期 24 小时，单份上限 256 KiB，账号总计最多 32 份。同一报告和格式在有效期内可复用。
- **打印**：成果面板的「打印 / 另存为 PDF」会打开浏览器打印，内容包含当前成果、变化和来源。

### 报告附件

支持上传、下载和删除 CSV、TXT、Markdown、JSON、TSV、PDF、PNG、JPEG 和 WebP。

- **预览**：256 KiB 以内的 UTF-8 文本可按原文行预览。
- **原件下载**：图片、PDF 和超过 256 KiB 的附件提供原件下载。
- **大小上限**：配置私有 R2/S3 存储后，单文件上限为 10 MiB。

## 工作流

在「工作流」页面创建自定义画布，或从模板库选择模板。

- **预设模板**：库存预警和项目周报。库存预警表单可点「使用示例数据」填入两行 CSV 和库存阈值，也可上传自己的文件。
- **画布编辑**：支持拖动、连线、分组、撤销重做，也可在步骤列表中编辑。
- **旧版工作流**：已有的串并行工作流可预览升级为画布，历史发布版本继续按原图运行。
- **试跑**：保存草稿后可试跑。试跑时通知显示为预览，研究节点会跳过。
- **发布**：先保存修改，并处理画布提示的问题。
- **正式运行**：使用已发布版本。运行详情显示节点状态、输出和可下载的 CSV 或 Markdown，站内通知可打开对应的运行或交付文件。

## 资料库与通知

- **结果收件箱与站内通知**：已读状态独立管理。
- **反馈**：可撤销，已交付的效果会保留。
- **来源收藏与笔记**：收藏来源，写纯文本笔记。
- **来源快照与历史**：查看已保存的来源快照及其历史。
- **资料搜索**：搜索当前账号已保存的资料。搜索资料库不会联网研究。

## 开发与预览

在仓库根目录运行：

```sh
vp install
vp run dev:frontend
```

- `vp run dev:frontend` 只启动 Vite；`vp run dev` 并行启动前端、Server 和 Worker。
- 开发时通过根 `.env.local` 的 `VITE_API_BASE_URL` 直连 API，并用 `APP_ORIGIN` 配置准确的前端来源。详见[本地开发](local-development.md)。
- API、Worker、数据库、Redis 与搜索配置见[部署指南](deployment.md)；完整同源部署使用 Compose。

常用检查与构建命令：

```sh
vp check
vp test
vp run build:frontend
vp run preview:frontend
vp run test:e2e tests/e2e/shell.spec.ts
```

- `vp run preview:frontend` 只预览现有静态产物，API 地址由构建时的 `VITE_API_BASE_URL` 决定。
- `vp run build:e2e` 生成含组件样例的 test 构建，同样写入 `apps/web/dist`；切回普通预览前先执行 `vp run build:frontend`。
- 根目录 `vp run build` 按依赖顺序构建整个 monorepo，`vp -C apps/web preview` 可显式指定前端工作区。
- 浏览器安装与隔离测试环境见[浏览器测试](../reference/browser-testing.md)。
- 目录、Vue 与通信约定见[前端约定](../reference/frontend-conventions.md)。
