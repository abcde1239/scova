# 工作台概览

在浏览器里创建研究任务、查看进度、阅读报告，并管理项目、工作流、资料库和通知。登录使用同源 Cookie 会话。

当前支持浏览器访问；桌面客户端和完整的移动端适配暂未提供。

## 账号与界面

- **账号**：支持注册、登录、会话恢复和退出。
- **主题**：账号偏好包括四色主题，以及浅色、深色或跟随系统。
- **阅读设置**：保存在本地。
- **模型配置**：每个账号独立保存多个模型供应商，可随时切换，见 [Agent 配置](agent-configuration.md)。
- **界面语言**：在登录页或工作台顶部切换「简体中文」或「English」，默认简体中文，选择只保存在当前浏览器。目前覆盖导航、页面标题、登录注册和连接状态，任务、报告等业务页面尚未完全翻译。切换语言不会修改账号或任务时区，不影响搜索语言，也不翻译报告和原文引文。
