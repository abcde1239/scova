# 项目与对话

用项目把相关任务和对话放在一起，在对话里让助手起草研究计划，确认后运行，并引用报告、来源段落或上传的文件继续研究。

## 功能概览

- 把相关任务和会话归入同一个项目，集中查看概览、成果、任务和设定。
- 在首页输入需求，由工作台按项目名归类，有歧义时由用户选择。
- 让助手起草研究计划，检查后再决定是否启动。
- 按自主度控制助手是否可以自动启动研究。
- 引用报告、来源段落和上传的文件继续对话。
- 通过对话提议暂停或调整周期任务，并可撤销已应用的动作。

任务本身的创建与执行见[任务](./tasks.md)，报告阅读见[报告](./reports.md)。

## 从首页开始

1. 在首页输入研究需求。
2. 选择已有项目、新建项目，或让工作台按项目名归类。
3. 如果匹配有歧义，工作台会保留输入，并提示选择目标项目。

不必归入项目也可以直接创建并运行独立任务。要通过对话继续研究，请先选择项目。

## 管理会话

- 在项目侧栏新建、改名和归档会话。
- 右侧面板可查看概览、成果、任务和设定。报告支持侧读和段落引用。
- 桌面端可拖动栏宽，也可用方向键调整；窄屏可打开抽屉。

## 起草研究并确认运行

空项目没有可查询的报告时，会话可能提供「起草研究」。

1. 在会话里发送研究需求，或使用「起草研究」。
2. 助手用原消息准备研究计划草案。
3. 检查草案，确认后再启动研究。

## 自主度与自动启动

默认自主度保存在项目设定里，也可以在单轮输入中临时修改，只影响该轮。

自动启动需要同时满足三个条件：明确的启动意图、成功生成的草案，以及部署配置的账号额度。

| 情况                                           | 结果                           |
| ---------------------------------------------- | ------------------------------ |
| 三个条件都满足                                 | 可自动启动                     |
| 部署没有设置 `PROJECT_AGENT_AUTO_RUNS_PER_DAY` | 会话先请求批准研究，不自动启动 |

## 引用报告、来源与附件

在输入里引用报告、来源段落或会话附件，助手会基于这些内容继续工作。要暂停或调整周期任务，请在输入里引用目标任务。

## 周期任务提议与撤销

- 助手可对周期任务提出暂停或调整的提议。
- 已应用的可逆动作提供「撤销」。
- 任务在动作之后被编辑过的，需要重新核对后再处理。

## 会话附件

| 项目     | 说明                                                         |
| -------- | ------------------------------------------------------------ |
| 文本格式 | UTF-8 的 CSV、TXT、Markdown（`.md`、`.markdown`）、JSON、TSV |
| 其他格式 | PDF、PNG、JPEG（`.jpg`、`.jpeg`）、WebP                      |
| 大小     | 单份最多 256 KiB                                             |
| 存储     | 部署需配置私有对象存储                                       |

读取方式：

- **文本附件**：会话先提供每份开头最多 1,200 字符。需要后续内容或精确行号时，助手可在本轮引用的附件里搜索关键词，或从指定行读取。
- **读取上限**：每轮最多请求三个片段，每个片段最多六行。回答引用片段时会显示文件名和行号。
- **PDF 和图片**：提供原件下载。

## 常见问题

**为什么没有自动启动研究？** 需要同时满足明确的启动意图、成功生成的草案和部署配置的账号额度。未设置 `PROJECT_AGENT_AUTO_RUNS_PER_DAY` 时，会先请求批准。

**为什么助手没读到附件后面的内容？** 默认只提供开头 1,200 字符，请让助手搜索关键词或指定行号；每轮最多三个片段、每片段最多六行。

**撤销不可用？** 任务在动作应用后被编辑过时，需要重新核对。
