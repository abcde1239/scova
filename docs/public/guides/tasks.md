# 任务与执行

任务是 Scova 的基本工作单位：描述想查阅的主题，设定执行方式，之后由系统搜索、阅读、查证并生成带引用的报告。

[创建任务](#创建任务) · [设置执行计划](#设置执行计划) · [运行与查看进度](#运行与查看进度) · [管理任务](#管理任务)

首次使用可以直接选择「手动填写」，填写标题、查阅主题和查阅目标，再点击「保存并立即运行」。研究开始前需要配置[模型](agent-configuration.md)和[搜索](search.md)。

## 创建任务

在「任务」页点「新建任务」。可以选择「用 AI 整理需求」，也可以点「手动填写」（或「跳过 AI，手动创建」）直接填写表单。

### 用 AI 整理需求

1. 在「需求描述」输入想研究的内容，最多 2000 字，且不超过 8000 UTF-8 字节，原文不会被自动修剪。
2. 在「需求时区」选择用来理解描述中时间的时区，默认沿用当前任务时区。
3. 点「生成任务草稿」。助手可能先提出需要澄清的问题，核对搜索范围与交付形式后再生成草稿；解析中可点「停止解析」。
4. 检查结果区：原文、解析模式、警告、建议计划与预算。
5. 确认无误后点「应用草稿并替换当前配置」，建议才会填入可编辑的表单。
6. 检查全部字段，再点保存。原文随最终任务配置保存。

要点：

- **只是整理**：生成和应用草稿都不保存任务、不安排执行、不启动研究。
- **手工模式**：结果显示「manual」表示待手工编辑，不是演示研究。
- **用量独立**：解析用量单独统计，不计入执行预算。
- **旧结果失效**：解析期间或结果返回后，如果修改了原文、需求时区或表单，旧结果不会覆盖新内容。可以重新解析，或继续手填。
- **出错时**：缺少模型时返回可编辑的手工草稿；限流、超时或结果不合法时保留原文与表单，解析请求不会自动重发。
- **离开页面**：草稿不保留。换账号或离开页面会终止请求，迟到的结果不会应用到新账号。

### 手动填写

1. 填写「任务标题」「查阅主题」「查阅目标」。
2. 在「任务类型」选择研究方式，再设置查阅时间范围和输出形式。
3. 按需展开填写「重点关注」「排除主题或条件」「优先来源网址」「排除来源网址」，每项一行。
4. 查看并按需修改「单次执行预算」「任务时区」和「站内提醒」。
5. 在「执行计划」选择执行方式，见下文[设置执行计划](#设置执行计划)。默认是「仅手动」。
6. 点「确认保存任务」只创建任务，进入任务摘要；点「保存并立即运行」创建后马上开始一次研究，进入执行详情。

### 任务类型

| 类型     | 日期范围          | 回答依据                                                           |
| -------- | ----------------- | ------------------------------------------------------------------ |
| 资料采集 | 必填，默认近 7 天 | 只收录窗口内、有直接原文出处的值，不用模型补答                     |
| 分析研究 | 可选「不限日期」  | 允许带【模型自回答】标签的稳定知识回答；回答完成与外部支持分别统计 |

- 资料采集中，日期未知的来源可选「单列展示，不计入采集结果」或「直接剔除」。
- 切换任务类型会设置对应的默认输出形式，之后仍可修改。读取已有配置或应用 AI 草稿时，会保留其明确选择。
- 查阅时间范围可选「滚动范围」（向前查阅天数）或「固定范围」（开始时间、结束时间）。固定范围按界面标明的浏览器当地时区填写，提交时转换为 UTC。

### 字段与默认值

| 字段                | 说明                          | 默认值       |
| ------------------- | ----------------------------- | ------------ |
| 搜索次数上限        | 正整数                        | 10           |
| 网页读取次数上限    | 正整数                        | 20           |
| 执行时长上限（秒）  | 正整数                        | 600          |
| 累计输入 token 上限 | 正整数                        | 1,000,000    |
| 累计输出 token 上限 | 正整数                        | 128,000      |
| 任务时区            | IANA 时区，可按城市或名称搜索 | 当前任务时区 |

- **预算**：必须是正整数，并受部署策略限制。默认部署允许保存的上限为：搜索 10 次、网页读取 20 次、时长 1800 秒、输入 2,000,000 token、输出 512,000 token。预算只对新建的执行生效，已开始的执行沿用自己的快照。
- **来源网址**：只接受不含用户名和密码的 HTTP/HTTPS 链接。来源偏好不代表已做安全检查或官方身份认证。
- **任务时区**：独立的 IANA 时区配置，与查阅时间范围使用的浏览器时区无关。

### 保存与出错

- 字段有错时，所在分组自动展开并聚焦。保存明确失败时，已填内容保留。
- 有未保存内容时，离开或关闭页面会提醒；保存进行中无法离开当前页面。取消离开可继续填写，实际离开后草稿不保留。
- 退出或换账号会清理旧内容并取消旧请求。
- 每次保存只提交一次，重复点击不会重复创建。网络中断、服务端出错或响应无法确认时，表单保留原内容，可点「重试同一次提交」，或回到列表核对。

### 编辑已有任务

1. 在任务摘要点「编辑任务配置」。
2. 修改后保存。每日或每周计划可调整频率、当地时刻和星期，未修改的计划保持不变。
3. 保存成功后停留在编辑页，并显示基线提示。点「返回任务摘要」回到原任务。

- 未编辑的字段保持原样。固定日期只在实际修改时才转换时区，未改的日期保留原始精度。
- 配置无法识别或版本不一致时，页面会阻止编辑，避免丢失字段。
- 查阅范围的语义发生变化后，下一次完整执行会建立新基线。
- 保存不会启动执行，也不会改写旧执行或报告。
- 有未保存修改时，离开、关闭或切换任务会提醒；保存进行中无法离开当前页面。

**编辑冲突**：别处已修改同一任务时，草稿仍可复制，但不能直接重发。

1. 先复制需要手动合并的内容。
2. 点「重新读取最新版本」。
3. 点「确认丢弃草稿并重新读取」。

取消或重新读取失败时，原草稿保留。网络中断或保存结果不确定时，同样需要先重新读取核对。保存不会自动重试。

### 项目归类与继续研究

任务摘要显示任务当前归属的项目。可以归入已有项目、归类时新建项目、换项目或取消归类。归类只改变项目与任务的关系，任务的配置、计划、执行历史和报告仍可从任务入口访问。

- 点「继续对话研究」：已归类的任务打开所属项目的对话；未归类的任务先选择已有项目或新建项目，确认后进入对话。
- 也可以在项目详情的「研究任务」点「新建任务」，使用同一份表单创建并关联任务。

详见[项目](./projects.md)。

## 设置执行计划

创建和编辑任务时，在「执行计划」的「计划频率」选择执行方式：

| 选项   | 需要填写                                         | 效果               |
| ------ | ------------------------------------------------ | ------------------ |
| 仅手动 | 无                                               | 不自动定时执行     |
| 每日   | 「任务时区」、「执行当地时间」（HH:mm）          | 每天按当地时间执行 |
| 每周   | 「任务时区」、「执行当地时间」、「每周执行星期」 | 每周按当地时间执行 |

星期以数字表示：周一为 1，周日为 7。站内提醒沿用表单原有配置，不影响执行频率。

### 查看计划

- **未保存预览**：只解释当前填写的计划，不推算下次执行时间。
- **已保存的计划**：显示最近保存或重新读取的配置、时区和下次执行时间，分别以任务当地时间和 UTC 展示。修改草稿时，旧的下次执行时间不会被当作新计划。
- 未修改的字段保留原有的精确时间、数组条目和预算，只有改过的字段才会按表单重建。
- AI 草稿的周期建议应用后同样显示在「执行计划」中，可以继续调整或改回「仅手动」；之后的编辑不会被解析建议覆盖。

### 夏令时

- **当地时刻不存在**：顺延到第一个有效时刻。
- **当地时刻出现两次**：只在第一次执行，跳过第二次。

以 America/New_York 为例（仅说明规则，不是对具体任务的预测）：

- 2026-03-08 的 02:30 顺延到 03:00（07:00Z）。
- 2026-11-01 的 01:30 选第一次（05:30Z），跳过第二次 01:30。

### 注意

- 所有新的定时执行都是真实研究，会调用已配置的搜索与模型，可能产生服务费用。缺少必要配置时明确失败，配置方法见[Agent 配置](./agent-configuration.md)和[搜索配置](./search.md)。
- 创建或修改计划不会立即启动执行。
- 项目概览会显示整个项目中最早的已启用周期计划，以及近期执行和报告。

## 运行与查看进度

### 立即运行

在任务摘要点「立即执行」，只在点击时提交。归档任务不能启动执行。执行完成后可在[报告](./reports.md)中查看结果。

操作成功后，页面显示返回执行的实际模式与状态，并提供「查看执行」入口。已有活动执行，或同一命令被重放时，可能复用既有执行，实际模式、版本和关联关系以页面显示为准。

### 取消执行

在执行详情点「请求取消」。

- 取消只影响本次执行，不暂停任务的未来计划。
- 显示「正在取消」时，后台仍在停止在途工作，最终结果以执行快照为准。
- 取消与完成同时发生时，执行可能已经结束。

### 重试

只有失败或已取消的执行可以点「重试并创建新执行」。

- 重试沿用原任务版本与预算，创建一个关联的新执行，同样是真实研究。
- 想用任务的最新配置（包括修改后的预算），请回到任务摘要点「立即执行」。

### 网络结果不确定

可点「使用同一命令重发」，写操作不会自动重发。

- 立即执行与重试：重发沿用原请求，不会重复创建。
- 取消：只重新确认同一执行的取消结果。
- 内容冲突：该操作停止，不会换标识绕过。

重发记录只保留在当前页面，离开、刷新或切换账号后清除。

## 管理任务

### 任务中心

「任务」页列出当前账号的任务。

- 点标题进入只读的任务摘要，查看当前配置的主题与目标。从摘要返回时保留状态筛选。
- 任务卡的**最近执行**显示排队时间和状态，没有执行时显示「尚无执行」；读取失败可单独重试。
- **下次执行**取自任务计划，没有时显示「未安排」。时间按当前浏览器时区显示，摘要另显示任务配置的时区。
- 任务卡提供报告历史入口，列表提供新建任务入口。

任务摘要提供：编辑任务配置、执行历史、立即执行、「任务管理」、项目归类和「继续对话研究」。

### 筛选与加载

「任务状态」筛选项有「已启用」「暂停」「归档」「全部」。

- 筛选只作用于已加载的任务，界面会标明这一范围。
- 每个筛选有各自的分页，每次最多加载 20 项，重复任务自动合并。
- 已加载的任务没有匹配项、但还有后页时，可继续加载。这不代表账号下没有任务，也不会自动扫描全部任务。
- 切换筛选会取消旧的加载。
- 退出或换账号会取消进行中的加载并清空缓存，旧账号或旧筛选的迟到结果不会替换当前列表。

### 暂停、恢复与归档

在任务摘要的「任务管理」管理任务的未来计划。打开时会先重新读取任务当前状态，再允许操作。写操作不会自动重发。仅手动执行的任务没有周期计划。

| 操作         | 效果                                                                                                                                     |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------------- |
| 暂停未来计划 | 停止后续周期触发。在途执行继续，仍可手动执行                                                                                             |
| 恢复未来计划 | 按当前时间重新安排未来时点，不补跑暂停期间错过的时点                                                                                     |
| 归档任务     | 需要确认（「确认归档」）。停止未来计划、阻止新执行，并对活动执行请求取消；请求取消不等于已停止。保留配置版本、报告与历史，但任务不能恢复 |

归档确认框点「取消」或按 Esc 会回到归档按钮，不提交操作。

**冲突或结果不确定**：遇到冲突、缺少版本信息或网络结果不确定时，操作保持锁定。

1. 点「刷新任务状态」，等待读取完成。
2. 根据最新状态重新选择操作。

刷新不会重发原操作，也不会因后台数据变化自动解锁。

### 永久清除

在「任务管理」点「清除任务」，确认框点「确认永久清除」。

- 将永久删除任务及其配置版本、执行历史、报告、通知、报告笔记和问答，无法恢复。
- 共享来源、网页快照和来源收藏保留。
- 仍有活动执行时，请先取消并等待结束后再清除。

### 批量清除

在任务列表点「批量管理」，勾选任务后点「清除所选任务」，再点「确认永久清除」。

- 只能选择当前筛选下已加载的任务，每批最多 50 个；加载更多不会自动选中。
- 任务逐项清除，可能只完成其中一部分。遇到结果不明的请求会停止后续清除，请刷新列表核对。
- 有活动执行或已变化的任务不会被清除。「已启用」不代表正在执行，清除时会检查活动执行。

## 常见问题

**生成草稿会开始研究吗？** 草稿只整理需求。确认保存任务之后，才能单独发起研究，或在保存时选择立即运行。

**生成草稿会消耗模型用量吗？** 配置了可用的解析模型时，生成草稿会调用该模型。解析用量单独记录，供应商可能按其规则计费。这部分用量独立于任务执行预算。

**创建了每日或每周计划，会马上执行吗？** 不会。创建或修改计划都不会立即启动执行，到计划时间才会执行。

**暂停之后，错过的执行会补跑吗？** 不会。恢复后按当前时间重新安排未来时点。

**取消后，任务的未来计划还在吗？** 还在。取消只影响本次执行。

**重试和「立即执行」有什么区别？** 重试沿用旧执行的任务版本与预算；「立即执行」使用任务的最新配置。

**归档后能恢复吗？** 不能。归档保留配置、报告与历史，但任务不能恢复，也不能再启动执行。

**列表里没看到任务？** 筛选只作用于已加载的任务，试试继续加载，或切换到「全部」。

**还想了解什么？** 固定流程见[工作流](./workflows.md)，资料管理见[资料库](./library.md)，界面总览见[Web 工作台](./web-workbench.md)。
