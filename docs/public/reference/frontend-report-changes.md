# 变化与基线

每份成果正文前都有“变化”区，告诉你这次和上次比有什么不同。

## 你会看到什么

- **比较状态**：最先显示。
- **新增、实质变化、待核验**：直接展开。
- **其他 N 项**：重复、疑似转载和非实质变化折叠在这里。
- **首次执行**：满足条件时显示“已设为比较起点”，不重复列出基线事实。
- **未达条件**：显示“未设为比较起点”和具体原因，例如字段只有模型回答、外部证据不足或日期未确认。

## 每一项怎么读

- **旧值 → 新值**：旧值为空时只显示本次值。
- **引用分侧**：新旧两侧各自链接到自己的原文，不借用另一侧的证据。
- **待核验**：旧值存在但没有旧引用时，显示待核验。
- **空值不等于删除**：没有值不表示被删除、撤回或没有变化。

## 基线规则

- 只有全部必答字段都有外部支持，并通过完整性与比较检查，基线才会推进。模型自答不算外部支持。
- 有上次报告时可点击链接跳转。
- 只有服务端判定“无重要变化”，且查阅完整、没有待核验项时，才显示“无重要变化”。部分交付或本次没看到某页，都不能证明资料没变。
- 引用校验失败时，整份报告隐藏并提供重新读取入口，不展示部分结果。
