# 报告变化与基线

报告中的“变化与基线”面板展示当前模式、关联基线执行标识和后端提供的逐项记录：基线、新增、实质变化、重复、疑似转载、非实质变化、待核验。每项保留事实键、重要性标记和原因，旧值与本次观测分别展示对应引用，可展开追溯原文。

变化分类与重要性沿用报告，不由页面重算。只有服务端给出 `no_important_change`，且查阅完整、没有重要项或待核验/旧值证据不足时，页面才呈现本次范围内未发现重要变化。查阅不完整、比较未知或旧证据不足会明确提示结论不确定，不修改原有分类。一次未观测到不等于资料已撤回，正文指纹变化本身不等于重要事实变化。

报告未给出基线执行时，页面只说明没有关联标识，不猜测是否首次查阅或模式/范围改变。内部比较清单不属于公开 DTO，页面不额外请求或暴露它，也不推进基线。现有原因和覆盖缺口保留在报告中。

引用的账号、模式、范围、旧新侧和快照归属由报告 API 校验。页面仅消费已授权的 `oldEvidenceIds`、`newEvidenceIds` 和证据对象，不能独立验证隐藏的存储关系。API 返回 `409 INVALID_REPORT_EVIDENCE` 时，整份报告隐藏并提供重新读取入口；不会展示部分失败引用或跨侧回退。

旧新值在宽屏并列，空间不足时自然堆叠；正文与标题使用阅读字体，引用工具和元信息使用界面字体。页面不重新抓取来源网页。
