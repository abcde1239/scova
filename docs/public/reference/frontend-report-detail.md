# 报告阅读

登录后打开报告页，查看当前账号可访问的报告。页首保留配置版本、服务模式和交付时间。

## 页面布局

- **宽屏**：左侧是“对话与后续研究”，右侧是纸页式成果预览，预览在自己的区域内滚动。
- **窄屏**：先显示对话。点“成果”进入全屏阅读，用“返回对话”或 Esc 返回。
- **关闭与重开**：点成果右上角 × 关闭预览，再点对话里的成果卡重新打开。在输入框和下拉框中按 Esc 不会关闭预览。
- **完整阅读**：展开报告并隐藏对话。点“返回研究对话”恢复提问位置。
- **切换不丢内容**：问题、笔记草稿、已展开的引用和当前成果选择都会保留，切换视图不会发起研究。

## 成果预览

按顺序展示：

1. **变化**：与上次比较的结果，见[变化与基线](frontend-report-changes.md)。
2. **成果正文**：标题、概述、结论。
3. **查阅范围**：已执行的查询、限制、覆盖缺口和耗尽的预算。“完整覆盖”只指本次计划范围，不表示查遍了互联网。
4. **来源与保存引用**：集中放在末尾。

多份成果通过“已生成成果”按钮切换，每份成果有自己的结论和引用。演示报告会标明演示来源。可选的输出形式见[输出形式](frontend-report-formats.md)。

## 引用与来源

- **点击引用**：正文里的引用会展开来源并定位到对应片段。
- **来源分组**：按网页和快照版本分组，同一网页只显示一次标题。
- **展开查看**：展开来源看保存的逐字片段，再展开“采集与定位信息”看原文位置、查阅时间和快照信息。
- **外链**：来源链接在新窗口打开，仅支持不带凭据的 HTTP/HTTPS 地址。
- **不重新抓取**：页面不会重新抓取网页。完整正文过期后，保存的引用仍可解释历史结论，但来源网页本身可能已变化。

## 待补充内容

- 页首显示已整理的问题材料数。
- 缺少依据时提示“部分内容待补充”，摘要和回答仍排在最前。
- 摘要后最多列出三条具体的未答项或分歧。
- 完整的待补充清单、查询和来源覆盖说明放在末尾默认折叠的“查阅与核验详情”。
- 待核实材料单独折叠并标注数量，不当作确定结论。
- 引用分别显示发布时间和更新时间。日期、无时区时间和精确时刻保留各自精度，旧报告缺少时不猜测。

## 其他

- 反馈、笔记和收藏默认折叠。
- “执行详情”进入本报告所属的运行与日志。
- 阅读外观入口连接当前浏览器的字体与字号设置。
