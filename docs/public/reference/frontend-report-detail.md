# 阅读报告与原文引用

登录后通过 `/reports/:reportId` 查看当前账号可访问的报告。基础简报展示概述、来源事实、Agent 推断、冲突证据与证据不足；报告使用的配置版本标识、服务模式和交付时间保留在页首。

报告优先展示标题、概述和正文结论，再展示查阅范围与来源，问答、反馈、笔记与收藏集中在正文后的“阅读后继续”。查阅范围包含已执行查询、限制、覆盖缺口及耗尽预算；完整覆盖指本次计划范围，不表示穷尽互联网资料。演示报告明确标示演示来源。报告详情可在简报、主题清单、对比表与研究报告间切换，同一报告的结论、变化和来源保持一致；当前阅读形式不保存，刷新恢复报告保存的形式，详见[报告形式](frontend-report-formats.md)。增量、历史、反馈、资料操作与报告内问答分别保留各自入口。

在结论下展开引用，可查看保存的逐字片段、原文定位、查阅时间及可用的快照信息。来源链接在新窗口打开，仅允许无凭据的 HTTP/HTTPS 地址；页面不重新抓取网页，也不把来源文本作为 HTML 执行。完整采集正文过期后，保存的引用仍可用于解释历史结论；来源网页本身可能已变化。

页首区分“核心问题已回答”“已生成部分答案”“已保存来源资料”，并展示已回答问题数。分类依据报告中直接相关且有引用支撑的答案，允许条件和分歧，不代表独立事实认证，也不等于连续比较覆盖完整。引用分别展示发布时间与更新时间；日期、无时区时间和精确时刻保留各自精度，冲突与未知状态明确标示。旧报告缺少这些字段时保留原有展示，不猜测来源时间。

阅读宽度上限为 45rem，字号、间距、圆角和控件最小尺寸以 rem 为主，容器可随可用空间收缩。正文与标题消费既有阅读字体，操作和证据工具采用界面字体。阅读外观入口连接当前浏览器的字体与字号设置。
