# 阅读报告与原文引用

登录后通过 `/reports/:reportId` 查看当前账号可访问的报告。基础简报展示概述、来源事实、Agent 推断、冲突证据与证据不足；报告使用的配置版本标识、服务模式和交付时间保留在页首。

报告页以“对话与后续研究”承接已保存资料的追问。宽屏左侧为对话，右侧为带工具栏的纸页式成果预览，预览在可视高度内独立滚动；窄屏按对话、成果顺序排列。成果预览右上角 × 可关闭面板，点击对话中的成果卡重新打开；键盘 Escape 可关闭预览并将焦点还给成果卡，在输入框和下拉框中不触发关闭。“完整阅读”展开报告并隐藏对话，“返回研究对话”恢复提问位置。切换视图保留问题、笔记草稿、引用展开和当前成果选择，不触发研究请求；换账号或报告时按会话身份隔离。面板开关使用 220ms 淡入和位移动画，减少动态效果设置下关闭动画，所有文本框禁止手动拖动调整尺寸。

成果预览包含标题、概述、结论、查阅范围与来源，下方保留历史变化与比较基线。查阅范围包含已执行查询、限制、覆盖缺口及耗尽预算；完整覆盖指本次计划范围，不表示穷尽互联网资料。演示报告明确标示演示来源。任务配置与执行前可多选输出形式，各形式按独立目标采集并生成。报告详情只允许切换实际保存的成果，每份成果展示自己的结论和引用；单份成果及旧报告不提供任意形式转换，详见[输出形式与成果](frontend-report-formats.md)。

报告内问答保存有序历史，刷新恢复后可继续追问；模型结合有界历史及原报告，只使用已有证据。可明确确认“生成新版报告”（保存证据内重组）或“后续研究”（联网补充），选择本次成果形式并核对原配置版本与预算。新成果独立保存并关联原对话，原报告及任务周期配置保留。详见[连续对话](frontend-report-questions.md)与[报告修订及后续研究](frontend-followup.md)。反馈、笔记和收藏默认折叠；“执行详情”连接本报告所属的独立运行与日志。

结论与历史变化通过引用链接指向统一来源附录，原文在同页集中展示一次。附录按网页与快照版本分组，同组只显示一次来源标题；相同快照内的重复原文共用展示并保留所有引用锚点。展开来源可查看保存的逐字片段，再展开“采集与定位信息”查看原文定位、查阅时间及可用的快照信息。点击正文引用会展开来源并定位到对应片段。来源链接在新窗口打开，仅允许无凭据的 HTTP/HTTPS 地址；页面不重新抓取网页，也不把来源文本作为 HTML 执行。完整采集正文过期后，保存的引用仍可用于解释历史结论；来源网页本身可能已变化。

页首展示已整理问题材料数；所需对象、字段或结论仍缺少依据时明确提示“部分内容待补充”，摘要与回答优先展示。摘要后保留最多三条具体未答项或分歧链接，完整待补充清单、查询和来源覆盖说明集中在末尾默认折叠的“查阅与核验详情”，重复说明按文本合并；待核实材料另有可展开入口与数量，不能作为确定摘要。影响结论的条件与未知字段仍就近可见。此展示投影不修改报告数据或完整性状态。新报告按保存的必需对象与字段覆盖判断完整回答，旧报告不凭空补齐对象。这些状态不代表独立事实认证，也不等于连续比较覆盖完整。引用分别展示发布时间与更新时间；日期、无时区时间和精确时刻保留各自精度，冲突与未知状态明确标示。旧报告缺少这些字段时不猜测来源时间。

完整阅读面板宽度上限为 68rem，预览随可用空间收缩。字号、间距、圆角和控件最小尺寸以 rem 为主。正文与标题消费既有阅读字体，操作和证据工具采用界面字体。阅读外观入口连接当前浏览器的字体与字号设置。
