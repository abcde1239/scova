# 来源历史与保存片段

资料库收藏和报告来源可进入来源历史；报告中的快照链接定位其实际 sourceId 与 snapshotId，无需先收藏。取消收藏不删除来源、快照或引用。

历史每行代表一份快照及其最近一次成功观测，不是逐次观测流水。同一正文与提取版本再次观测，可能更新该行的观测时间、执行和地址。来源发布时间与观测时间分别展示；快照 hash 标识保存正文，不表示时间或来源真实性认证。

列表按不透明游标分页，每页20条。分页位置失效或内容重复时可从第一页重新读取；不会自动扫描全部历史。未选择快照时只读取列表。非法来源或快照标识不发请求；切换目标、换号和卸载取消旧请求。

详情展示保留期内纯文本正文、采集信息和保存片段，不解析 HTML 或 Markdown，不自动访问外站。正文到达已知期限后从页面撤下，保存片段、hash 和字符定位仍可阅读。片段的字符范围按 UTF-16，起点包含、终点不含。最多返回100条片段；有更多片段时明确提示，当前没有片段分页接口。

正文期限以服务端响应为权威。页面根据本地时间、响应接收后的单调经过时间，以及可选且严格有效的 HTTP Date 辅助值保守隐藏到期正文；Date不是必需字段，也不虚构 serverNow。缺少可靠服务器时基时，不保证任意客户端与数据库时钟偏差下同时到期。重新打开已过已知期限的缓存也不展示全文；重新读取失败时不回退旧全文。权限、结构或完整性失败隐藏详情，实际重读成功后才能再次展示。

快照和每条片段都提供各自真实 runId 的“查看该次执行”入口。执行页读取真实执行，再按任务分页查找相同 runId、配置版本与模式的报告；首页未找到时可明确继续查找。成功观测不代表整次研究成功或一定交付报告。来自报告的临时上下文只用于“返回刚才的报告”，不作为任意历史的持久关联。

后端验证保存正文和片段 hash、授权与来源归属；前端消费共享 schema，并核对请求目标、正文状态、片段长度、提取版本与可用正文切片的一致性。前端不宣称验证了未公开数据库事实或来源真实性。

专项验证：`vp test apps/web/tests/source-history.test.ts`。浏览器使用 `vp run test:e2e tests/e2e/source-history.spec.ts`；受控 HTTP 样本、实际数据库保留期和远程来源能力分别验证，不混称已完成。
