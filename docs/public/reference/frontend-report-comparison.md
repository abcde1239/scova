# 对象对比表

对比表把几个对象放在同一组维度下并排比较。它是只读的，不会重新比较事实或改动报告。

## 版式

- **列**：对比对象。
- **行**：共同维度。
- **单元格**：对应的值，并关联到支撑它的结论。未知值和缺口就地显示。
- **滚动**：表格太宽时只在表内横向滚动，不撑宽整页。聚焦后可用左右方向键滚动，Tab 进入引用。
- **文字**：长文本自然换行，不截断。

## 核对依据

- 点击单元格的引用，定位到来源原文。
- 表后可展开完整的问题依据与结论，待核实内容直接可见。
- 来源附录按网页和快照集中引用。

## 与变化的关系

- 历史变化在正文前的“变化”区单独显示，见[变化与基线](frontend-report-changes.md)。
- 没有历史变化，不代表对象之间没有差别。
- 部分交付、待核验或旧证据不足时，不会推断“无重要变化”。

## 旧报告

没有对象结构的历史问题型报告会说明这一点，并保留原问答。更早的报告保留结论表格。

另见：[输出形式](frontend-report-formats.md)。
