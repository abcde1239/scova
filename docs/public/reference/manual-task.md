# 手工配置任务

在任务列表点「新建任务」填写任务配置。也可以先用[自然语言草稿](task-draft.md)整理需求，检查后再应用到表单。

## 创建任务

1. 填写标题、主题与目标。
2. 选择查阅时间范围和输出形式。
3. 按需展开填写关注事项、排除条件和来源偏好，每行一项。
4. 查看并按需修改预算、任务时区和站内提醒。
5. 在「执行计划」选择[仅手动、每日或每周](task-schedule.md)，默认「仅手动」。
6. 点「确认保存任务」只创建，进入任务摘要；点「保存并立即运行」创建后马上开始，进入执行详情。

执行详情可通过任务链接回到摘要。

### 填写规则

- **固定范围日期**：按界面标明的浏览器当地时区填写，提交时转换为 UTC。
- **任务时区**：独立的 IANA 时区配置。
- **来源**：只接受不含用户名和密码的 HTTP/HTTPS 链接。这不等于已做安全检查或官方身份认证。
- **预算**：必须是正整数，部署策略可能进一步限制。

### 研究方式

| 方式     | 日期范围          | 回答依据                                                           |
| -------- | ----------------- | ------------------------------------------------------------------ |
| 资料采集 | 必填，默认近 7 天 | 只收录窗口内、有直接原文出处的值，不用模型补答                     |
| 分析研究 | 可选不限日期      | 允许带【模型自回答】标签的稳定知识回答；回答完成与外部支持分别统计 |

资料采集中，日期未知的来源可以单列或剔除；单列的来源不计入采集结果。切换研究方式会设置对应的默认输出形式，之后仍可修改。读取已有配置或应用 AI 草稿时，会保留其明确选择。完成与基线规则见[研究循环](agent-research-loop.md)。

### 保存与出错

- 字段有错时，所在分组自动展开并聚焦。保存明确失败时，已填内容保留。
- 有未保存内容时，离开或关闭页面会提醒；保存进行中无法离开当前页面。取消离开可继续填写，实际离开后草稿不保留。
- 退出或换账号会清理旧内容并取消旧请求。
- 每次保存只提交一次，重复点击不会重复创建。网络中断、服务端出错或响应无法确认时，表单保留原内容，可重试同一次提交，或回到列表核对。

## 项目归类与继续研究

任务摘要显示当前归属。你可以：

- 归入已有项目。
- 归类时新建项目。
- 换项目。
- 取消归类。

归类只改变项目与任务的关系，任务的配置、计划、执行历史和报告仍可从任务入口访问。

点「继续对话研究」：已归类的任务打开所属项目的对话；未归类的任务先让你选择已有项目或新建项目，确认后进入对话。项目对话中可选择要引用的报告。

## 在项目内创建

1. 在项目详情的「研究任务」点「新建任务」，进入同一份配置表单。
2. 「确认保存任务」创建并关联任务；「保存并立即运行」还会排队一次真实研究，并进入执行详情。

项目概览显示整个项目中最早的已启用周期计划，以及近期执行和报告。

项目工作台支持多条会话。直接说明想研究的问题或要查阅的报告，项目助手会提议相应动作。确认研究计划后，可在会话中看到运行状态和结果。项目详情仍可进入旧版对话，查看默认会话的历史并编辑旧草案。周期仍可在任务表单中直接配置。

## 编辑已有任务

1. 在任务摘要点「编辑任务配置」。
2. 修改后保存。每日或每周计划可调整频率、当地时刻和星期；未修改的计划保持不变。
3. 保存成功后停留在编辑页，并显示服务端返回的基线提示。点「返回任务摘要」回到原任务。

要点：

- 未编辑的字段保持原样。固定日期只在你实际修改时才转换时区，未改的日期保留原始精度。
- 配置无法识别，或版本不一致时，页面会阻止编辑，避免丢失字段。
- 语义上的查阅范围变化后，下一次完整执行会建立新基线。
- 保存不会启动执行，也不会改写旧执行或报告。
- 有未保存修改时，离开、关闭或切换任务会提醒；保存进行中无法离开当前页面。

### 编辑冲突

别处已修改同一任务时，草稿仍可复制，但不能直接重发。

1. 先复制需要手动合并的内容。
2. 选择「重新读取最新版本」。
3. 明确确认丢弃草稿。

取消，或重新读取失败时，原草稿保留。网络中断或保存结果不确定时，同样需要先重新读取核对。保存不会自动重试。
