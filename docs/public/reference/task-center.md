# 任务中心

`/tasks` 读取当前账号的真实任务摘要。标题进入 `/tasks/:taskId` 的只读任务摘要，展示当前配置主题与目标；浏览器返回或“返回任务”保留状态筛选，并复用账号/epoch 内的分页缓存。创建、编辑、计划和执行控制尚未接入，不提供无效按钮。

API 模块通过统一 requestlane 和共享 schema 校验访问 `/tasks`、`/tasks/:taskId`，只在选中任务的摘要中读取 `/tasks/:taskId/runs?limit=1`。列表接口不含最近执行，因此列表不逐卡补发历史请求；摘要的最近执行只显示真实历史的排队时间和状态，不使用任务更新时间推测。没有执行时显示“尚无执行”，读取失败可独立重试。下次执行采用任务的 `nextRunAt`，为空时显示“未安排”；时间明确按当前浏览器时区显示，摘要另展示真实任务配置时区。

后端任务列表只支持 `limit`、`cursor`，没有状态筛选参数。因此“进行中/暂停/归档/全部”筛选的是已加载任务；界面明确该范围。每个筛选拥有独立游标链，切换取消旧观察请求，匹配为空且仍有后页时可以继续加载。不会把当前页无匹配误称整个账号无任务，也不会自动扫描全部任务。每次最多加载20项，相同任务ID合并去重；列表只保存在 Vue Query，不复制至 Pinia。

查询 key 的领域前缀为 `tasks`、`runs`，兼容事件模块的领域失效，外层使用现有 `session/accountId/epoch`。退出或换号沿用统一生命周期取消请求并清空缓存；旧账号或旧筛选的迟到结果不能替换当前列表。列表、摘要与最近执行均可取消，不新增 fetch/axios 层。

验证：`vp test apps/web/tests/task-center.test.ts`。持久本地浏览器样本使用 `vp exec playwright test --config tests/e2e/task-center.config.ts`，独立4191端口、生产构建、六宽和200%文字、分页/只读入口/返回、筛选及状态；API响应由测试明确提供的本地契约样本拦截，不是真实后端旅程。截图与失败trace保存在忽略的 `artifacts/e2e/task-center`。该测试不会启动数据库、访问供应商或复用其他工作树预览。
