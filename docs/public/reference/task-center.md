# 任务中心

「任务」页列出当前账号的任务。

## 任务列表

- 点标题进入只读的任务摘要，查看当前配置的主题与目标。从摘要返回时保留状态筛选。
- 列表提供新建任务入口，任务卡提供报告历史入口。
- 任务卡的**最近执行**显示真实的排队时间和状态，没有执行时显示「尚无执行」。读取失败可单独重试。
- **下次执行**取自任务计划，没有时显示「未安排」。时间按当前浏览器时区显示，摘要另显示任务配置的时区。

## 筛选与加载

筛选项有「进行中」「暂停」「归档」「全部」。

- 筛选只作用于已加载的任务，界面会标明这一范围。
- 每个筛选有各自的分页，每次最多加载 20 项，重复任务自动合并。
- 当前已加载的任务没有匹配项、但还有后页时，可继续加载。这不代表账号下没有任务，也不会自动扫描全部任务。
- 切换筛选会取消旧的加载。

## 任务摘要

摘要页提供：

- 编辑任务配置。
- 执行历史。
- 立即执行。
- 暂停、恢复与归档。
- 项目归类，以及「继续对话研究」。该操作需要任务已归入项目，或在摘要中先完成归类。

相关规则见[手工配置任务](manual-task.md)、[每日与每周计划](task-schedule.md)、[暂停、恢复与归档](task-lifecycle.md)和[执行操作](run-actions.md)。

## 账号切换

退出或换账号会取消进行中的加载并清空缓存，旧账号或旧筛选的迟到结果不会替换当前列表。
