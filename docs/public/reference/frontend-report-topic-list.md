# 主题清单

主题清单把一组具名对象和它们的字段列出来，适合“有哪些”类问题。

## 你会看到什么

- **对象卡片**：每个对象一张卡，列出所需字段的值、支持依据和缺口。
- **未知字段**：不隐藏，明确标出未知。
- **共用部分**：和简报一样显示标题、模式、交付时间、配置版本、覆盖范围、限制和部分交付警告。
- **变化**：历史变化显示在正文前的“变化”区，清单正文不重复。
- **来源**：按网页和快照集中，点击引用定位原文。

## 资料采集清单

资料采集任务的清单显示“已采集条目”表：值、发布或更新日期、日期来源和直接出处。

- 没有收录的来源不会出现在条目表里。
- 日期未知的来源按任务设置分开列出或剔除。
- 详见[输出形式](frontend-report-formats.md)。

## 旧报告

没有对象结构的历史问题型报告会说明这一点，并保留原问答。更早的报告按“来源事实 / Agent 推断 / 冲突证据 / 证据不足”分组。

切换成果只是阅读，不会触发生成，也不能凭空增加没生成过的形式。

另见：[阅读报告](frontend-report-detail.md)。
