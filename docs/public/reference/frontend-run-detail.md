# Web 执行详情

登录后可直达 `/runs/:runId`，刷新后从权威 GET Run 快照恢复八种持久状态、固定任务版本、演示/真实模式、累计用量、预算及覆盖缺口。演示数据明确标记；部分交付、执行失败、连接中断与“本次范围内未发现重要变化”分别展示。顶部展示状态、时间和终态耗时，执行标识与完整时间默认折叠。执行操作位于日志与覆盖信息之后，仍使用既有幂等启动、取消和失败重试流程，不提供手动恢复运行。

事件通过既有 [Run 订阅](frontend-run-events.md) 接入，同一 Query key 读取和替换快照。事件使缓存失效，不凭终态事件直接宣布完成；连接 EOF 后仍从权威接口确认。连接信息独立展示，研究期间不占用整页 progress 光标。阶段栏可筛选日志，显示节点结束次数、累计耗时与工具失败次数；节点结束不代表其中工具成功。日志按持久化序号去重，展示时间、工具结果、耗时、用量及白名单错误分类；可筛选“仅失败”、关闭“跟随最新”阅读历史。最多保留最近500行，裁剪明确提示，阶段累计独立保留；不渲染原始参数、自由文本消息、提示词、密钥或网页全文。旧记录无法还原丢失的异常原因，记录缺失不等于工具从未执行。游标过期、切换执行或会话时清理投影，过期后明确提示日志范围。

报告入口仅在权威快照确认完整或部分交付后展示，来自校验过的发布事件，或 `/reports?taskId=…` 分页结果中与当前 Run、固定版本和 mode 一致的报告。首次只读取一页，未找到且有游标时可继续查找，重复游标会停止分页；查找失败可以重试，不伪造报告 ID。`/reports/:reportId` 是独立报告详情模块的目标地址。

组件按 Vue/community 约定拆为薄 view、展示组件、composable 和统一 API 桥接。尺寸以 rem 为主，容器随可用空间重排，断点使用 rem，保留默认根字号；仅连接工具区使用局部轻度玻璃，正文保持实色与留白。暂时断网时可展示带说明的上次快照；权限、资源或结构校验失效时隐藏旧快照与报告入口。

```sh
vp test apps/web/tests/execution-view.test.ts
vp exec playwright test --config tests/e2e/execution.config.ts
```

浏览器入口使用独占回环端口 5219 的 test 模式构建，HTTP 响应由 Playwright 本地样本提供，不代表真实账号、后端或模型研究。覆盖六宽 320/390/768/1024/1440/1920、demo/live 与 partial/failed、八状态、200% 文字放大、键盘刷新、错误恢复、重连、报告分页及换号隔离；截图保存在忽略的本地产物目录。文字放大不等于真实浏览器整页缩放，实体移动设备、真实 API SSE 和业务研究仍需独立验收。harness 的可选 `web-execution-browser` 仅覆盖浏览器工作区，不替代后端或必需单元检查。
