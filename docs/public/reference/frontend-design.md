# 工作台视觉约定

工作台在宽屏使用左侧栏，「新建任务」直达表单，「任务」与「项目」各有一级入口。窄屏通过顶部个人栏打开导航。通知、语言和账号工具在侧栏底部，外观可从账号菜单进入。报告和资料的正文使用限宽阅读区，证据、笔记和操作按需展开。

项目工作台默认呈现对话，待确认研究草案与生成该草案的消息相邻，项目概览和研究任务通过视图选择器切换。串行工作流以开始、研究节点、结束表示顺序，检查器负责所选节点的任务配置和排序操作。

内容保持左对齐，阅读区限制行宽；窄屏重排为单列和折叠菜单。字号、间距和控件尺寸使用 rem/em 与弹性容器，保留浏览器默认根字号。加载更多等列表后续操作居中，页面加载状态占据相应内容区域。

界面使用 Inter 与 Noto Sans SC，阅读正文可使用 Noto Serif SC；主题支持蓝、松绿、鸢尾、琥珀及浅暗模式。字体必须提供系统回退。局部玻璃用于导航和工具层，正文、表单与证据保持清晰底色，并提供实色降级。

来源图片按内容需要展示，没有图片时收回图片列。中文动作名、键盘焦点和纯图标按钮的可访问名称须保留；状态不能只靠颜色区分。

实现与验证见[前端约定](frontend-conventions.md)、[字体](frontend-fonts.md)、[局部玻璃](frontend-glass.md)、[来源图片](source-images.md)和[基础视觉检查](frontend-visual-foundation.md)。
