# 纯文本笔记

资料库“笔记”分区可阅读、分页查看和编辑全部笔记。可从收藏来源选择“为此来源记笔记”，也可在报告中选择本报告或其已有来源后新建。目标在创建后固定，不提供任意 UUID 或网址输入。来源笔记不推断属于某份报告；只有报告目标提供稳定的关联报告入口。

笔记、收藏、报告独立保存。取消收藏不删除笔记或报告，删除笔记也不删除来源或引用。阅读正文使用阅读字体，编辑器、按钮和元信息保持界面字体。内容始终按纯文本显示，HTML 和 Markdown 不被解析。

正文原样提交，不 trim 或 normalize。共享 schema 要求非空白且最多 20000 个 UTF-16 码元；前端另检查 80000 UTF-8 字节，并拒绝 TAB、LF、CR 以外的 C0 控制字符和 DEL。当前合法的长度上限无法触及 80000 字节，因此字节检查是防御限制，不表示存在能达到它的合法正文。控制字符拒绝是本项前端保护，不宣称共享 schema 或服务端已实施相同规则。

新建按一次用户动作固定目标、原文与 `Idempotency-Key`。结果不确定时保留原稿和该键，仅由用户选择“同键核对并重放创建”，不靠列表中相同正文推断成功，也不自动换键。同键重放可能返回已被其他操作编辑的当前笔记：本地原稿保持不变，服务器副本单独展示。原笔记已删除时旧键不能复建，须明确结束旧尝试后再决定是否新建；未知尝试的结束提示会说明另起新建可能重复。

列表不带逐条 HTTP ETag。编辑或删除前会实际读取详情，校验目标、标识、修订与原样带引号的 ETag；保存和删除使用 `If-Match`。409 修订冲突会保留本地稿。重新读取只更新服务器副本，不自动授权覆盖；用户选择采用服务器正文，或保留本地稿并按该版本整理后，才能再次保存。网络、超时、取消及结构异常后的未知保存或删除，同样需实际重新读取核对，旧成功缓存和取消回滚不能解除锁定。

429 不会触发后台写入重试。存在有效 `Retry-After` 时显示服务器指定的可重试时间，并禁写至到期；没有有效时间时如实提示稍后手工重试。错误不清空原稿。删除需明确确认。

切换目标、分页、资料库分区、路由及关闭页面会保护未保存稿；在途操作不能切换，未知创建须核对或明确结束，未知保存/删除须先实际读取。换号、退出或会话失效会清理旧账号的本地编辑状态，迟到结果不会写入新账号。草稿仅在当前编辑会话中保留，不承诺跨刷新持久化。

通信使用统一 requestlane 与同源 Cookie/CSRF；Vue Query 保存服务端列表和详情，本地仅维护编辑稿与动作状态，不改动配置、Run 或报告。

报告后台读取失败时（包括 403/404），旧报告、服务器笔记和目标选择隐藏；同账号、同报告的本地编辑会话仍保留，可复制原稿或明确关闭，恢复前禁用笔记读取和写入（包括创建重放）。恢复报告不会自动改写原稿。401 导致会话失效、退出或换号仍清理旧会话。保存成功还须验证返回修订恰好比发送的 `If-Match` 增加一，旧修订或跳号响应按结果不确定处理。
