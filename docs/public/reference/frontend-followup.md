# 报告修订与后续研究

已保存回答下可选择“生成新版报告”或“后续研究”，均需单独确认。普通提问、刷新、打开或取消确认不会创建执行。确认弹窗读取原报告 Run，核对任务、不可变配置版本和模式，展示预算并允许选择本次成果形式。仅真实报告可新建执行；历史演示报告和已有执行仍可读取。

“生成新版报告”发送 `{confirm:true,operation:'revise'}`，仅使用原报告保存的证据及讨论上下文，禁止搜索与重新抓取来源，模型生成及保存证据读取仍计量。原证据的覆盖限制继续保留，缺少所选形式所需材料时明确说明。“后续研究”使用默认 research 操作，可联网搜索和读取新来源；兼容原 `{confirm:true}` 请求。

可选 `outputFormats` 冻结本次成果形式，省略时沿用原配置。服务端分别为问题关联修订与研究 Run；目标改为保存的问题原文，清空重点条目，计划改为手动，沿用原版本、模式、预算和其他限制。确认时冻结有界报告、历史问答及本轮问题和已保存回答，重试沿用该快照。原报告和 TaskVersion 保留，原任务计划不改，后续比较与普通监控基线隔离。

执行完成后，对话历史展示新成果入口；新版报告提供“返回原报告对话”，可回到对应问题。原报告内容与生成时的成果形式保持不变。

写入期间拦截重复确认。超时、网络或响应校验错误可能发生在服务器落库之后，页面保留冻结的原问题、父执行、版本、模式、预算和幂等键，不自动重试。可明确“读取已保存关联”：非空关联需核对真实 Run，空关联仍不能证明写入未完成，原请求继续保留；也可明确使用同一请求重发，不生成新 key。幂等记录不一致会停止重发，仍可读取关联。

暂时报告读取失败会禁用写入并保留同账号、同问题未知请求。离开、换问题或刷新会丢失本地恢复记录，已有离开保护会说明后果；换号、路由身份改变和卸载隔离迟到响应。取消客户端请求不保证服务器回滚。已有 question.followupRunId 或命令复用时提供关联执行入口，可能指向活动或已结束 Run，不创建第二个执行、不自动跳转抢占当前页面。状态从真实详情读取；命令快照不覆盖 Run Query 或 SSE 的权威状态。

验证：`vp test apps/web/tests/followup.test.ts apps/web/tests/report-questions.test.ts apps/web/tests/run-actions.test.ts`、`vp check`、`vp run build:frontend`。独立浏览器专项为 `vp exec playwright test --config tests/e2e/playwright.config.ts tests/e2e/followup.spec.ts`，核对确认/取消/Escape、焦点、重复触发、未知结果恢复、原报告失败、跨账号与窄屏文字放大。受控 HTTP 测试不能替代真实 API/数据库的唯一 Run、配置覆盖、outbox 和监控基线验证，也不表示真实搜索或模型已完成。
