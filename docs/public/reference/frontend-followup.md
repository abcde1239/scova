# 补充研究

在已保存的回答下，可以选择“生成新版报告”或“后续研究”。两者都需要你单独确认。普通提问、刷新、打开或取消确认都不会创建执行。

## 两种操作

| 操作         | 数据来源                       | 联网 | 结果                                                 |
| ------------ | ------------------------------ | ---- | ---------------------------------------------------- |
| 生成新版报告 | 原报告已保存的证据和对话上下文 | 否   | 在原有证据内重新组织。缺少所选形式所需材料时会说明。 |
| 后续研究     | 联网搜索并读取新来源           | 是   | 补充新资料后生成新成果。                             |

输入区的“补查新资料”会把未提交的问题直接作为新研究目标。

## 确认时你会看到

- 原报告的任务、配置版本和模式。
- 预算。
- 本次成果形式的选择，不选则沿用原配置。
- 只有真实报告能新建执行。演示报告不行。

## 执行时的规则

- 研究目标改为你的问题原文，计划改为手动，沿用原版本、模式、预算和其他限制。
- 确认时会固定报告、历史问答和本轮问题，重试沿用这份快照。
- 原报告、原任务和周期计划都不变。后续比较和日常监控的基线不受影响。
- 原证据的覆盖限制继续保留。

## 完成之后

- 对话历史里出现新成果入口。
- 新版报告提供“返回原报告对话”，回到对应问题。
- 原报告内容保持不变。
- 已有关联执行时，会提供入口，可能指向进行中或已结束的运行。不会再创建第二个执行，也不会自动跳转抢占当前页面。

## 结果未知时

- 写入期间会阻止重复确认。
- 超时或网络错误时，页面保留冻结的问题、版本、模式和预算，不自动重试。
- 可点“读取已保存关联”。有关联时请到运行详情核对；没有关联也不能证明未创建，原请求会继续保留。
- 也可以用同一请求重发，不会生成新的重复执行。
- 报告暂时读不出来时，写入被禁用，未知请求保留。离开页面、换问题或刷新会丢失这份恢复记录，离开前会提示。
- 换账号或换报告会隔离迟到的响应。取消请求不保证服务端已回滚。
