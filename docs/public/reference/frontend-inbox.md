# 报告收件箱

登录后在 `/inbox` 浏览已交付报告，按全部、未读或已读筛选并加载后续页。报告行展示标题、摘要、交付时间、演示或真实模式及部分交付警告。当前媒体契约没有图片字段，页面使用纯文字，不抓取外站图片。

“标记已读”和“恢复未读”仅修改收件箱条目，与站内通知独立。请求完成前保留原状态，失败可重试；读取报告本身不会修改已读状态。同一报告在列表中只显示一次。分页使用服务端原样游标，不用客户端时间重新生成。

从报告标题进入详情后，可通过“返回收件箱”回到同账号的原筛选与缓存位置。正常往返保留已加载页面；刷新浏览器或缓存释放后重新读取。无权访问或响应校验失败时隐藏旧内容；暂时连接失败保留上次读取的内容并提供重试。退出或换号会取消旧请求并清理缓存。

```sh
vp test apps/web/tests/inbox.test.ts
vp run test:e2e tests/e2e/inbox.spec.ts
```
