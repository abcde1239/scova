# 从自然语言生成任务草稿

在创建任务页选择「用 AI 整理需求」，把想法整理成任务配置。选择「手动填写」则直接填写同一份表单。两种方式创建的是同一种任务。

## 生成并应用草稿

1. 输入需求描述。最多 2000 字，且不超过 8000 UTF-8 字节，原文不会被自动修剪。
2. 从预设列表选择需求时区，默认沿用当前任务时区。任务执行时区同样可按城市或 IANA 名称搜索选择。
3. 点「生成任务草稿」。
4. 检查结果区：原文、模型解析或手工编辑模式、手工原因、警告、建议计划与预算，以及解析用量。
5. 确认无误后点「应用草稿并替换当前配置」，建议才会填入可编辑表单。
6. 检查全部字段，再另行确认保存。原文随最终任务配置保存。

说明和生成用量可在弹窗中按需查看，必要的错误与警告留在页面上。

### 要点

- **只是整理**：生成草稿不保存任务、不安排执行、不启动研究。
- **手工模式**：显示「manual」表示待手工编辑，不是演示研究。
- **用量**：解析用量独立统计，不计入运行预算。
- **旧结果失效**：解析期间或结果返回后修改了原文、解析时区或表单，旧结果就不能覆盖新内容。可重新解析，或继续手工填写。

## 执行计划

合法的周期建议应用后显示在「执行计划」中。你可以继续调整频率、星期和当地时刻，或选择「仅手动」。

- 未修改的配置保留原有的精确时间、数组条目和预算，只有你改过的字段才会按表单重建。
- 应用后你继续编辑的计划不会被解析建议覆盖。
- 保存周期配置不会立即执行。

## 出错与限制

- **缺少模型**：返回可编辑的手工草稿。
- **限流、超时或结果不合法**：保留原文与表单，可继续手工填写。解析请求不会自动重发。
- **离开页面**：草稿不保留。换账号或离开页面会终止请求，迟到的结果不会应用到新账号。
