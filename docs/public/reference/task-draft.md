# 从自然语言生成任务草稿

创建任务页的「用 AI 整理需求」可将描述整理为任务配置，点击「生成任务草稿」后先检查建议，再应用到表单；「手动填写」直接填写同一表单，两者最终创建同一种任务。描述最多 2000 字且不超过 8000 UTF-8 字节，原文不被自动修剪。需求时区必须从预设列表选择，默认沿用当前任务时区；任务执行时区也用同样的城市/IANA可搜索选项。说明和生成用量通过 Naive UI 弹窗按需查看，必要错误与警告保留在页面。

解析只调用 `POST /task-drafts`，不保存任务、安排执行或启动研究。结果区显示原文、模型解析或手工编辑模式、手工原因、警告、建议计划与预算，以及独立解析用量。manual表示待手工编辑，不能视为demo研究；解析用量不计入Run预算。

查看结果后，显式点击“应用草稿并替换当前配置”才填入可编辑表单。解析期间或结果返回后修改原文、解析时区或表单，会使旧结果不能覆盖新内容；可重新解析或继续手工填写。应用后仍须检查全部字段，再另行确认保存。原文随最终任务配置保存。

合法周期建议应用后显示在“执行计划”中，可继续调整频率、星期和当地时刻，或明确选择“仅手动”。未修改的原配置保留精确时间、数组条目和预算；用户修改的字段才从表单重建。解析建议不会覆盖应用后继续编辑的计划，保存周期配置也不立即执行。

缺少模型时，后端返回可编辑手工草稿。限流、超时或无法取得合法结果时保留原文与表单，用户始终可手工继续；解析请求不会自动重发。离开页面后不持久保存草稿，换账号或卸载会终止请求，迟到结果不能应用到新账号。
