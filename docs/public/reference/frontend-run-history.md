# 任务执行历史

在任务摘要下查看当前账号的执行历史，按服务端返回顺序分页。每条记录保留当次状态、模式、排队时间和固定配置版本；历史版本不会替换为任务当前版本。选择记录进入独立执行详情，已交付报告继续沿授权报告地址访问。

“加载更早的执行”使用服务端游标，不根据浏览器时间重新生成；重复记录按执行 ID 去重，重复游标停止加载。离开任务、切换任务或账号会取消旧请求，历史缓存由 Vue Query 与会话代次隔离。暂时网络失败可重试；权限失效时隐藏旧记录。

字号、间距、控件最小尺寸和断点以 rem 为主，窄屏允许版本标识与文字换行；模式和版本始终可见。

```sh
vp test apps/web/tests/run-history.test.ts
vp run test:e2e --config tests/e2e/run-history.config.ts
```

浏览器套件使用受控样本验证布局、分页及导航。另已在隔离 PostgreSQL 17 / Redis 7 与真实 API 中验证 25 条记录的分页、历史版本、账号隔离及旧执行到报告的访问路径：其中一次为实际演示执行交付，一次为实际排队执行，其余为持久化的同时间历史测试记录；不代表真实联网研究。200% 根文字放大不等同于浏览器整页缩放。
