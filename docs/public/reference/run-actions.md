# 执行操作

## 立即执行

在任务摘要点「立即执行」，只在点击时提交。所有新执行都是真实研究，会使用已配置的搜索与模型，可能产生服务费用。缺少必要配置时明确失败。

## 取消执行

在执行详情可请求取消当前活动执行。取消不会暂停任务的未来计划。

- **正在取消**：后台仍在停止在途工作，最终结果以执行快照为准。
- 取消与完成同时发生时，执行可能已经结束。

## 重试

只有失败或已取消的执行可以「重试并创建新执行」。

- 重试沿用原任务版本与预算，创建一个关联的新执行，同样是真实研究。
- 想用任务的最新配置，请从任务摘要点「立即执行」。

## 操作结果

操作成功后，页面显示返回执行的实际模式与状态，并提供「打开执行」。已有活动执行，或同一命令被重放时，可能复用既有执行。实际模式、版本和关联关系以返回结果为准。

## 网络结果不确定

可点「使用同一命令重发」。写操作不会自动重发。

- 立即执行与重试：重发沿用原请求和幂等键。
- 取消：没有请求体或幂等键，只重新确认同一执行的取消结果。
- 幂等内容冲突：该操作停止，不会换键绕过。

重发记录只保留在当前页面，离开、刷新或切换账号后清除。
