# 执行操作

任务摘要的“立即执行”只在点击时提交命令。默认演示模式使用示例数据；真实模式须显式选择，可能使用部署者配置的外部搜索与模型并产生计量费用。缺少配置或服务失败时不会自动切换模式。

执行详情支持请求取消当前活动执行，取消不暂停任务的未来计划。“正在取消”表示后台仍在停止在途工作，最终结果以执行快照为准。取消与完成竞争时，执行可能已经结束。

只有失败或已取消的执行支持“重试并创建新执行”。重试使用原任务版本与预算，创建关联的新执行，默认仍是演示模式。要使用任务的最新配置，请从任务摘要立即执行。

命令成功后显示返回执行的实际模式与状态，并提供“打开执行”。已有活动执行或同一命令重放可能复用既有执行，实际模式、版本和关联关系以返回结果为准。

网络结果不确定时，可显式“使用同一命令重发”，不会自动重发写请求。立即执行与重试保留原端点、模式和幂等键；取消命令没有请求体或幂等键，只重新确认同一执行的取消结果。幂等内容冲突时停止该动作，不通过更换键绕过冲突。重发记录仅保留在当前页面，离开、刷新或切换账号后清除。
