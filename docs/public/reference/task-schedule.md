# 每日与每周计划

创建和编辑任务的“执行计划”支持仅手动、每日或每周。周期计划需要IANA任务时区与当地HH:mm时间；每周还需明确星期，周一为ISO 1，周日为7。站内提醒复用表单原有配置，不改变执行频率。

未保存预览只解释当前填写的计划，不推算下次执行时刻。“服务端已保存的计划”使用最近保存或重新读取的配置、时区和nextRunAt，分别展示任务当地时间与UTC。修改草稿不会把旧nextRunAt标成新计划。保存走完整Task config，编辑原样携带quoted If-Match；冲突与不确定结果沿用重新读取核对流程。未修改字段保留原配置内容与时间精度。

夏令时导致当地时刻不存在时，后端顺延到首个有效时刻；重复时刻选择首次且不执行第二次。页面的America/New_York固定示例只解释规则：2026-03-08的02:30顺延至03:00（07:00Z）；2026-11-01的01:30选择首次（05:30Z），跳过第二次01:30。示例不是当前任务预测。

“仅手动”是计划频率，不是demo/live执行模式。定时执行由部署者的WORKER_SCHEDULED_RUN_MODE控制，默认demo；当前部署值没有公开查询接口，页面不能保证live或修改部署配置。创建或修改计划不会启动即时Run，前端不安装cron或执行计时器。暂停、恢复与归档由独立任务生命周期功能提供。
