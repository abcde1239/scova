# 每日与每周计划

创建和编辑任务时，在「执行计划」选择「仅手动」、每日或每周。

| 选项   | 需要填写                             | 效果               |
| ------ | ------------------------------------ | ------------------ |
| 仅手动 | 无                                   | 不自动定时执行     |
| 每日   | IANA 任务时区、当地 HH:mm 时间       | 每天按当地时间执行 |
| 每周   | IANA 任务时区、当地 HH:mm 时间、星期 | 每周按当地时间执行 |

星期以数字表示：周一为 1，周日为 7。站内提醒沿用表单原有配置，不影响执行频率。

## 查看计划

- **未保存预览**：只解释你当前填写的计划，不推算下次执行时间。
- **服务端已保存的计划**：显示最近保存或重新读取的配置、时区和下次执行时间，分别以任务当地时间和 UTC 展示。修改草稿时，旧的下次执行时间不会被当作新计划。

保存使用完整任务配置。编辑冲突或结果不确定时，按[编辑冲突](manual-task.md#编辑冲突)的步骤重新读取核对。未修改的字段保留原配置内容与时间精度。

## 夏令时

- **当地时刻不存在**：顺延到第一个有效时刻。
- **当地时刻出现两次**：只在第一次执行，跳过第二次。

页面以 America/New_York 为例说明规则，示例不是对当前任务的预测：

- 2026-03-08 的 02:30 顺延到 03:00（07:00Z）。
- 2026-11-01 的 01:30 选第一次（05:30Z），跳过第二次 01:30。

## 注意

- 所有新的定时执行都是真实研究，会调用已配置的搜索与模型。缺少必要配置时明确失败。
- 创建或修改计划不会立即启动执行。
- 暂停、恢复与归档见[暂停、恢复与归档](task-lifecycle.md)。
