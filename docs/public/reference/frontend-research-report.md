# 研究报告

研究报告是篇幅最完整的形式，包含论点、证据链、解释与限制。阅读时不会发起新请求。

## 你会看到什么

- **概述与章节**：新报告按保存的大纲展示。章节只引用本成果已验证的结论，浏览时不会重新生成。
- **目录**：有大纲时链接章节和问题覆盖。没有大纲时链接概述、已保存问题与结论分类。
- **锚点跳转**：点目录会展开所在折叠区，并滚动到标题。
- **变化**：正文前的“变化”区，见[变化与基线](frontend-report-changes.md)。
- **来源**：按网页和快照集中，只包含当前成果和变化用到的引文。
- **条件与缺口**：条件、缺口、置信说明和引用继续显示。

## 阅读细节

- 正文自然换行并保留段落，来源里的 HTML 不会被执行。
- 窄屏和文字放大时重排，不截断答案。
- 切换成果不会混入其他成果的结论。
- 没有大纲的历史报告，保留问题回答，或来源事实、Agent 推断、冲突证据、证据不足等分组。

另见：[输出形式](frontend-report-formats.md)。
