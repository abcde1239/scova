# 暂停、恢复与归档

任务摘要中的“任务计划与归档”先重新读取任务状态与修订版本，再允许操作。所有命令通过同源 Cookie、CSRF 和原样 If-Match ETag 校验；不会自动重发写请求。

“暂停未来计划”停止后续周期触发，当前在途执行继续，仍允许显式手动执行。“恢复未来计划”按服务端时间重新安排未来时点，不补跑暂停期间的历史时点。仅手动执行的任务没有周期计划。

“归档任务”需要确认：停止未来计划、阻止新执行，并对活动执行请求取消；请求取消不等于已停止。归档保留配置版本、报告与历史，不能恢复任务。取消确认或按 Esc 会返回归档按钮，不提交命令。

冲突、缺少修订或网络结果不确定时，操作保持锁定。点击“刷新任务状态”完成实际读取后，根据最新状态重新选择操作；刷新不会重发原命令，后台缓存变化也不会自动解除锁定。

此页面负责任务生命周期。执行的取消与失败重试由独立执行操作功能提供，是否可用以当前部署页面为准。
