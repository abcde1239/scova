# 暂停、恢复与归档

在任务摘要的「任务计划与归档」管理任务的未来计划。打开时会先重新读取任务当前状态，再允许操作。写操作不会自动重发。

## 操作

- **暂停未来计划**：停止后续周期触发。在途执行继续，仍可手动执行。
- **恢复未来计划**：按当前时间重新安排未来时点，不补跑暂停期间错过的时点。
- **归档任务**：需要确认。归档会停止未来计划、阻止新执行，并对活动执行请求取消；请求取消不等于已停止。归档保留配置版本、报告与历史，但任务不能恢复。取消确认或按 Esc 会回到归档按钮，不提交操作。

仅手动执行的任务没有周期计划。

## 冲突或结果不确定

遇到冲突、缺少版本信息，或网络结果不确定时，操作会保持锁定。

1. 点「刷新任务状态」，等待读取完成。
2. 根据最新状态重新选择操作。

刷新不会重发原操作，也不会因后台数据变化自动解锁。
