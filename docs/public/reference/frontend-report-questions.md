# 对报告提问

在报告页可以接着报告继续提问。回答只依据这份报告已保存的证据，不会联网。

## 提问

- 问题最多 2000 个字符，保留原始空格和换行，纯空白不能提交。
- 输入为空时，可点“总结主要发现”或“查看结论依据”填入建议，再编辑，点“提问”才提交。
- 成功后输入框清空，可直接追问。
- 历史按轮显示问题、回答、引用和关联执行。选中一轮可看用量和后续操作。
- 收起对话时，草稿和未确认的请求会保留。
- 问题内容不写入链接。未发送的草稿只留在当前页面。

## 模型能看到什么

- 最近最多 12 个完整问答，更早最多 16 轮的摘要。
- 有限的报告内容和最多 24 条保存证据。
- 输入有长度预算，不保证记住全部细节。久远或含糊的指代，请写明具体内容。
- 历史回答只是讨论背景，不会成为新的事实证据。

## 回答与引用

- 每条回答都带当前报告的证据，引用是保存原文中的连续逐字片段。
- 事实摘录要求逐字匹配，解释和归纳用自然语言并明确标识。逐字引用通过，不代表已核查事实真伪。
- 校验失败时不显示回答。
- 证据可用键盘展开，HTML 和 Markdown 按纯文本展示。

## 回答不足

不足分为：证据不足、未配置可用模型、模型失败、输出未通过核验、已中止。

“需要更多资料”不表示已同意后续研究。要联网补充，须另行确认，见[补充研究](frontend-followup.md)。

## 结果未确认时

- 网络错误、处理中或限流，不代表问题没有保存。点“读取本次结果”恢复，沿用同一个问题，不会自动重发。
- 读取到的可能是已保存的“不足”结果，并不表示再次调用了模型。
- 服务给出等待时间时，界面会显示再次读取的时间。
- 放弃未知请求前，先复制需要保留的问题。再次独立提问可能另计用量。
- 切换报告、换账号或离开页面会中止请求，但不能撤销已经执行的模型调用。离开未提交或未知请求前会有确认。

## 刷新与历史

- 刷新后恢复最近 100 轮，点“查看更早的对话”继续向前翻。
- 链接可直接定位到某条回答，不会再次提问。
- 每份报告同时只处理一轮。另一个标签页已新增轮次时，需要先读取最新历史再提交，避免接到过时的上下文。
- 报告暂时不可读时，本地问题和未确认请求保留供复制，回答与读写暂停。换账号或换报告会清除旧的编辑内容。

## 用量

本次问答的模型调用和 token 单独记录，不计入原运行的预算。含估算或未知调用的预留会标注，不表示精确费用。

另见：[阅读报告](frontend-report-detail.md)、[补充研究](frontend-followup.md)。
