# 报告内证据问答

报告详情中的问答面板只查阅当前报告已保存、授权的证据，不搜索网页、不读取新的来源，也不创建研究 Run。问答界面、引用和用量使用界面字体；原报告的演示、部分交付与覆盖缺口仍按报告原样展示。

## 提问与保存结果

问题保留原始空格与换行，最多 2000 个 UTF-16 码元，纯空白不能提交。提交后本次问题和幂等键固定；未确认结果时，使用“读取本次结果”明确恢复。网络错误、处理中或限流并不证明服务端未保存问题，恢复沿用同一问题和键，不自动重试写请求。

服务提供 Retry-After 时界面显示再次读取时间。读取可能返回已保存的不足结果，不代表再次调用模型。结束未知请求前应复制需要保留的问题；服务端可能仍已处理，再次独立提问可能另计用量。切报告、换号或卸载会中止客户端请求，不能撤销已经执行的模型调用。

成功接受回答后，链接的 `questionId` 保存已核验的回答标识。刷新先读取当前授权报告，再 GET 该指定回答，不再次 POST 或调用模型。问题正文和幂等键不写入链接或本地存储。非法或重复的 questionId 不发问答请求。当前没有问题列表接口，也不承诺尚未知 ID 的请求能在刷新后恢复。

## 回答与不足

每条回答必须带当前报告的证据 ID，引用必须是保存原文中的连续逐字片段，回答也必须是其引用中的逐字摘录。身份、结构、状态或引用校验失败时不显示回答。证据可在面板内用键盘展开查看，HTML 与 Markdown 按纯文本展示。

不足状态区分证据不足、未配置可用模型、模型失败、输出未通过核验与中止。需要更多资料不表示已同意启动后续研究；本面板不提供 followup 操作或模型密钥设置。

模型尝试与输入、输出 token 是本次问答的独立记录，不计入原 Run 预算。包含估算或未知调用预留时明确标注，不表示精确费用或实际扣款。

当前报告暂时不可读，包括同账号的权限或不存在响应时，已输入的本地问题与未确认请求保留供复制；回答、引用及读写暂停。换账号或换报告清除旧编辑上下文。离开未提交或未知请求前有确认，已保存回答可通过其链接恢复。

## 验证

`vp test apps/web/tests/report-questions.test.ts` 检查实际 requestlane 端点、原文与 UTF-16 边界、状态和引用语义、稳定恢复请求及会话隔离。浏览器覆盖使用 `vp run test:e2e tests/e2e/report-questions.spec.ts`；真实持久化与供应商可用性须另行验证，受控 HTTP 样本不代表远程模型可用。
