# 搜索已存资料

资料库的“搜索已存资料”入口打开 `/library/search`，只检索当前账号已保存的来源快照标题、仍可用正文和纯文本笔记。它不联网、不启动执行，不检索全部报告或独立引用片段。英文可由 PostgreSQL simple 全文词项匹配命中，中文等可由字面子串补充命中；不承诺分词、同义词或语义检索。

输入约 300ms 后检索；中文输入法组合期间不提交。搜索按钮或 Enter 可立即提交，取消保留输入，清空移除输入和结果。原样关键词和资料类型、来源收藏状态一起构成检索范围，任一变化会取消旧读取、隐藏旧命中并重置分页。关键词非空白、最多 200 个 UTF-16 码元、800 UTF-8 字节及 8 个空白分隔词。已收藏来源筛选包括来源及其笔记，不包括报告笔记。

结果按来源最近成功观测或笔记更新时间排列，不按相关度评分。每页最多 20 项，仅提供上一页/下一页；没有总数。游标保持不透明，重复条目或循环页会停止展示并提示从第一页重新读取；游标失效后从头操作会实际请求服务器。空结果只说明当前条件下没有已存可搜资料命中，错误不会冒充空结果。

来源结果的 ID 是命中快照 ID，打开对应来源和具体快照；来源笔记打开关联来源历史，报告笔记打开关联报告。笔记结果不承诺直接定位或编辑完整笔记。标题、最多 500 码元的摘录和匹配方式均使用 API 原始值，摘录为纯文本上下文，不执行 HTML 或补写内容。

过期正文不参与新的检索，标题与笔记仍可能命中。搜索 DTO 没有正文到期或当前正文状态字段，页面不伪造逐项状态/倒计时；已显示摘录反映本次检索时的内容，当前正文状态由来源详情确认。重新检索会从服务器读取。读取统一使用 requestlane 和同源 Cookie 会话，Vue Query 是唯一服务端缓存；换号会清理输入、分页及旧结果。

验证命令：`vp test apps/web/tests/library-search.test.ts`、`vp check`、`vp run web#build`。浏览器专项为 `vp run test:e2e tests/e2e/library-search.spec.ts`。受控 HTTP 验证前端交互、纯文本、目标和隔离；真实中文/英文召回、数据库到期及分页仍需独立 API/数据库验证，不以空列表或 HTTP 200 代替召回验收。
