# 资料与结论反馈

报告下方的“调整后续研究”面板可选择本报告的一份资料或一条结论，设置“不相关”“已了解”“希望深入”，也可切换或撤销。资料按来源标识去重，结论保留独立标识；操作前展示完整目标文本与标识。同一目标同时只有一种生效反馈，重复设置相同种类保持幂等。

“当前任务生效反馈”可展开查看任务最多 200 条生效项，并逐项撤销。其他报告中的目标只显示目标类型与标识，不补造标题。新增或重激活达到上限时，请先撤销已有项；切换已有生效项不新增名额。

反馈仅供后续新执行创建快照时捕获，不追溯在途执行或历史报告，不修改配置版本、证据、结论和比较基线。当前设置不表示这份报告实际使用了反馈，也不承诺来源整体拉黑或某项算法效果。

网络请求通过统一 requestlane 与同源 Cookie/CSRF 入口，服务端状态仅保存在账号和任务隔离的 Vue Query 缓存。提交中禁用目标选择及写入，收到与任务、目标、种类一致的成功响应后才更新显示，并只刷新该任务的反馈列表，以取得其他页面可能修改的生效项。刷新期间继续防止重复提交，不使报告或执行缓存失效。

失败保留上次读取值；连接中断、响应失效等无法确认写入结果时，不自动重发，需重新读取当前反馈并成功核对后才能继续操作。重读失败或取消后恢复旧缓存均不会解除这项限制；离开后再次打开也会重新请求。读取时发现权限、归属、结构或协议校验问题，会隐藏旧列表。
