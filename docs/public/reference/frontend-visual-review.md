# Scova Web 视觉评审记录

状态：候选方案与待确认决策，2026-10-30。本文是 #88 的公开评审记录，不表示应用已经实现，也不把预览切换或浏览器截图当作用户批准。

## 评审结论

Scova 采用顶部工作台作为候选布局：任务、收件箱、资料库是主导航；通知、外观和账号是全局工具。研究报告和资料阅读保持内容优先的单列阅读层，证据和操作通过局部切换或展开出现。桌面保留明显留白，窄屏重排为单列和折叠菜单，不在空隙中添加欢迎语、装饰统计、同义副标题或无用途的小字。

以下决策仍需用户确认：

| 决策     | 当前候选                                 | 状态                       |
| -------- | ---------------------------------------- | -------------------------- |
| 主导航   | 顶部工作台，任务 / 收件箱 / 资料库       | 待确认                     |
| 默认主色 | 蓝、松绿、鸢尾、琥珀四套主题             | 待确认默认值               |
| 界面字体 | Inter + Noto Sans SC                     | 候选，需许可/自托管验证    |
| 阅读字体 | Noto Serif SC，可切无衬线正文            | 候选，需长文与中文回退验证 |
| 信息密度 | 宽屏 32–48px 外边距；窄屏 16–20px        | 候选，需真实页面验收       |
| 毛玻璃   | 仅顶部导航、工具组、报告操作条和移动菜单 | 候选，需对比度/性能验证    |

未确认项保持“待评审”，后续主题、字体、响应式和玻璃 Issue 不能自行替换这些值并宣称已定稿。

## 页面与功能覆盖

主导航和全局工具应能定位全部现有能力，但不把所有能力堆在首屏：

- 任务：任务列表、创建/编辑、计划与预算、暂停/恢复/归档、执行详情和历史。
- 收件箱：报告交付、已读状态、失败或不完整执行入口。
- 资料库：来源收藏、纯文本笔记、来源搜索、快照与观测历史。
- 报告：简报、主题清单、对比表、研究报告、引用和证据问答。
- 全局工具：通知、主题与阅读字体偏好、账号登录/注册/会话恢复/退出、默认时区和提醒偏好。
- 结果语义：真实/演示、partial、覆盖缺口、事实/推断/冲突/不足必须有文字表达，不能只依赖颜色。

保存和启动是两个动作；暂停保留在途执行；恢复只安排未来计划；问答不联网，继续研究必须显式确认；反馈只影响后续新执行；收件箱已读和通知已读相互独立。

## 视觉规则

### 留白与排版

- 桌面主内容最大约 1100px，报告阅读宽度约 680–760px，编辑表单约 640–740px。
- 窄屏采用 16–20px 边距和单列布局，内容重排而非缩放桌面。
- 标题下只保留能帮助识别、来源、时间、状态、后果或下一步的文字；不使用占位小字填空。
- 操作界面使用 Inter + Noto Sans SC；资料标题和报告阅读默认 Noto Serif SC；表格、按钮、警告、引用工具和元信息保持无衬线。
- 中文字体必须提供本地回退，不能依赖网络字体才能打开页面；字号和行高最终以实际中文长标题、混排、200% 缩放检查为准。

### 图片与图标

- 收件箱或资料库每条最多一张相关来源缩略图；没有自然图片时收回图片列，保持纯文字可读可操作。
- 桌面缩略图候选约 150×100px，手机约 88×88px；报告原图保持比例，不裁掉地图图例或比例尺。
- 图片必须有准确 alt，图片不是唯一信息载体，也不暗示它证明整份报告。
- 图标使用 community 采用的 `@vicons/ionicons5` / `NIcon` 方向，通常 18–20px、`currentColor`；中文动作名保留，纯图标必须有可访问名称和焦点。

### 主题、透明度与光标

- 主题候选为蓝、松绿、鸢尾、琥珀，各自支持浅色、深色和跟随系统；默认主题待确认。
- 毛玻璃只用于顶部导航、工具组、报告操作条和移动展开菜单；正文、输入、证据、图片和警告使用清晰底色。
- 透明度只作用于背景，文字和图标 opacity 保持 1；无 `backdrop-filter` 或减少透明度时使用实色回退。
- 可点击控件使用 `cursor-pointer`，输入使用 `cursor-text`，静态内容使用 `cursor-default`，禁用使用 `cursor-not-allowed`，当前操作使用 `cursor-progress`。光标不能替代键盘语义、焦点、触屏目标或文字状态。

### 响应式

| 宽度       | 布局候选                                            |
| ---------- | --------------------------------------------------- |
| ≥1200px    | 顶部导航、约 1100px 内容区、报告独立阅读宽度        |
| 768–1199px | 弹性收缩，操作换行，不常驻辅助多栏                  |
| 480–767px  | 压缩图片和间距，折叠主导航                          |
| <480px     | 16–20px 边距、单列正文/表单、触屏菜单；极窄继续重排 |

不得出现整页横向溢出；长表只在自身区域滚动；主要操作不依赖 hover；触屏目标候选至少 44×44px。

## 验收与后续顺序

用户确认导航、默认主色、字体、密度和毛玻璃强度后，按以下顺序实施：

1. #89 主题令牌和本地外观偏好。
2. #90 图标语义与集中导入。
3. #91 字体许可、自托管和加载回退；随后 #92 用途排版。
4. #93 响应式工作台壳；#94 局部毛玻璃与实色降级。
5. #95/#96 主题、字体、六宽、缩放、键盘和读屏验收。
6. #98 图片展示和无图纯文字回退；#99 在媒体字段确认后设计同源交付契约。

验收必须覆盖 1440/1024/768/390/360/320px、200% 文字缩放、键盘/读屏/触屏、浅暗主题、四套主色、减少透明度、长标题、混排字体、图片失败和无图状态。预览文件和历史草案只能作为评审材料，不能替代真实页面或设备证据。
