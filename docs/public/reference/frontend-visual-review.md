# Scova Web 视觉评审记录

状态：2026-10-31 用户明确确认下表视觉方向。本文是 #88 的公开评审记录；确认设计方向不表示应用已经实现，实际页面仍须按专项 Issue 验证。

## 评审结论

Scova 采用顶部工作台布局：任务、收件箱、资料库是主导航；通知、外观和账号是全局工具。研究报告和资料阅读保持内容优先的单列阅读层，证据和操作通过局部切换或展开出现。桌面保留明显留白，窄屏重排为单列和折叠菜单，不在空隙中添加欢迎语、装饰统计、同义副标题或无用途的小字。

以下决策已由用户明确确认：

| 决策     | 已确认方向                               | 状态                                |
| -------- | ---------------------------------------- | ----------------------------------- |
| 主导航   | 顶部工作台，任务 / 收件箱 / 资料库       | 已确认                              |
| 默认主色 | 默认蓝色，可切松绿、鸢尾、琥珀           | 已确认，默认蓝色                    |
| 界面字体 | Inter + Noto Sans SC                     | 方向已确认，交付仍需许可/自托管验证 |

| 毛玻璃   | 仅顶部导航、工具组、报告操作条和移动菜单 | 轻度玻璃已确认，仍需对比度/性能验证 |

后续主题、字体、响应式和玻璃 Issue 以这些已确认方向为依据；精确令牌、透明度和断点按真实内容、对比度与可访问性验证调整，不能把实现前确认当作验收通过。

## 页面与功能覆盖

主导航和全局工具应能定位全部现有能力，但不把所有能力堆在首屏：

- 任务：任务列表、创建/编辑、计划与预算、暂停/恢复/归档、执行详情和历史。
- 收件箱：报告交付、已读状态、失败或不完整执行入口。
- 资料库：来源收藏、纯文本笔记、来源搜索、快照与观测历史。
- 报告：简报、主题清单、对比表、研究报告、引用和证据问答。
- 全局工具：通知、主题与阅读字体偏好、账号登录/注册/会话恢复/退出、默认时区和提醒偏好。
- 结果语义：真实/演示、partial、覆盖缺口、事实/推断/冲突/不足必须有文字表达，不能只依赖颜色。

保存和启动是两个动作；暂停保留在途执行；恢复只安排未来计划；问答不联网，继续研究必须显式确认；反馈只影响后续新执行；收件箱已读和通知已读相互独立。

## 视觉规则

### 留白与排版

- 主内容使用 `width: 100%` 与 `max-inline-size: 68.75rem`；报告阅读宽度约 `42.5–47.5rem`，编辑表单约 `40–46.25rem`，均以容器可用空间为上限。
- 边距使用 `clamp(1rem, 3vw, 3rem)` 等弹性规则，窄屏约 `1–1.25rem`，内容重排而非缩放桌面。
- 标题下只保留能帮助识别、来源、时间、状态、后果或下一步的文字；不使用占位小字填空。
- 操作界面使用 Inter + Noto Sans SC；资料标题和报告阅读默认 Noto Serif SC；表格、按钮、警告、引用工具和元信息保持无衬线。
- 中文字体必须提供本地回退，不能依赖网络字体才能打开页面；字号和行高最终以实际中文长标题、混排、200% 缩放检查为准。

尺寸实现统一使用弹性单位：字号、间距、圆角、控件最小尺寸用 `rem` / `em`，行高为无单位值；容器采用 `%`、`min()` / `max()` / `clamp()`，阅读宽度可结合 `ch`，图像使用比例与自适应尺寸。断点采用 `rem` 并按内容验证。保留浏览器默认根字号，不以固定根字号或 `vw` 单独限制文字缩放；不把本表的视觉对照换算成固定像素布局。

### 图片与图标

- 收件箱或资料库每条最多一张相关来源缩略图；没有自然图片时收回图片列，保持纯文字可读可操作。
- 缩略图使用 `aspect-ratio` 与受容器约束的相对尺寸；桌面约 `9.375rem` 宽、3:2，手机约 `5.5rem` 方形，极窄屏可继续收缩或上下重排。报告原图 `max-inline-size: 100%`，保持比例，不裁掉地图图例或比例尺。
- 图片必须有准确 alt，图片不是唯一信息载体，也不暗示它证明整份报告。
- 图标使用 community 采用的 `@vicons/ionicons5` / `NIcon` 方向，通常 `1.125–1.25em`、`currentColor`；中文动作名保留，纯图标必须有可访问名称和焦点。

### 主题、透明度与光标

- 主题为蓝、松绿、鸢尾、琥珀，默认蓝色，各自支持浅色、深色和跟随系统。
- 毛玻璃只用于顶部导航、工具组、报告操作条和移动展开菜单；正文、输入、证据、图片和警告使用清晰底色。
- 透明度只作用于背景，文字和图标 opacity 保持 1；无 `backdrop-filter` 或减少透明度时使用实色回退。
- 可点击控件使用 `cursor-pointer`，输入使用 `cursor-text`，静态内容使用 `cursor-default`，禁用使用 `cursor-not-allowed`，当前操作使用 `cursor-progress`。光标不能替代键盘语义、焦点、触屏目标或文字状态。

### 响应式

| 宽度            | 布局候选                                              |
| --------------- | ----------------------------------------------------- |
| ≥75rem          | 顶部导航、最大约 68.75rem 内容区、报告独立阅读宽度    |
| 48rem 至 <75rem | 弹性收缩，操作换行，不常驻辅助多栏                    |
| 30rem 至 <48rem | 压缩图片和间距，折叠主导航                            |
| <30rem          | 1–1.25rem 边距、单列正文/表单、触屏菜单；极窄继续重排 |

不得出现整页横向溢出；长表只在自身区域滚动；主要操作不依赖 hover；触屏目标至少 `2.75rem × 2.75rem`，控件可随文字增大。
