# 研究循环与完成判定

本文说明 Agent 的研究循环如何冻结策略、补证、结束并交付。Agent 在持久化研究图内执行：模型评估具体字段的资料是否足够，程序选择允许的下一步并保存检查点；搜索摘要不充当正文证据。

候选结果由 Worker 认证和原子交付，节点成功不能替代任务交付。

## 冻结与恢复

新执行冻结以下策略，恢复时沿用，不自动增加新动作：

| 策略                       | 冻结内容                                                                                                      | 旧检查点                                               |
| -------------------------- | ------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------ |
| `loopQualityPolicy: 1`     | 原有研究、字段和缺口策略；规划工具的请求元数据进入成功回执，恢复校验策略一致性，Worker 对照不可变账本再次认证 | 缺少该标记时继续使用原语义，不增加新动作或严格支持规则 |
| `searchDirectionPolicy: 3` | 新 live 缺口循环；规划查询和字段诊断沿用可空 `language`                                                       | 无策略标记、v1、v2 沿用原行为，不增加补证动作          |
| `pagePolicy: 1`            | Worker 新执行；检查点只存页面引用与元数据，节点运行前从同次成功读取回执恢复正文                               | 历史检查点保留原正文结构                               |
| `baselinePolicy: 1`        | 全部必答字段有外部支持才能推进比较起点                                                                        | 旧执行保持原规则                                       |
| `collectionPolicy: 1`      | 资料采集的日期窗口与直接出处规则                                                                              | -                                                      |

**恢复**：恢复验证读取操作身份、完整元数据及正文指纹。截止交付只读取明确提升的检查点，重新校验已综合结论并标记部分交付，不发起模型、搜索或网页请求。基础设施故障可恢复，账本完整性和程序错误不会被记作普通来源失败。

## 搜索方向

报告语言与搜索语言独立，不用语言或时区推断用户所在地。查询与语言共同参与去重、补搜指纹、搜索缓存及工具账本输入身份。

| 搜索服务   | 语言处理                                                            |
| ---------- | ------------------------------------------------------------------- |
| Tavily     | 映射语言偏好                                                        |
| Perplexity | 兼容适配器映射语言过滤（仍不可作为缺少独立读取能力的 API 模式配置） |
| DeepSeek   | 只发送改写后的查询                                                  |
| SearXNG    | 透传语言并保留引擎白名单                                            |

策略不切换供应商、不添加国家过滤参数；地区通过适用的发布者站点和检索词表达，不能改变任务明确要求的辖区、对象、版本和时间。

**v3 补证顺序**：

1. 优先重绑已取得的正文。
2. 直接读已经发现的候选。
3. 之后才补搜。

查询重复或同字段上一次补搜没有增益时，若还有搜索、读取、模型及时间预算，则尝试未查过的语言或相关资料库站点；已有明确的新语言诊断时直接复用。

- 必要的查询改写每轮最多调用一次，输出上限 384 token，共享原预算并为后续综合留额度。
- 无新方向时不再发送重复搜索，仍可继续其他可执行字段。
- 逐字段两次无增益停止及总预算不变。

### 常用资料库目录

内置目录按主题和来源范围提供少量 `site:` 检索提示，不直连资料库 API、不需要密钥或部署配置。严格官方模式不注入目录提示，读取仍只允许用户指定的来源范围。

| 类别     | 入口                                                                                                                               | 用途                                                   |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------ |
| 通用导航 | Wikipedia（`wikipedia.org`）、Wikidata（`wikidata.org`）                                                                           | 查多语种条目、别名、实体标识和参考链接，不替代一手证据 |
| 文献发现 | PubMed（`pubmed.ncbi.nlm.nih.gov`）、Crossref（`search.crossref.org`）                                                             | 查生物医学文献或 DOI/出版元数据，再找原始出版物        |
| Web 技术 | MDN（`developer.mozilla.org`）                                                                                                     | 查 Web 平台文档，必要时追溯规范                        |
| 地区法规 | 欧盟 `eur-lex.europa.eu`、英国 `legislation.gov.uk`、美国 `govinfo.gov`、加拿大 `laws-lois.justice.gc.ca`、日本 `laws.e-gov.go.jp` | 按适用辖区查法规及出版物，不把它们视为跨辖区通用规则   |

站点目录、搜索摘要和查询改写均不提供证据，也不会直接把主页或猜测的条目 URL 送给 Reader。只有搜索回执或已读正文中出现的地址可以进入读取，仍须经过来源排除、正文、时间和引用校验。

**正文链接**：正文的可选 `links` 是导航元数据，最多 80 个 HTTP(S) 目标，链接文本最多 200 字符、URL 最多 4000 字符。链接不提供事实支持，不改变正文 hash 或发现问题范围；Worker 对它与原读取回执一并认证。正文提取版本未因增加可选导航元数据改变。

## 字段反馈

综合为冻结字段返回 `fieldChecks`：

| 诊断               | 下一步                                                       |
| ------------------ | ------------------------------------------------------------ |
| `binding_missing`  | 用现有正文重绑问题、引文和字段                               |
| 引用或结构无效     | 局部修复，不据此推断互联网缺资料                             |
| `evidence_missing` | 优先重用刚取得的正文，再直接读已发现目标，最后按缺失命题补搜 |
| `conflict`         | 保留双方，使用启用的冲突复核策略                             |

**直接读取**：

- 只选择搜索回执或已读正文链接中真实出现的 URL，继续遵守来源白名单、排除范围、版本及读取能力限制。
- 每次只安排一页，成功后沿原校验、综合和候选投影执行。
- 最新版本任务在相容候选中优先具体的较新版本记录；此排序是启发式，不认证版本是否最新。

**共享字段**：可以绑定多条单题结论或一条多题结论。每条引用都必须支持该结论的全部问题；来源原发现范围之外的问题，须通过回执中的连续原文关联授权。字段所有权本身不扩大引用权限。

**严格字段支持**同时要求：

1. 合法绑定。
2. 完整问题范围。
3. 该次字段诊断为 supported。
4. 无缺失的直接支持。

必需阶段、日期等缺失即使标成 `missing_detail` 仍不计 supported；多个 partial 来源也不自动升级。已经 supported 的字段不被较弱补丁覆盖。尚未选中展示的合法外部候选可留待重绑，历史响应仍完整保存在回执中。

## 结束与交付

`coverage.completion` 是可选的版本化输出，旧报告可无此字段：

| 字段                       | 含义                                                                                                           |
| -------------------------- | -------------------------------------------------------------------------------------------------------------- |
| `answerReady`              | 所有问题已有可交付回答，且无未解决争议                                                                         |
| `externalEvidenceComplete` | 所有必需字段均由外部证据完整支持                                                                               |
| `verificationDone`         | 外部完整支持，或有界核验已因明确原因停止                                                                       |
| `stopReason`               | `verified`、`no_progress`、`budget`、`deadline`、`provider_unavailable`、`iteration_limit` 或 `source_limited` |

- validate 与最终候选共用完成计算。
- 知识草稿答全不结束外部核验；有界核验停止后，分析研究允许的模型答案仍可交付。
- `baselinePolicy: 1` 要求全部必答字段有外部支持才能推进比较起点；模型回答可计为回答完成，但不会计作外部支持。资格与原因保存在 `coverage.baseline`。

### 资料采集

`collectionPolicy: 1` 的规则：

- **日期窗口**：必填，默认近7天；分析研究允许不限日期，窗口外来源可作背景。
- **直接出处**：只认有直接原文出处的值，关闭模型知识草稿与补答。
- **日期来源**：优先使用来源发布时间，发布时间未知时可使用独立解析的更新时间；冲突或窗口外的发布时间不被更新时间覆盖。
- **筛选结果**：窗口外来源剔除；日期未确认来源默认单列且不计入结果，也可由用户选择剔除。
- **`dateScreening`**：统计筛选来源页面数，保留日期精度和连接器出处类型；它不是已核实字段的数量。

### 无正文与故障

- 没有合法正文时，新循环及采集策略跳过付费综合，保留已有合法模型答案并执行有界补搜。
- 采集只有已认证的日期筛选说明时，可以交付零收录的 partial；来源读取成功不等于通过日期筛选，零收录也不表示网上没有相关信息。
- 空来源 schema 明确禁止引用，不生成空枚举。
- 模型配置故障直接终止为 `AGENT_CONFIGURATION_INVALID`，不进入结构修复循环。
- 仅经连接器认证的同步、未发送 preflight 失败可按零实际用量结算；已发出或网络结果未知的调用继续保留预算预留。
- 读取期限和传输行为见[连接器说明](../../../packages/connectors/README.md)。

### 重试上限

动作增益按目标字段新增支持或合法绑定原文区间计算，无关新页 hash 和其他字段的关联不算该目标的增益。以下条件共同限制重试：

- 每字段两次无增益。
- 重复动作。
- 最多 60 个缺口动作。
- 原预算与期限。

新正文仍可触发一次综合，不能因尚未产生语义增益而跳过处理。

## 能力边界

字段支持和规划对象划分依赖模型语义评估。结构与逐字校验通过不证明现实事实正确，受控回归也不替代真实搜索和模型效果验收。
