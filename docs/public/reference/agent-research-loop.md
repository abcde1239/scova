# 研究循环与完成判定

Agent 在持久化研究图内执行。模型评估具体字段的资料是否足够，程序选择允许的下一步并保存检查点；搜索摘要不充当正文证据。候选结果由 Worker 认证和原子交付，节点成功不能替代任务交付。

## 冻结与恢复

新执行在原有研究、字段和缺口策略上冻结 `loopQualityPolicy: 1`。规划工具的请求元数据进入成功回执；恢复校验策略一致性，Worker 对照不可变账本再次认证。历史检查点缺少该标记时继续使用原语义，不自动增加新动作或严格支持规则。

新执行还冻结 `searchDirectionPolicy: 1`：规划查询及字段缺口诊断携带可空 `language`，按发布者语言检索，保留专名、对象、版本、模块和时间条件。综合使用有界的搜索候选/失败诊断调整下一条查询；这些诊断只是未受信导航，不提供证据。缺少带语言的字段诊断时，可在缺口节点调用一次最多 384 输出 token 的查询改写，不生成答案、不另开循环。改写共享原模型预算，并预留后续综合额度；配置错误、额度、取消与期限沿用原处理。旧检查点不自动启用此策略。

查询与语言共同参与去重、补搜指纹、搜索缓存及工具账本输入身份。Tavily 映射语言偏好，Perplexity 兼容适配器映射语言过滤（仍不可作为缺少独立读取能力的 API 模式配置），DeepSeek 只发送改写后的查询，不虚构语言参数；SearXNG 透传语言并保留引擎白名单。明确新检索方向直接补搜，不用旧候选替代；仍优先复用新正文、保留逐字段两次无增益停止和原累计预算。

正文的可选 `links` 是导航元数据，最多 80 个 HTTP(S) 目标，链接文本最多 200 字符、URL 最多 4000 字符。链接不提供事实支持，不改变正文 hash 或发现问题范围；Worker 对它与原读取回执一并认证。正文提取版本未因增加可选导航元数据改变。

Worker 新执行使用 `pagePolicy: 1`，检查点只存页面引用与元数据，节点运行前从同次成功读取回执恢复正文。恢复验证读取操作身份、完整元数据及正文指纹；历史检查点保留原正文结构。截止交付只读取明确提升的检查点，重新校验已综合结论并标记部分交付，不发起模型、搜索或网页请求。基础设施故障可恢复，账本完整性和程序错误不会被记作普通来源失败。

## 字段反馈

综合为冻结字段返回 `fieldChecks`：

| 诊断               | 下一步                                                       |
| ------------------ | ------------------------------------------------------------ |
| `binding_missing`  | 用现有正文重绑问题、引文和字段                               |
| 引用或结构无效     | 局部修复，不据此推断互联网缺资料                             |
| `evidence_missing` | 优先重用刚取得的正文，再直接读已发现目标，最后按缺失命题补搜 |
| `conflict`         | 保留双方，使用启用的冲突复核策略                             |

直接读取只选择搜索回执或已读正文链接中真实出现的 URL，继续遵守来源白名单、排除范围、版本及读取能力限制。每次直接读取只安排一页，成功后沿原校验、综合和候选投影执行。最新版本任务在相容候选中优先具体的较新版本记录；此排序是启发式，不认证版本是否最新。

共享字段可以绑定多条单题结论或一条多题结论。每条引用都必须支持该结论的全部问题：来源原发现范围之外的问题，须通过回执中的连续原文关联授权。字段所有权本身不扩大引用权限。

严格字段支持同时要求合法绑定、完整问题范围、该次字段诊断为 supported，以及无缺失的直接支持。必需阶段、日期等缺失即使标成 `missing_detail` 仍不计 supported；多个 partial 来源也不自动升级。已经 supported 的字段不被较弱补丁覆盖。尚未选中展示的合法外部候选可留待重绑，历史响应仍完整保存在回执中。

## 结束与交付

`coverage.completion` 是可选的版本化输出，旧报告可无此字段：

| 字段                       | 含义                                                                                                           |
| -------------------------- | -------------------------------------------------------------------------------------------------------------- |
| `answerReady`              | 所有问题已有可交付回答，且无未解决争议                                                                         |
| `externalEvidenceComplete` | 所有必需字段均由外部证据完整支持                                                                               |
| `verificationDone`         | 外部完整支持，或有界核验已因明确原因停止                                                                       |
| `stopReason`               | `verified`、`no_progress`、`budget`、`deadline`、`provider_unavailable`、`iteration_limit` 或 `source_limited` |

validate 与最终候选共用完成计算。知识草稿答全不结束外部核验；有界核验停止后，分析研究允许的模型答案仍可交付。新 `baselinePolicy: 1` 要求全部必答字段有外部支持才能推进比较起点；模型回答可计为回答完成，但不会计作外部支持。资格与原因保存在 `coverage.baseline`，旧执行保持原规则。

资料采集冻结 `collectionPolicy: 1`，日期窗口必填，默认近7天；只认有直接原文出处的值，关闭模型知识草稿与补答。优先使用来源发布时间，发布时间未知时可使用独立解析的更新时间；冲突或窗口外的发布时间不被更新时间覆盖。窗口外来源剔除，日期未确认来源默认单列且不计入结果，也可由用户选择剔除。`dateScreening` 统计筛选来源页面数，保留日期精度和连接器出处类型；它不是已核实字段的数量。分析研究允许不限日期，窗口外来源可作背景。

没有合法正文时，新循环及采集策略跳过付费综合，保留已有合法模型答案并执行有界补搜。采集只有已认证的日期筛选说明时，可以交付零收录的 partial；来源读取成功不等于通过日期筛选，零收录也不表示网上没有相关信息。空来源 schema 明确禁止引用，不生成空枚举。

模型配置故障直接终止为 `AGENT_CONFIGURATION_INVALID`，不进入结构修复循环。仅经连接器认证的同步、未发送 preflight 失败可按零实际用量结算；已发出或网络结果未知的调用继续保留预算预留。读取期限和传输行为见[连接器说明](../../../packages/connectors/README.md)。

动作增益按目标字段新增支持或合法绑定原文区间计算，无关新页 hash 和其他字段的关联不算该目标的增益。每字段两次无增益、重复动作、最多 60 个缺口动作及原预算/期限共同限制重试。新正文仍可触发一次综合，不能因尚未产生语义增益而跳过处理。

字段支持和规划对象划分仍依赖模型语义评估。结构与逐字校验通过不证明现实事实正确，受控回归也不替代真实搜索和模型效果验收。
