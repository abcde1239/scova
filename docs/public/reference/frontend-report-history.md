# 报告历史

从任务列表的“报告历史”进入 `/tasks/reports?taskId=…`，或通过授权路由 `/tasks/reports` 查看全部任务范围。该页面属于任务区域，不增加并列报告中心或主导航。

任务筛选使用已读取的任务标题，可继续加载更多任务选项。若当前筛选任务尚未出现在选项中，保留“当前筛选任务”；报告请求独立于任务选项加载，不额外读取每份报告正文。无效任务标识显示错误，不退回全部范围。

每条报告保留实际标题和摘要、真实/演示模式、完整性、交付时间，以及报告与对应执行入口。部分交付明确说明结论缺口。不同模式可以在历史中同时浏览，但不据此推断它们共用基线；此列表不计算报告对比。

分页使用服务端原样游标并按报告标识去重，保持服务端顺序。主动切换任务会取消旧读取并从首个游标开始。打开报告后通过浏览器后退，正常往返保留已加载页、筛选、滚动与标题焦点；浏览器刷新或缓存释放后重新读取。读取不会改变收件箱或通知已读。

权限、协议或结构失败隐藏旧内容；暂时连接错误保留上次内容并提供重试。退出或换号清除旧账号历史缓存。
