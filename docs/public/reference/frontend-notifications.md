# 站内通知

登录后，桌面顶部“通知”支持悬浮、聚焦或点击查看最近最多 4 条通知，显示类别、简要状态、未读标识和时间。点击条目直接进入报告或执行记录，“查看全部通知”进入 `/notifications`；移动端通过侧栏进入通知页。通知页可按普通汇总、重要变化、运行问题和已读状态筛选，加载后续页面。

普通汇总表示一次查阅报告交付，不代表没有变化。重要变化指已确认的重要信息变化；部分交付和失败归为运行问题，并展示对应执行状态。通知保留真实或演示模式与时间；当前接口没有任务/报告标题摘要，页面不虚构这些内容，也不额外读取每份报告。

有关联报告时“阅读报告”，无报告时“查看执行”。打开内容不会自动修改已读状态。“标记已读”和“恢复未读”是独立动作，只修改通知，不改变收件箱已读或隐藏既有报告。默认提醒偏好与任务提醒偏好由各自设置页面管理，本页不创建或删除通知，也不接入系统通知、邮件或推送。

写请求确认前保留原状态；失败或结果未确认时可重新读取核对。分页沿用服务端游标并按通知标识去重。权限/协议/结构错误隐藏旧内容，暂时连接错误保留上次内容并提供重试。退出或换号取消旧请求并清缓存。

```sh
vp test apps/web/tests/notifications.test.ts
vp run test:e2e tests/e2e/notifications.spec.ts
```
