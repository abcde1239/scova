# 研究运行图

执行详情页 `/runs/:runId` 提供现有 Agent 研究流程的只读运行图。选择节点可查看重复执行实例、尝试次数、已完成/运行中/已中断等状态及保存的耗时；图中的连线表示允许的流程路径，不表示本次实际经过所有路径。尚未访问的节点不推断为跳过，循环步骤不换算为完成百分比。

运行图是观察入口，不提供拖拽编排、修改流程或从画板重新执行。搜索和读取工具失败可能被研究流程处理，不能据此直接判断节点或整个任务失败；节点结束也不代表最终报告已经交付。运行终态仍以 Run 公共快照和报告交付结果为准。

## 状态与恢复

`GET /api/v1/runs/:runId/graph` 仅返回当前账号拥有的执行，包含图版本、投影事件序号、节点及允许连线、节点实例与尝试、历史完整性和裁剪标记。实例身份绑定当前 Run、节点及其来源检查点，恢复同一个逻辑节点时新增尝试，不把再次搜索误算成原节点成功。

Worker 在节点开始时保存尝试，节点检查点合法提升之后才记录完成；恢复中断、取消和未确认完成分别显示。成功的 Run 不会把缺少完成记录的节点自动涂为成功。图不暴露租约、检查点标识、提示词、密钥、网页全文或隐式思维链。

图快照与事件在同一事务内持久化，独立于 SSE 的保留窗口。事件序号继续使用持久高水位，即使旧事件全部清理也不会从头计数。前端使用统一 requestlane/Vue Query 读取，复用现有 SSE 的缓存失效与断线重连；游标过期后重新读取权威快照，不靠浏览器内存补造历史。可使用「刷新运行图」单独核对。

旧执行缺少实例身份或完整事件历史时，显示阶段汇总及可确认实例；不虚构精确尝试。无匹配图版本时降级为历史汇总。快照最多保留256个实例，每个最多8次尝试，裁剪时明确标记。暂时读取失败可保留带说明的旧图；账号、权限或响应校验失效时隐藏旧快照。

## 组件与验证

图形节点使用原生按钮，文字说明状态，支持键盘选择；窄区域的图板独立横向滚动，节点详情在图下方阅读。字号和图板尺寸使用 rem，页面放大后不裁切节点文字。

源码入口为 `apps/web/src/components/run/ExecutionGraph.vue`、`apps/web/src/composables/useRunGraph.ts`、`packages/models/src/research/graph.ts`；服务端状态投影在 `packages/db/src/run-graph.ts`。

验证使用 `vp test` 的运行图单元测试、真实 PostgreSQL 的 SSE/运行图集成测试，以及 `vp run test:e2e tests/e2e/search-graph.spec.ts` 的受控浏览器场景。浏览器固定响应不代表真实研究或线上 SSE 业务验收。
