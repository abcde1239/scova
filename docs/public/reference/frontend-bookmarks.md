# 来源收藏与资料库

报告下方可选择已有来源进行收藏，资料库的“收藏”分区按服务端顺序分页展示来源标题、地址和必要时间。没有媒体信息时保持纯文字，不抓取外站图片。原始来源链接明确在新窗口打开。

列表默认展示标题、来源域名和简短收藏日期；“来源详情”可展开完整地址、收藏时间和最近查阅记录。原始来源、历史、笔记与收藏操作保持可达，读取错误和未知写入结果不会藏在详情中。

收藏创建返回 `201 / reused:false`；重复收藏返回 `200 / reused:true`，复用已有记录。取消收藏只移除收藏记录，返回无正文的 `204`，不会删除来源、报告或证据。重复取消可能返回 `404`，需核对当前状态。

报告按钮初始只提供“收藏来源”，不因某个已加载页面没有目标而认定未收藏。操作结果未知时，会保留上次确认值并暂停写入；“核对收藏状态”从首页按原样游标读取，直到找到该来源或确实到达末页才确认。失败、取消、循环游标或达到安全批次上限均不代表未收藏，也不会解除未知限制。此限制在同一会话的页面切换后仍保留。

列表使用账号与会话隔离的 Vue Query 缓存，通过 requestlane 同源 Cookie/CSRF 通信。前后翻页不解码或重写游标；操作成功只失效收藏域并返回第一页，避免删除分页锚点后继续使用失效游标。失败保留原页和此前显示，权限或协议校验失败时隐藏旧数据。

收藏 DTO 不包含报告关联。由报告进入资料库时，仅在同账号、会话和页面生命周期的有效客户端入口上下文中，对同一来源提供“返回刚才的报告”；这不是持久化关联。直接进入、页面重载或账号变更后不补造关联报告，也不逐条查询猜测。资料库也已提供[笔记分区](frontend-notes.md)、[已有资料检索](frontend-library-search.md)与[来源历史](frontend-source-history.md)。这些功能沿用各自的目标与归属规则，不为收藏 DTO 补造报告关联。
