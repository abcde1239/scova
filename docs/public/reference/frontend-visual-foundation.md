# 基础视觉验收

`/__examples/visual-foundation` 是仅在 test 模式注册的基础样例，复用实际主题、用途字体、图标、按钮、状态和玻璃样式，不连接业务接口。正常生产构建不注册或打包该页面。它验证已交付基础的渲染组合，不代表具体业务页面或设备已经验收。

## 复现

```sh
vp install --frozen-lockfile
vp run test:e2e:install
vp exec playwright test --config tests/e2e/visual-foundation.config.ts
```

专用配置启动回环地址 `127.0.0.1:4195` 的 test 模式构建预览，不复用其他服务；端口已占用时先确认占用来源，不停止未知进程。通用浏览器配置和安装说明见[浏览器测试](browser-testing.md)。

| 测试组                           | 覆盖                                                                                              |
| -------------------------------- | ------------------------------------------------------------------------------------------------- |
| 四主色 × 浅暗 × 原生玻璃         | 界面/阅读中文混排、主按钮与普通按钮、引用、选中、弱化来源、部分/失败/成功及状态文字；四种玻璃用途 |
| 同一矩阵 × 减少透明度 + 字体阻断 | 浏览器媒体特性模拟 `prefers-reduced-transparency: reduce`，实际确认媒体匹配、无模糊和系统字体回退 |
| 同一矩阵 × 显式实色 + 字体阻断   | 使用已交付 `scova-glass--solid` 降级类，确认模糊关闭、字体失败时文字与操作仍存在                  |
| 每组白/黑/蓝底色                 | 同一元素的真实背景、透明层合成与文字对比度；避免只比较静态令牌                                    |

每个样例等待字体与浏览器报告的过渡动画完成，读取 `getComputedStyle` 的前景和逐层背景，使用浏览器 Canvas 将 CSS 色值转换为 sRGB，按透明度合成到样例的均匀实际底色，再计算 WCAG 相对亮度比。普通文字至少 4.5:1，样例中经实际字号检查的大标题至少 3:1。样例拒绝背景图或元素整体透明度，避免算法悄悄忽略未支持的渲染情况。均匀底色上的 blur 不改变合成结果；该方法不能代表照片/渐变等任意动态背景，也不验收主题切换中间帧。

字体通过 Chromium 的 `CSS.getPlatformFontsForNode` 核实具体中文/拉丁节点使用的字形来源，不把 CSS 声明的 family 或 `document.fonts.check` 当作真实中文字体证据。正常路径应使用 Inter、Noto Sans SC 与 Noto Serif SC；阻断路径必须实际发生字体请求失败，且节点没有使用自托管字形。图标复用现有组件，装饰图标 `aria-hidden`、纯图标按钮有可访问名称，中文动作名保留。

## 证据索引与审阅

每次运行在忽略的本地结果目录生成每组 `sample.png` 和附加 `rendered-measurements.json`。JSON 记录：实际 HEAD、样例/样式/组件/spec/配置/锁文件 SHA-256、Chromium 版本、主题/底色/字体模式、平台实际字体、玻璃背景及滤镜、各配对色值/字号/阈值和对比度。未提交代码通过文件指纹区别于 HEAD，提交后应对准确候选重跑；不能沿用历史草案数字。

自动断言失败即该组未通过，不能删去不合格配对或降低阈值。人工审阅同次运行的截图：检查中文是否缺字、标点/拉丁混排、正文与阅读标题层级、引用可识别、状态文字、玻璃清晰度和字体回退后操作是否完整；记录具体运行版本与审阅结论。截图和测量文件只保留本地，不通过公开文档链接私有资料或用户数据。

## 验证边界

- 自动对比度通过不等于人工视觉审阅通过，也不等于 WCAG 整体认证。
- 本项不覆盖业务数据、真实图片、六宽页面、键盘旅程或 200% 缩放；这些由页面专项承担。
- 减少透明度是浏览器媒体特性模拟；显式 solid 是既有降级分支验证，两者都不是“真实不支持 backdrop-filter 的浏览器”。该类引擎、实体设备 GPU 与低端性能仍需单独验证。
- 字体阻断模拟字体网络失败，不替代每个平台字体栈、读屏或全部中文字符验收。
- 基础视觉检查已由 `verify:web` 的 visual-foundation 阶段接入 `ready`，也可通过专用浏览器配置单独执行；基础样例不替代真实业务页面验收。
