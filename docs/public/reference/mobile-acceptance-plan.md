# 完整移动旅程与真实设备验收计划

状态：待执行计划，2026-11-01，对应 [#100](https://github.com/abcde1239/scova/issues/100)。完整 Web 联合验收 [#29](https://github.com/abcde1239/scova/issues/29) 尚待完成；本文不表示该前置或本项已验收。iOS/Android 实体设备、软键盘、安全区、旋转及真实读屏目前均未验，不据桌面 viewport 或截图声明兼容通过。

## 验收范围与证据

现有 Web 使用 rem/弹性容器、响应式导航、报告表格局部滚动与可滚动确认弹层。基础与补充页面的六宽、根文字放大和键盘专项分别由 [#96](https://github.com/abcde1239/scova/issues/96)、[#97](https://github.com/abcde1239/scova/issues/97) 跟踪；四报告形式由 [#27](https://github.com/abcde1239/scova/issues/27) 跟踪。每项实际状态以对应准确提交和运行结果为准。

验收记录区分代码观察、桌面浏览器模拟、真实设备和辅助技术。根文字 200% 与整页浏览器缩放分别记录；AX 树或可访问名称断言不能代替 VoiceOver/TalkBack 的实际报读。缺少安全区或视口专用适配代码只是待查线索，先复现问题再做最小修复。

## 可复现环境

1. 使用独立测试账号、数据库、队列与固定研究响应。demo 与受控 live 分别标明；固定响应不代表远程供应商验收。
2. 提供手机可访问的受控 HTTPS 测试源与一致的 `APP_ORIGIN`。手机 localhost 指向手机自身；如显式开放专属实例到局域网，结束后关闭该入口。保持 Secure Cookie、Origin/CSRF、Reader 私网限制与账号隔离。
3. 设备操作者按官方流程授权 Android USB 调试或 Safari/WebKit 检查；不预设设备已授权或自动更改其设置。
4. 保存准确提交/构建指纹、设备配置、模式/数据来源、步骤、截图或录像、控制台/网络及服务端计数。无图片路径仍完整操作，不依赖外站素材。

## 旅程、步骤与预期

在竖屏完成基础路径，再于输入聚焦、键盘弹出、横竖旋转及较大系统字体下复测代表步骤。以下均为待执行用例。

| ID                | 复现步骤                                                               | 通过条件                                                                                           |
| ----------------- | ---------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| M1 登录/恢复/导航 | 填邮箱密码并提交；打开关闭菜单；锁屏后恢复                             | 输入/主动作可达、无意外缩放或重复提交；焦点返回；不显示旧账号数据                                  |
| M2 任务草稿       | 输入长中文；解析失败后手工编辑；旋转后保存                             | 草稿和编辑代次保护；输入/错误/保存可滚达；保存一次且零 Run                                         |
| M3 计划与预算     | 编辑 daily/weekly、IANA 时区、ISO weekday、预算；制造 409 后读取新版本 | 原生控件可用，错误可读；不覆本地稿，不擅改其他字段或预测 DST                                       |
| M4 执行恢复       | 固定测试供应商后执行；切后台/锁屏再回；分别暂停与取消                  | 重连读取同一 Run；断线不猜失败；暂停不取消在途、取消不改计划；无跨账号闪现                         |
| M5 四形式阅读     | 同报告切四形式；展开变化双方引用；横滚表格；跳正文/变化/来源           | reportId/事实/引用不变，partial 可读；仅表格局部横滚，长 URL 换行；焦点及外围草稿保留              |
| M6 笔记与冲突     | 写长中文；键盘弹出后旋转；制造 409；保稿/复制并尝试离开                | 光标/选区合理，保存/取消可达；冲突不覆稿；离开只出现一次确认，不在未核对状态误发写入               |
| M7 资料库         | 收藏；中文组合输入搜索；分页；定位结果与旧快照                         | 当前账号隔离；键盘不挡住结果入口；旧正文限制与短引用正确；不启动研究                               |
| M8 反馈           | 设置已知/不相关/深入并撤销；新 Run 核作用                              | 触控命中和状态清楚；忙碌零重复请求；只影响后续 Run，重要新值仍可见                                 |
| M9 问答与未知结果 | 输入提问；提交中断网；读取原请求；切报告形式                           | 保问题/attempt/key；提问零 Run；不足明确；不自动重提，不据空 GET 推断写入从未发生                  |
| M10 后续研究弹层  | 打开长内容确认框；旋转/滚动；返回键或取消；重开后确认                  | 安全取消先获焦点，正文可滚且动作可达；取消零写，确认仅一次独立 Run；关闭焦点返回，未知请求保原 key |
| M11 真实读屏      | VoiceOver/TalkBack 遍历菜单、表单、partial、引用、弹层及忙碌态         | 名称/角色/顺序可理解，装饰图标不重复读，无焦点困住；保存实际报读记录                               |

## 遮挡与布局检查

- 缺口、圆角、底部手势区：工具栏展开/收起和横屏均检查菜单、报告工具、弹层页脚与输入。记录遮挡元素、可见边界和截图后再决定 `env(safe-area-inset-*)` 等修复。
- 软键盘：覆盖邮箱、密码、数字、多行和日期；中文组合输入、下一项/完成后当前字段与错误能滚入视区。不以固定高度裁切或缩小字体解决遮挡。
- 旋转与固定区域：保报告形式、草稿、未确认请求与合理焦点；弹层可关闭，无额外写/Run。粘性区不能占满有效高度。
- 系统返回与手势：核原生弹层和页面离开保护的实际顺序；不全局劫持返回，不产生多重确认。
