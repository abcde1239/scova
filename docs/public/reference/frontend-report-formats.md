# 切换报告阅读形式

报告详情提供简报、主题清单、对比表和研究报告四种阅读形式。初次打开采用报告保存的形式；通过“报告形式”选择器可切换当前阅读结构。

四种形式使用明确不同的阅读结构：简报以连续摘要和结论为主；主题清单将每个问题显示为带编号的卡片并按结论类型分组；对比表使用“研究问题 / 已收集信息与来源”的语义表格，旧版没有问题答案时显示“序号 / 信息与引用 / 资料类型”的事实表；研究报告使用双线纸页式正文、编号目录和分隔章节。形式切换只改变信息编排，不把同一份证据伪装成新的比较对象或重新生成内容。

切换只影响本页呈现，不修改报告、任务配置、比较基线或网址，也不重新读取报告、启动研究或保存四份副本。同一账号阅读同一报告时保留本次选择；换报告、换账号或会话代次变化后重新采用对应报告保存的形式。刷新页面也恢复保存的形式。临时读取失败时隐藏不可读内容，恢复后保留同一报告的本次选择。

四种形式使用同一份报告的结论、变化和引用。事实、推断、冲突和不足保持区分；同文不同标识的结论分别保留，变化保留原值、理由和双方引用。全部形式均在“来源与保存引用”中按保存顺序列出所有证据，包括只用于变化或未归入结论的来源。引用是保存的原文片段，来源网页当前内容可能已变化。

“变化与基线”不再挤在正文问答下方，而是固定在右侧“对话与后续研究”工具卡片之后的独立卡片中；窄屏时随侧栏纵向排列。旧值和新值在该卡片内纵向堆叠，分别保留原始引用。专注阅读同时收起问答和基线，页内“变化”导航会先展开侧栏再聚焦基线标题。

“正文”“变化”“来源”是页内导航，与阅读形式选择分开。选择形式后焦点留在选择器；页内导航将焦点移到对应标题。对比表在自身区域横向滚动，页面可随文字大小和可用宽度重排。部分交付警告、模式、版本、交付时间及覆盖限制在各形式保持可达。

笔记、反馈、收藏和报告问答位于阅读结构之外。切换形式不清空本地编辑内容，不重新提交问题或确认后续研究；这些操作仍需各自的显式动作。

```sh
vp test apps/web/tests/report-formats.test.ts
vp run test:e2e -- tests/e2e/report.spec.ts tests/e2e/report-topic-list.spec.ts
```

单元测试渲染真实 Vue 组件并核对保存内容的完整映射。浏览器测试覆盖生产路由切换、刷新、身份隔离、网络只读及窄屏和文字放大；受控接口样本不代表远程模型或实体设备已验收。
