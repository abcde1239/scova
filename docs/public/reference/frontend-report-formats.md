# 选择输出形式与阅读成果

任务配置和执行前可多选简报、主题清单、对比表和研究报告，至少选择一种。每种形式具有独立的采集目标与生成指令，执行只生成所选成果；任务中保存的选择用于后续执行，执行前的选择仅覆盖本次运行。

简报收集核心答案与重要发现；主题清单收集对象条目及所需字段；对比表收集共同维度、差异与对应依据；研究报告收集完整论点、证据链、解释与限制。同次执行可复用已读取的来源，各形式分别保存结论索引、安全摘要与必需对象/字段的覆盖状态。清单按显式对象与字段渲染卡片，对比以显式对象为列、共同维度为行；字段值关联保存的结论作为依据，不在页面拆解中文句子推测结构。旧报告没有对象结构时明确说明并保留原问题与回答。

报告详情只提供实际保存的成果。多份成果通过“已生成成果”按钮切换，单份成果不显示选择器；旧报告缺少独立成果记录时只按其保存的形式展示。查看其他已保存成果不会修改任务配置、比较基线或网址，也不会启动研究或生成内容。要增加形式，应在后续执行前选择并运行。

同一账号阅读同一报告时保留本次成果选择；换报告、换账号或会话代次变化后重新采用对应报告保存的形式，刷新也恢复默认选择。临时读取失败时隐藏不可读内容，恢复后保留同一报告的本次选择。事实、推断、冲突和不足保持区分，历史变化与比较基线单独保留原值、理由和双方引用。

“来源与保存引用”按来源和快照版本分组，同一网页的一组引用只显示一次标题，相同快照内的重复原文只展示一次并保留原锚点。不同版本的网页分别展示。引用是保存的逐字片段，定位、查阅时间与快照信息可继续展开查看，来源网页当前内容可能已变化。

正文与历史变化仅保留对应的引用链接，原文集中在来源区。字段的依据链接先定位结论，结论再链接到逐字引文；所需的折叠区域会自动展开。报告先展示摘要与回答，页首保留部分交付状态；摘要后以具体对象或问题链接简述需补充处及分歧，最多显示三项，更多内容有完整入口。全部待补充清单集中在末尾“查阅与核验详情”，待核实材料单独折叠并保留数量，不计入已确认回答。字段未知与影响结论的适用条件仍在对应位置直接说明。问题材料数、对象字段完整性和查阅范围分别保留，不能用有一个相关结论代表所有指定对象已答。单形式保留安全的已保存摘要，多形式优先使用独立摘要；历史摘要含不足结论时仅以可交付结论按问题覆盖重建显示，不改写已保存报告。

结构化字段直接显示关联结论的适用条件与实质缺口，并合并重复说明。未知字段不展示过期值；参考或待核依据明确标记，后续综合补充过的旧表述保留替代说明。新结构化摘要先覆盖请求对象，再补同对象的更多细节，保留完整限定而不截句。

“变化与基线”位于成果预览内的正文下方，宽屏随成果展示在对话右侧，窄屏随成果排列在对话之后。旧值和新值在预览中纵向堆叠，分别保留原始引用；完整阅读时可随空间并排。× 关闭成果后可从对话中的成果卡重开，完整阅读隐藏对话并保留基线；页内“变化”导航直接聚焦基线标题。

“正文”“变化”“来源”是页内导航，与成果选择分开。选择成果后焦点留在按钮；页内导航将焦点移到对应标题，引用链接展开对应来源并定位到原文。对比表在自身区域横向滚动，页面可随文字大小和可用宽度重排。部分交付警告、模式、版本、交付时间及覆盖限制在各成果保持可达。

笔记、反馈、收藏和报告问答位于成果结构之外。切换成果不清空本地编辑内容，不重新提交问题或确认后续研究；这些操作仍需各自的显式动作。

```sh
vp test apps/web/tests/report-formats.test.ts
vp run test:e2e -- tests/e2e/report.spec.ts tests/e2e/report-topic-list.spec.ts
```

单元测试渲染真实 Vue 组件，核对成果内容隔离、问题索引映射、来源分组与保存内容不变。浏览器测试覆盖成果选择、刷新、身份隔离、引用定位及窄屏和文字放大；受控接口样本不代表远程模型或实体设备已验收。
