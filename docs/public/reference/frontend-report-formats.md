# 输出形式

一次研究可以同时生成多种成果。每种形式有自己的采集目标和写法，适合不同的读者需求。

## 选择形式

- 在任务配置页多选，至少选一种：简报、主题清单、对比表、研究报告。
- 立即执行沿用已保存的形式，执行区域不再临时选择。
- 重试沿用原执行的设置，不随任务后来的修改变化。
- 要增加形式，先修改并保存任务配置，再新建执行。

## 四种形式

| 形式     | 适合               | 你会看到                                                                                   |
| -------- | ------------------ | ------------------------------------------------------------------------------------------ |
| 简报     | 快速拿到答案       | 核心答复和少量关键发现，证据充分时通常 3–5 点。必要条件紧邻发现，不凑数、不强加建议。      |
| 主题清单 | 知道“有哪些”       | 具名条目和一致的字段，保留日期、条件和来源。未知信息明确标注，不虚构条目。                 |
| 对比表   | 在几个对象间做取舍 | 对象为列、共同维度为行，统一单位、时段和计费口径。缺失值不等于零或劣势，不无依据评选胜者。 |
| 研究报告 | 需要完整论证和背景 | 概述、必要背景、主题分析、结论与限制，使用连贯段落，不虚构实验、样本或研究方法。           |

清单字段一致、不超过六个且值简短时，宽屏用表格、窄屏用卡片，其余用卡片。旧报告没有对象结构时，会说明并保留原问答。

## 切换与阅读

- **已生成成果**：多份成果用该按钮切换，单份成果不显示选择器。旧报告只按保存的形式展示。
- **不会触发生成**：切换只是阅读，不修改任务配置、比较基线，也不启动研究。
- **选择会记住**：同一账号阅读同一报告时保留选择，刷新后恢复默认。
- **页内导航**：“正文”“变化”“来源”与成果选择分开，点击后焦点移到对应标题。
- **完整阅读**：成果浮窗展开到工作区宽度，稿纸居中。返回对话或按 Esc 收起，已选形式、展开的来源和本地编辑内容保留。系统启用减少动态效果时直接切换。

## 写作与版式

- 正文直接陈述发现，不反复加免责声明或“建议核实”。实质未知放在对应字段，影响答案的条件就近保留。
- 新生成的简报和研究报告可带章节大纲，研究报告有目录。重要条件保留在对应段落旁，问题覆盖可展开查看。
- 对比表在自身区域横向滚动，列宽按内容自动分配。窄面板取消固定维度列，避免遮挡放大后的内容。
- 清单的长字段用更宽的卡片，窄面板自动单列。
- 长链接和标识符可换行，不裁切答案、不缩小文字。
- 章节结构和引用校验不等于独立事实核查。

## 字段条件与缺口

- 表格单元格只放简短值，额外条件和缺口放在表下编号注释。卡片则在字段旁显示完整说明。
- 未知字段不显示过期值。参考或待核依据会明确标记。

## 来源与保存引用

- 统一放在稿件末尾，每个网页一项标题和一个外链。
- 网页按规范化地址分组，忽略片段和常见跟踪参数。不同保存版本在同一网页下分别展示。
- 正文、清单和对比表不逐项插入来源按钮，引用关系集中在文末可展开的依据里。点击引用链接可展开并定位原文。

## 分析研究与资料采集

- **分析研究**：稳定知识可由模型直接回答，答案和表格单元格显示【模型自回答】。实时信息、精确数据、指定出处和真实冲突仍需要证据。规则见[研究循环](agent-research-loop.md)。
- **资料采集**：不使用模型自答。清单显示“已采集条目”表，含值、日期、日期来源和直接原文引用。日期筛选另列窗口、收录页数、日期未知页数和窗口外页数。选择剔除未知日期时，不展示该来源列表。零条目时提示没有满足日期和出处要求的条目。
- **统计**：报告页和执行页分别显示“回答完成”“外部证据支持”“仍未解决”。模型自答计入回答完成，不计入外部支持。切换成果时按该成果的必要字段重算。

## 变化与页首

- “变化”区位于成果正文之前，见[变化与基线](frontend-report-changes.md)。
- 页首只保留交付状态入口，具体查询、缺口和核验信息在可展开详情里。
- 笔记、反馈、收藏和报告问答在成果之外，切换成果不会清空本地编辑内容，也不会重新提交问题。
