# 选择输出形式与阅读成果

分析研究可用模型已学知识回答允许的稳定知识字段，并在答案及表格单元格显示【模型自回答】标签，不附小字说明。知识草稿不会提前结束外部核验；实时信息、精确数据、指定出处和真实冲突仍保留证据要求。资料采集关闭模型知识草稿与补答。模型答案计入回答完成，外部证据支持独立统计，不附虚构引用；具体规则见[研究循环与完成判定](agent-research-loop.md)。

在任务配置编辑页可多选简报、主题清单、对比表和研究报告，至少选择一种。每种形式具有独立的采集目标与生成指令，执行只生成所选成果。立即执行沿用已保存的任务形式，执行区域不再提供临时形式选择；重试沿用原执行快照，不随任务后续修改变化。

简报收集核心答案与重要发现；主题清单收集对象条目及所需字段；对比表收集共同维度、差异与对应依据；研究报告收集完整论点、证据链、解释与限制。同次执行可复用已读取的来源，各形式分别保存结论索引、安全摘要与必需对象/字段的覆盖状态。清单按显式对象与字段展示：字段一致、数量不超过六个且值简短时，宽屏使用表格、窄屏使用卡片；其余情况使用卡片。对比以显式对象为列、共同维度为行；字段值关联保存的结论作为依据，不在页面拆解中文句子推测结构。旧报告没有对象结构时明确说明并保留原问题与回答。

四种形式采用不同的正文组织：

| 形式     | 正文与阅读方式                                                                                                 |
| -------- | -------------------------------------------------------------------------------------------------------------- |
| 简报     | 核心答复与少量关键发现，通常在证据充分时整理为 3–5 点；必要条件紧邻发现，不凑条目数、不强加建议。              |
| 主题清单 | 具名条目与一致的请求字段，保留日期、条件和来源；未知信息明确标注，不虚构条目。                                 |
| 对比表   | 对象为列、共同维度为行，统一单位、时段和计费口径；缺失值不等同于零或劣势，不无依据评选胜者。                   |
| 研究报告 | 简要概述、必要背景、主题分析、结论与实质限制，按资料和需求选择章节；使用连贯段落，不虚构实验、样本或研究方法。 |

新生成的简报与研究报告可保存章节大纲。章节只引用本成果已验证的正文结论，不能另存无依据正文、漏掉主文或重复索引；概述不重复整篇正文。研究报告目录链接到保存的章节，重要条件保留在对应段落旁，问题覆盖以可展开的审计入口提供。旧成果没有大纲时保留原阅读方式，不在浏览时重新生成。章节结构和引用认证不等同于独立事实核查或远程模型质量保证。

正文直接陈述发现，不反复增加免责声明、泛化风险或“建议核实”等结尾。实质未知在对应字段或必要的一条说明中表达；影响答案的条件和分歧仍就地保留。保存大纲的成果页首仅保留交付状态入口，具体查询、缺口与核验信息集中在可展开详情，不再重复插入阅读提示和来源范围入口。

写作以读者能理解为准：段首先说明要点，再解释依据、机制或实际含义，一段只展开一个中心。研究报告避免把整套流程、风险和措施压进分号长句；简报用完整短句交代关键发现；清单字段可独立阅读；对比表同一行采用平行表述与相近的信息量。正文保留作者的空行分段，重要条件自然写入相关句子，单独保存但正文未包含的条件仍紧随段落展示。标题、日期和来源计数各司其职，简报与研究报告不再重复展示形式标题及操作说明。这些写作要求用于后续生成，阅读历史成果不会改写已保存文本或核验状态。

常规结构参考 [IDRC 简报指南](https://idrc-crdi.ca/en/funding/resources-idrc-grantees/how-write-policy-brief)、[NN/g 对比表指南](https://www.nngroup.com/articles/comparison-tables/)及 [Reading 报告结构指南](https://libguides.reading.ac.uk/reports/structuring)。这些指南用于阅读组织；具体字段、篇幅与章节仍以任务需求和实际证据为准。

报告详情只提供实际保存的成果。多份成果通过“已生成成果”按钮切换，单份成果不显示选择器；旧报告缺少独立成果记录时只按其保存的形式展示。查看其他已保存成果不会修改任务配置、比较基线或网址，也不会启动研究或生成内容。要增加形式，应先修改并保存任务配置，再新建执行。

同一账号阅读同一报告时保留本次成果选择；换报告、换账号或会话代次变化后重新采用对应报告保存的形式，刷新也恢复默认选择。临时读取失败时隐藏不可读内容，恢复后保留同一报告的本次选择。事实、推断、冲突和不足保持区分，历史变化与比较基线单独保留原值、理由和双方引用。

“来源与保存引用”统一放在稿件末尾，每个网页只显示一项标题与一个外链。网页按规范化地址分组，忽略片段和常见跟踪参数，保留有业务意义的查询参数；不同保存版本在同一网页项下分别展示，相同快照内的重复原文只展示一次并保留所有原锚点。逐字引文、定位、查阅时间与快照信息可展开查看。

正文、对象清单和对比表不再逐项插入来源按钮；结论和历史变化双方的引用关系集中在文末可展开的依据中，链接仍能展开并定位对应保存引文。报告先展示摘要与回答，页首保留交付状态；完整样稿展示正常完成的四种布局，不以大量缺失字段演示默认效果。实际待补充清单集中在“查阅与核验详情”，待核实材料单独折叠并保留数量，不计入已确认回答。字段未知与影响结论的适用条件仍在对应位置说明，已包含的完整条件不再重复。问题材料数、对象字段完整性和查阅范围分别保留。单形式保留安全的已保存摘要，多形式优先使用独立摘要；历史摘要含不足结论时仅以可交付结论按问题覆盖重建显示，不改写已保存报告。

结构化字段保留关联结论的适用条件与实质缺口，并合并重复说明。表格单元格使用简短值，额外条件与缺口移到表下编号注释；卡片在字段旁显示完整说明。未知字段不展示过期值；参考或待核依据明确标记，后续综合补充过的旧表述保留替代说明。新结构化摘要先覆盖请求对象，再补同对象的更多细节，保留完整限定而不截句。

“变化”位于成果预览内的正文之前。首次合格执行仅显示比较起点状态，不重复列出基线事实；后续新增、变化和待核验直接显示，重复等记录折叠。每项用旧值 → 新值展示，保留两侧原始引用，详见[变化与基线](frontend-report-changes.md)。× 关闭成果后可从对话中的成果卡重开，完整阅读隐藏对话并保留变化区；页内“变化”导航直接聚焦该区标题。窄屏通过“成果”进入全屏阅读，再返回对话。

“完整阅读”让同一个成果浮窗以 420 毫秒的过渡展开至工作区宽度，稿纸居中、正文控制行宽，滚动在面板内继续。返回研究对话或按 Escape 时收起，保留已选形式、展开的来源和本地编辑内容；系统启用减少动态效果时直接切换。关闭、重新打开成果仍使用原有短过渡。

资料采集的清单成果显示“已采集条目”表，包含值、发布或更新日期、日期来源和直接原文引用。日期筛选另列窗口、收录页数、日期未知页数及窗口外页数；选择剔除未知日期时不展示该来源列表。零条目明确显示尚无满足日期与直接出处要求的条目，不用模型知识补成结果。

“正文”“变化”“来源”是页内导航，与成果选择分开。选择成果后焦点留在按钮；页内导航将焦点移到对应标题，引用链接展开对应来源并定位到原文。对比表在自身区域横向滚动，页面可随文字大小和可用宽度重排。部分交付警告、模式、版本、交付时间及覆盖限制在各成果保持可达。

报告根据内容长度与面板实际宽度自动排版。对比表使用可用宽度，按各列最长内容估算列宽；短维度列保持紧凑，长文列适当扩展，空间不足时仅在表内滚动。清单的长字段使用更宽的卡片，窄面板自动单列；简报与研究报告保持适中的正文行宽。长链接和标识符可换行，原始空行分段保留，不裁切答案或缩小文字。窄面板取消固定维度列，避免遮挡放大后的内容。布局计算在前端完成，不额外调用模型，也不改写已保存内容。

新策略报告和执行页分别显示“回答完成”“外部证据支持”“仍未解决”。模型补足的稳定知识计入回答完成，保留【模型自回答】标签，不计入外部支持；实时信息、精确数据与指定出处未核实的字段仍待解决。切换成果时按本成果的必要字段重算统计，不带入其他成果的结论。历史报告没有这项保存数据时保留原显示。

笔记、反馈、收藏和报告问答位于成果结构之外。切换成果不清空本地编辑内容，不重新提交问题或确认后续研究；这些操作仍需各自的显式动作。

```sh
vp test apps/web/tests/report-formats.test.ts
vp exec playwright test --config tests/e2e/playwright.config.ts report-documents.spec.ts report.spec.ts report-topic-list.spec.ts report-comparison-table.spec.ts report-research.spec.ts
```

单元测试渲染真实 Vue 组件，核对成果内容隔离、问题索引映射、来源分组与保存内容不变。浏览器测试覆盖成果选择、刷新、身份隔离、引用定位及窄屏和文字放大；受控接口样本不代表远程模型或实体设备已验收。
