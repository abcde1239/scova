# 登录表单

`/login` 使用公开的 LoginInputSchema，通过统一 requestlane 的匿名登录端点提交，响应经会话生命周期交接。登录密码允许 1 至 128 位，不能套用注册最短限制；邮箱规范化由服务端负责。

表单只在本地保存当前输入，成功或卸载清空密码；密码不进入 Pinia、日志或浏览器存储。在途动作同步锁定，鼠标及键盘不会重复提交。字段错误聚焦首个无效输入，401/429及网络错误使用明确文字。请求绑定发起时的会话代次，离开页面取消请求，旧返回不能覆盖后来安装的会话。

成功进入任务页。会话刷新恢复、守卫与退出由独立会话 Issue 交付；注册由独立注册 Issue 交付。当前没有找回密码、邮件验证或第三方登录入口。表单采用单列弹性宽度和相对字号，不缩小整个页面以适应窄屏。

登录与注册共用 `AuthLayout.vue`。宽度 ≥ 54rem 时左右分栏：左侧展示品牌、标语、报告与运行进度预览和三项能力，右侧表单栏限宽 36rem，标题与表单整体水平、垂直居中，表单最大宽度为 28rem。右上以色点、外观和「文/A」翻译图标提供紧凑设置入口，三者共用 `AppSelect` 下拉菜单，悬停提示名称与当前值，键盘和触屏均可操作。窄屏只保留表单栏，品牌与一句话定位显示在标题上方。切换主题保留布局和已填内容。

登录页左栏可独立滚动，隐藏滚动条并提供上下跳转入口；首屏与产品示例共用连续网格背景。点击报告卡或按 Enter、空格切换摘要与示例引用。鼠标悬停时，来源卡随报告卡组倾斜，对话中的提问、回复和草案依次轻移。点击或用键盘选择示例工作流节点，检查器会显示该节点绑定的任务和成果。减少动态效果时，节点详情直接切换。支持滚动时间轴的浏览器使用轻微滚动视差和入场效果。网格在裁切层内平移，进度条以固定布局宽度缩放，浏览器可合成这两段动画。减少动态效果时保留静态网格和预览内容，隐藏随滚动更新的进度轨。登录标题仅在进入时轻微浮现，导览箭头对悬停和键盘聚焦提供方向提示。登录按钮按下时文字轻缩，字段错误短暂浮现。系统设为减少动态效果时，这些过渡使用静态状态。注册页保留静态展示，不显示产品导览。
