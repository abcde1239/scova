# 登录表单

`/login` 使用公开的 LoginInputSchema，通过统一 requestlane 的匿名登录端点提交，响应经会话生命周期交接。登录密码允许 1 至 128 位，不能套用注册最短限制；邮箱规范化由服务端负责。

表单只在本地保存当前输入，成功或卸载清空密码；密码不进入 Pinia、日志或浏览器存储。在途动作同步锁定，鼠标及键盘不会重复提交。字段错误聚焦首个无效输入，401/429及网络错误使用明确文字。请求绑定发起时的会话代次，离开页面取消请求，旧返回不能覆盖后来安装的会话。

成功进入任务页。会话刷新恢复、守卫与退出由独立会话 Issue 交付；注册由独立注册 Issue 交付。当前没有找回密码、邮件验证或第三方登录入口。表单采用单列弹性宽度和相对字号，不缩小整个页面以适应窄屏。

登录与注册共用 `AuthLayout.vue`，页面完全静态，没有背景动画。宽度 ≥ 54rem 时左右分栏：左侧展示栏放品牌、标语、两张静态产品预览卡片（示例报告与运行进度，`aria-hidden`）和三项能力（`auth.showcase.*`、`auth.highlights.*`），右侧表单栏居中放标题与表单，右上保留主题、外观和语言选择。窄屏只保留表单栏，品牌与一句话定位（`auth.tagline`）显示在标题上方。切换主题只改变强调色，不改变布局和已填内容。
