# 报告反馈作用

报告详情中的“本报告的反馈作用”只读展示 `Report.feedbackEffects`。它与下方“调整后续研究”的当前任务反馈分开：修改或撤销当前反馈不会改写旧报告，新报告展示自身保存的记录。字段缺省或数组为空时不显示面板，也不据此推断当前反馈状态。

| 记录                    | 展示与范围                                                   |
| ----------------------- | ------------------------------------------------------------ |
| `expanded_query`        | 深入查询已执行；不代表找到新事实或已完成全部研究             |
| `promoted`              | 目标来源已优先采集；不保证多来源相对排名发生变化             |
| `excluded`              | 已排除新发现候选；不删除旧证据，也不表示永久屏蔽             |
| `deprioritized`         | 未变结论已后移；重要新事实、原分类与引用仍保留               |
| `baseline_protected`    | 基线来源保留复读；不代表模型保证或已确认所有新条件           |
| `monitoring`            | 已读取目标来源；不表示忽略、降序或穷尽查阅                   |
| `not_applied_budget`    | 未执行：预算不足                                             |
| `not_applied_unmatched` | 未执行：未匹配                                               |
| `not_applied_policy`    | 未执行：策略限制；共享 DTO 支持，当前 Agent 尚无生产生成分支 |

“反馈意图”保留该记录的“不相关 / 已了解 / 希望深入”，实际结果以作用与原始原因说明。一条反馈可同时有多个作用和限制；全部记录按保存顺序逐项显示，包括重复项，不按反馈标识合并。

目标与执行详情可展开查看资料或结论标识、反馈标识，以及存在时的完整查询和来源网址。目标内容只从本报告按类型与标识准确匹配；旧目标不在当前报告中时保留类型和标识，不另行请求或猜测标题。原因、查询、目标内容保持原文，按纯文本换行显示，网址通过统一安全链接入口并明确在新窗口打开。

本面板没有请求、命令或独立缓存，不改变报告结论、变化、重要性、引用、Run、配置或基线。报告读取失败时随原报告一起隐藏。合法上限为 600 条、原因 1000 字符、查询 2000 字符，由共享 schema 验证，不在展示层静默截断。
