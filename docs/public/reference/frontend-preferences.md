# 账号默认偏好

从账号工具进入 `/account`，可查看邮箱并修改默认时区、结果提醒方式及运行问题提醒。时区使用可搜索的下拉框，展示城市与 IANA 名称，包含浏览器支持的时区、常用项及当前有效设置。结果提醒共用带图标、说明和选中标记的下拉框；两个控件均支持方向键、确认、Esc 和焦点恢复。

保存通过同源 Cookie 会话的 `PATCH /api/v1/me/preferences` 完成，仅提交变更字段。保存成功后更新会话摘要，并重新读取当前账号偏好。保存失败时保留输入，检查错误后可手动重试；保存期间不能重复提交。会话失效时进入登录流程，旧账号请求不能覆盖新账号状态。

这些默认值用于后续新建的任务草稿，不追溯修改已保存任务的时区、计划或配置版本。

`/account/appearance` 的明暗、主题色、正文字体与字号仅保存在当前浏览器，不调用账号偏好接口，也不会改变其他设备的默认任务偏好。

验证命令：

```sh
vp test apps/web/tests/preferences.test.ts
vp run test:e2e tests/e2e/preferences.spec.ts
```

浏览器用例使用明确的本地 HTTP 样本检查交互、刷新、错误焦点与响应式布局；不据此证明数据库持久化或真实任务创建。200% 覆盖通过增大根文字字号完成，不等同于浏览器页面缩放。
