# 工作台响应式导航

工作台使用弹性容器：`width: min(100%, 88rem)`，边距随可用宽度变化，字号和触屏目标保持浏览器默认根字号下的 rem/em。内容自然换行，不缩小桌面画布；长表格的局部滚动由领域页面负责。

导航在约 `54rem` 以下合并为左侧个人栏。已登录时，点左上角头像打开原生模态侧栏，再点顶部头像或账号摘要进入账号页；摘要保留真实邮箱和跳转箭头，列表不重复放“账号”。任务、收件箱、资料库、通知和外观在其后排列，退出紧接选项。未登录时使用账号图标入口，侧栏提供登录链接。

触发器提供展开状态和可访问名称，侧栏有遮罩、关闭按钮与焦点约束。Esc、关闭按钮或点击遮罩返回触发器；选择链接后关闭并进入主内容，同页选择也恢复主内容焦点；浏览器后退返回原页面而不重开侧栏。切到宽屏会清理打开状态并将隐藏区域的焦点移出。桌面仍使用顶部导航和头像账号菜单。图标复用集中 Ionicons，保留文字和足够点击面积。

布局不实现业务表单、媒体、报告内容或认证守卫。浏览器验收覆盖六种视口和 200% 文字放大；视口的像素值是测试环境参数，应用布局仍使用相对单位。真实设备旅程由后续验收项覆盖。
