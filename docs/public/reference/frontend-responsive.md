# 工作台响应式导航

工作台在 `54rem` 起使用粘性左侧栏，主区在剩余宽度内居中，最大宽度为 `88rem`。任务表单等窄内容使用独立最大宽度。长列表只滚动导航项，侧栏底部的通知和账号弹层可以向主区或上方展开。长表格的局部滚动由领域页面负责。

小于 `54rem` 时使用紧凑顶部栏。点左上角头像打开模态侧栏，可直接进入新建任务、任务、项目、工作流、收件箱和资料库。账号摘要显示真实邮箱并链接账号页，通知、Agent 配置、外观和退出在抽屉内。未登录时使用账号图标入口，侧栏提供登录链接。

导航保留可访问名称、当前页面状态和可见焦点。Esc、关闭按钮或点击遮罩会将焦点还给触发器。选择链接后关闭抽屉并聚焦主内容，同页选择也遵循同一规则。浏览器后退保持抽屉关闭。切换到宽屏会关闭打开的抽屉，并将焦点移出隐藏区域。图标复用集中 Ionicons，保留文字和足够点击面积。

内容按可用宽度重排，字号和控件尺寸使用 rem/em。项目对话在宽屏可并排显示概览，窄屏用视图选择器切换。工作流在宽屏并排呈现节点顺序和检查器，窄屏按相同顺序堆叠。报告在 `72rem` 起并排显示对话和成果，低于此宽度时通过「成果」打开独立阅读视图。浏览器验收覆盖多种视口及 200% 文字放大。
