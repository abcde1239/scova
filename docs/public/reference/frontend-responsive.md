# 工作台响应式导航

工作台使用弹性容器：`width: min(100%, 68.75rem)`，边距随可用宽度变化，字号和触屏目标保持浏览器默认根字号下的 rem/em。内容自然换行，不缩小桌面画布；长表格的局部滚动由领域页面负责。

导航在约 `54rem` 以下合并为非模态展开菜单，包含任务、收件箱、资料库、通知、账号和外观。按钮提供展开状态，菜单中的链接保持原生键盘操作。Esc 关闭并返回触发器，选择入口后关闭且焦点进入主内容；切到宽屏会清理打开状态并将隐藏区域的焦点移出。菜单在文档流中展开，无全屏遮罩或焦点锁定。图标复用集中 Ionicons，保留文字和足够点击面积。

布局不实现业务表单、媒体、报告内容或认证守卫。浏览器验收覆盖六种视口和 200% 文字放大；视口的像素值是测试环境参数，应用布局仍使用相对单位。真实设备旅程由后续验收项覆盖。
