# 来源媒体契约候选

状态：2026-10-31，#99 设计交付，尚未实现或批准媒体 API。已确认的展示方向见[视觉评审记录](frontend-visual-review.md)：资料与报告按需展示相关来源图片，缺图保持纯文字；图片不阻塞核心流程。本文供后续契约评审与交付拆分使用，不定义数据库列名、路由、资产供应商或抓取默认开关。

## 当前能力核对

事实源为 [library.ts](../../../packages/models/src/library.ts)、[reports.ts](../../../packages/models/src/reports.ts) 和 [资料库服务](../../../apps/server/src/service/library.ts)。下表列出与媒体相关的现有字段，不是完整 DTO 清单。

| 当前对象                | 已支持                                                                                                                                                     | 当前不支持                                                             |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| `LibrarySourceSchema`   | `id`、`canonicalUrl`、可空的 `title`、`latestSnapshotId`、`lastObservedAt`；标题来自最近成功观测                                                           | 图片、缩略图、媒体身份、授权、尺寸或媒体交付地址；来源 URL 不触发抓取  |
| `LibrarySnapshotSchema` | `id`、`sourceId`、`observationId`、`runId`；原始/最终/规范 URL、正文 `contentHash`、提取版本、观测/发布时间、`textExpiresAt`、`bodyStatus`、模式与截断状态 | 图片字节或指纹、图片与观测的绑定、媒体保留期；正文指纹不能充当图片指纹 |
| `EvidenceSchema`        | `id`、`sourceId`、`snapshotId`、URL、标题、文字 `quote`、位置、观测时间；可选 `snapshot` 保存来源元数据与 `text_offset` 选择范围                           | 图片证据、区域选择器、媒体引用或图片授权；文字偏移不能定位图像区域     |

快照详情在正文过期后可以返回空正文和保留的引用片段，这不授予媒体继续保留的权利。取消收藏不删除来源、报告或证据，也没有“取消收藏即删除图片”的现有行为。资料库服务按会话账号核来源/快照归属；这些校验尚未扩展为媒体访问权限。当前没有可供前端消费的媒体契约，不能从来源 URL 猜封面或把演示素材写入真实 DTO。

## 候选绑定与展示语义

以下均为拟新增能力，表中的信息是语义需求，不是属性命名或 JSON 草案。

| 拟新增信息         | 候选语义                                                                                                | 仍需决定                                                               |
| ------------------ | ------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| 媒体身份与内容版本 | 稳定身份区分资产，独立内容指纹区分实际字节；变体可追溯到其原始资产与转换版本                            | 内嵌 DTO、独立关系或独立查询；身份和变体版本策略                       |
| 来源及采集绑定     | 关联当前账号可访问的来源，并明确来自哪个快照/观测、何时发现和取得；相同 URL 后来变图不得改写旧绑定      | 每快照/观测的数量、采集时机、失败重试与是否主动补采                    |
| 引用上下文         | 装饰/浏览用缩略图只表示与来源相关；不能隐式加入报告证据集合或证明整份报告                               | 首轮仅缩略图还是也支持正文插图；真正图片证据另需 schema/定位与产品评审 |
| 展示元信息         | 验证后的格式、原始像素宽高/比例、变体信息、可解释的替代文本、必要的出处署名                             | alt 的取得与人工修正流程；无可靠描述时的可访问回退                     |
| 许可与处置状态     | 记录出处页面、作者/权利人、许可或允许使用的依据、适用范围及核验时间；区分未取得、待核验、可交付、不可用 | 可接受授权依据、转载/转换/保留范围与撤回处理责任                       |
| 生命周期与交付     | 明确媒体是否仍可访问、为何不能交付及交付所需权限；前端只拿可公开给当前账号的摘要                        | 状态集合、响应形状、错误语义、保留时限和缓存策略                       |

绑定建议优先以实际采集的快照/观测为依据：历史报告沿其 `sourceId`/`snapshotId` 使用当时明确绑定的媒体，不读取来源后来替换的图片；资料库当前列表如展示最新来源缩略图，应能追溯到该最新成功观测。没有可匹配的历史绑定时保持无图，不能用最近图片填补历史。重复内容可以物理去重，但每个账号的可见绑定、许可和删除判定必须独立。

同页图片、`og:image`、搜索结果图片和原站可公开打开均不是授权证明，也不保证与某条证据相关。NASA 等受控演示素材只证明该素材自身来源与使用条件，不适用于其他来源。未核验授权的候选不对用户交付；是否允许为核验暂存及其期限由许可负责人确认。alt 不应凭文件名或模型猜测，署名不塞进 alt；如果缩略图只是同一文本链接的冗余视觉，是否使用空 alt 应由无障碍评审根据组件语义决定。

## 账号、撤回与保留

以下是实施必须满足的候选安全边界，具体契约须经后文待决项确认后落地。

- owner 来自可信会话或后台任务上下文，不接受客户端指定 owner。取得元数据和实际字节时均验证账号、来源、快照/观测及媒体绑定；仅知道资产 ID、内容指纹或同源地址不构成授权。
- 复制其他账号的来源/快照/媒体标识、交换同账号不同来源的绑定、通过报告绕读无权快照，都必须被拒绝且不泄漏元数据、存储位置或其他账号是否持有资产。是否延用现有领域“不存在”语义，由 API 契约评审统一；登录失效仍沿用现有会话语义。
- 新快照、重新采集或同 URL 字节变化产生新的绑定/内容版本，不覆盖已发布报告的历史。缩略图失败、过期或权限撤回不改变报告结论、文字引用、已读状态或 Run 结果。
- 取消收藏仅移除收藏关系；删除资产、删除绑定、到期清理、授权撤回和账号删除是不同动作。媒体期限不从 `textExpiresAt` 推断；原图、变体、元数据、授权依据和历史引用各自的保留规则须明确。
- 失效后先停止新交付并失效关联元数据，再按已确认规则清理字节、变体、未完成采集和缓存；并发采集完成时重核绑定及权限，防止清理后重新发布。重试清理需幂等，物理去重不能误删仍有合法引用的其他账号资产。
- 历史来源/文字引用可保留可解释的缺图状态；不为缺图重跑研究、自动联网补图或伪造替代图片。法律/隐私删除与历史可追溯性冲突的处理、备份和日志清理时限由产品与数据保留负责人确认。

撤回可以阻止后续交付，但无法收回用户此前合法下载的字节；保留与缓存政策应明确这个边界，不能承诺浏览器或外部副本的远程销毁。

## 采集与存储安全

现有 HTML Reader 的公共地址验证可作为参照，不能证明图片抓取、解码或交付安全。若选择抓取模式，后续实现须独立覆盖以下边界；不允许因参数未确认而使用无限默认值。

| 环节       | 候选约束                                                                                                                                              | 独立验收输入                                             |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------- |
| URL        | 仅接受评审允许的 HTTP(S)；拒绝非网络 scheme、用户信息、非法端口/地址表达；相对地址以已验证的来源页面 URL 解析后再检查                                 | `file:`/`data:`、带凭据 URL、混淆 IP、相对路径与跨站候选 |
| DNS 与连接 | 全量解析结果必须符合公共地址策略；拒绝回环、私网、链路本地、保留地址和云元数据等目标；连接固定到已校验 IP 并保持正确 Host/SNI，不能校验后再次任意解析 | IPv4/IPv6、混合公私地址、DNS rebinding、连接目标变化     |
| 重定向     | 有限跳数；每跳重验 scheme、端口、域名和实际连接 IP；不转发会话 Cookie、授权头或来源站秘密；不继承 HTML Reader 的内部搜索服务例外                      | 公网转私网、跨域重定向、循环、超跳数、异常 Location      |
| 网络预算   | 限连接/总时间、跳数、并发、每来源数量、账号配额、重试及磁盘暂存；HEAD/Content-Length 仅作参考，按实际流累计压缩与展开字节，越限立即终止               | 长度缺失/虚报、chunked、压缩膨胀、慢速流、断线与取消     |
| 类型       | 候选首轮只接受有限静态光栅格式；同时校验响应类型、文件签名和解码结果，拒绝伪图片 HTML、SVG/脚本和未经批准的格式                                       | HTML 冒充 image、签名不符、多格式混杂、动画与损坏文件    |
| 解码       | 在受限资源/隔离环境解码，限制宽、高、总像素、帧数、内存、CPU 和时间；完整验证后生成受控变体，不向用户转发未验证原始字节                               | 巨幅/极端比例、解压炸弹、动画多帧、截断数据和恶意元信息  |
| 输出与存储 | 根据许可允许的范围重编码、校正方向并剥离不必要 EXIF/GPS/嵌入内容；独立指纹、转换版本和 MIME；暂存验证成功后再原子发布，失败不留下可交付半成品         | 超时/崩溃、转换失败、重复任务、发布前撤回与孤儿清理      |

允许格式、端口策略、上述所有数值上限、隔离方案和重编码是否符合来源许可，由安全/后端负责人提出并由产品确认可接受效果。图片自身像素宽高是解码资源计量，不是 CSS 固定像素布局。若无法满足抓取或解码限制，该候选媒体保持不可交付；不得回退为浏览器直接热链原站或降低地址验证。素材获取不夹带用户凭据，不把可能含签名参数的原始地址、响应正文或解码错误直接写入公开日志。

媒体采集是否独立于研究任务预算、何时触发、如何限额和取消，需单独确认；首轮不允许把页面读取或悬停变成隐式外网抓取，也不能把图片失败记作文本研究失败。

## 同源授权交付与缓存

候选采用经服务端验证的同源媒体交付，避免前端访问任意外站图片、暴露阅读行为或绕过账号检查。对象存储、文件系统、私有代理或签名方式尚未选择；同源地址不等于公开地址，存储键、远端抓取 URL、凭据和供应商配置不进入公开 DTO。

1. 媒体元数据和脚本发起的资源读取统一进入 requestlane 通信模块；Vue Query 管元数据缓存，Pinia 不复制媒体服务端列表，不建立页面 fetch/axios 请求层。是否通过图片元素加载经确认的同源地址，或由统一模块取得受控对象 URL，在契约评审时根据权限与撤回要求确定。
2. 每次实际交付先校 Cookie 会话及有效绑定，再处理条件请求；HEAD、Range、304、错误响应和代理命中同样不得绕过授权。交付设置可信的 Content-Type、`nosniff` 和与文档用途一致的内容策略，拒绝提供任意 URL 的公开代理。是否支持原图下载、Range 或签名地址均待决，不默认开启。
3. 首轮推荐认证媒体与其元数据采用 `Cache-Control: private, no-store`，共享代理/CDN及 Service Worker 不保存受保护响应。若产品需要浏览器私有缓存，必须另行批准有限 TTL、账号与绑定/内容版本隔离、重新验证和撤回时效；仅 `Vary: Cookie`、随机文件名或内容 hash 都不能替代授权。
4. 缓存身份至少覆盖当前账号的有效绑定与内容/变体版本，不把原站 URL 当全局可见缓存键。账号切换/退出中止在途请求、清空当前会话元数据并撤销对象 URL；迟到响应不能显示到新账号。跨账号物理去重不暴露缓存命中或放松读取授权。
5. 撤回、删除、到期、转换版本停用须使新请求不可交付，并覆盖应用缓存、代理和已生成变体；尚未完成的请求按约定取消或重新核验。缓存/304策略必须有 A 登录读取→退出→B 访问同地址及 A 权限撤回的回归测试。

## 前端适配边界

媒体未支持、无绑定、待核验、获取/解码失败、过期、删除或失去权限时都可退回纯文字，保留标题、来源、状态与操作，不展示破图或用装饰小字填空。只在帮助用户理解后果时提供简短可访问状态；业务可恢复的媒体错误不产生整个报告失败提示。

每条来源最多一张相关缩略图；报告插图若获批准，不裁掉地图图例、比例尺或关键文字。尺寸遵循已确认的弹性单位：容器用 `%`、`min()` / `max()` / `clamp()`，图片用 `aspect-ratio`、`max-inline-size: 100%` 及相对尺寸；不固定根字号，不把原始像素尺寸写成固定 CSS 布局。应在窄屏、长标题、200% 文字缩放、浅暗主题和触屏下保持阅读及操作，缺图时收回图片列。出处署名与相关说明按许可必要程度呈现，不增加无用途的常驻小字。
